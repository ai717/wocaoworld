自建WireGuard一条命令搞定：扫码就连的私人 VPN

 

一条命令搭好 VPN 服务端：脚本到底替你干了什么

想在国外访问家里的服务，或者出门在外走自己的加密通道，最省事的办法是自己搭一个 WireGuard VPN。wireguard-install 就是干这个的开源脚本：在自己的 Linux 服务器上一条命令，全自动装好 WireGuard 服务端，配置自动生成，客户端配置与手机扫码二维码自动导出，还支持增删用户、IPv4 与 IPv6 双栈、sysctl 性能优化。装完手机扫个码就能连，不用手动抄密钥。

装之前先备好服务器：脚本免费不等于零成本

先把账算清楚：脚本本身免费，但它要跑在你自己的服务器上，服务器或 VPS 是要付费的，不是零成本。装法很直接：curl -O https://raw.githubusercontent.com/hwdsl2/wireguard-install/master/wireguard-install.sh，再 chmod +x wireguard-install.sh && ./wireguard-install.sh，按提示选端口与 DNS 就能装完。装好之后管理用户也不用改配置文件，脚本带交互菜单，加人、删人、导出配置都在菜单里点几下完成。

手机扫码就能连：客户端配置一次给齐

脚本装完会给每个用户生成客户端配置文件，手机端扫二维码就能导入，电脑端把配置文件丢进 WireGuard 客户端即可。IPv4 与 IPv6 双栈都支持，家里宽带只有 IPv4 也能用；sysctl 性能优化已经写进脚本，转发性能不用自己调内核参数。出门在外连上自己的 VPN，流量先回自己的服务器再出去，公共 Wi-Fi 下的嗅探风险小得多。

老法师避坑提醒：自建 VPN 的安全取决于服务器本身，系统不打补丁、SSH 弱密码、密钥泄露，哪个都能让加密通道白搭；另外留意你所在地的网络规则，合规使用，别把自建 VPN 当成绕过管制的工具。

什么时候值得自建：三类人最划算

第一类是已有 VPS 的人，服务器反正闲着，搭个 VPN 是顺手的事。第二类是常出差、常连公共 Wi-Fi 的人，自己的加密通道比酒店与机场的裸 Wi-Fi 踏实。第三类是想远程访问家里 NAS 与开发机的人，VPN 连回家比把端口暴露在公网安全得多。三类之外，单纯想换个 IP 看视频的人，用商业 VPN 更省事，没必要自己运维一台服务器。

客户端用官方的 WireGuard 应用就行，手机扫二维码导入，电脑把配置文件拖进去，连接开关一拨即通。日常维护别偷懒：服务器系统补丁要定期打，脚本有新版就跟着升，密钥文件只存自己手里。用户多了就再开配置，离职或设备丢了马上在菜单里删掉对应用户，通道立刻失效。
