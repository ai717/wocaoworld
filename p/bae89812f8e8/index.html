huashu设计3.4版：30966星Skill免费商用

 

一句话拿回设计：网页原型PPT都能出

让 AI 做设计最常见的翻车是「还行但廉价」：配色像默认模板，排版没有呼吸感。huashu-design 是花叔的开源设计 Skill，30966 星、MIT 许可，个人和商用都免费。装进 Claude Code、Codex、Cursor 等兼容 Skill 的 Agent 后，打一句话就能拿回能交付的设计：网页、App 原型、可编辑 PPTX、小红书 3:4 图文、App Store 宣传图、动画和信息图。安装命令是 npx skills add alchaincyf/huashu-design。

3.4 版的更新点很具体：走查两届 App Store Awards 的 90 个入围作品，提炼出八条界面范式，各带样张；新增商店宣传图模块，1320×2868，连幅、破框、搜索结果预览都考虑了。界面里该是图的地方放真图：自带生图的环境直接生成，Claude Code、DeepSeek Harness 借本机 Codex 或你给的生图 API，不再用 emoji 和占位块顶替。「拆解获奖应用提炼范式」为作者自述，样张在仓库里可看。

六个候选挑三版：不让你盲选风格

它防廉价感的办法是给选择而不是给成品。需求模糊时触发设计方向顾问：三套逻辑各出两个候选，共六个——最佳设计师（两位气质不同的设计师思维）、现实参照（两件同媒介获奖作品，先截图亲眼看再拆网格字号色彩）、秒数轮盘（从 92 种带样张的风格库随机抽，打破惯性）。六个候选挑三版做完整稿，单看够好、彼此不一样、不撞你最近的项目，没选上的三个作备选告诉你。摆出来就停，看着选，不让你在没看到视觉时盲选风格。

92 种风格库分六个分区：网页 20、PPT 20、信息图 20、App 12、中文与东亚 12、小红书 8，纯 CSS 无需生图，每种配样张和源码。小红书图文是一组 3:4 竖图的八种范式——标本志、贴纸本、索引、长卷、日报、集换卡、留白、信息图，每个样张同时是能直接改的模板，一条命令切成成图，顺手查字号、出界、长卷跨缝和压字。

品牌资产五步：色值不许从记忆猜

涉及具体品牌时它强制走品牌资产协议五步：问用户有没有品牌规范，搜官方品牌页，下载资产（SVG、官网 HTML、产品截图取色三条兜底），用 grep 从资产里抓色值按频率排序过滤黑白灰，最后固化成 brand-spec.md 加 CSS 变量。作者称 v2 稳定性方差比 v1 低 5 倍，这是作者的 A/B 测试说法。还有一本外观账本记录每次交付的底色、色板、字体和版式骨架，下个项目主动避开长得像。

交付物耗时作者给了参考：交互原型 10 到 15 分钟，演讲幻灯片 15 到 25 分钟，信息图约 10 分钟，6 维度专家评审约 3 分钟。PPT 导出的是真文本框，PowerPoint 里双击即可编辑，不是把图片贴进幻灯片。原型是单文件 HTML 带真 iPhone 边框，可点击并用 Playwright 验证。

装完先自检：子目录缺了就是装残了

安装提醒写得很直白：这个 Skill 不只是 SKILL.md 一个文件，references/、assets/、scripts/、demos/ 四个子目录里有 430 多个被引用的文件，缺一不可。装完看安装目录，如果只有 SKILL.md，说明 skills CLI 版本太旧，升级后再装，或用 git clone https://github.com/alchaincyf/huashu-design.git ~/.claude/skills/huashu-design 兜底。DSH 桌面端可用 dsh plugin --profile desktop add github:alchaincyf/huashu-design 装插件版。

 3.4 的八条界面范式和耗时数字都是作者自述，样张好看不等于你的题材一次到位，六个候选挑三版的环节别跳过。生图依赖你环境里的图片服务或自备 API，导出 PDF 会借用本机 Chrome 或 Edge。装完先自检子目录，缺文件时表现会很怪。

适合谁：经常要出原型、PPT、小红书图又不想每回从零调审美的人。它的价值在把「先看样张再选方向」做成流程，而不是替你做决定。
