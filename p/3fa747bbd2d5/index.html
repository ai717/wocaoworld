GitHub 免费仓库 11 月爆火 10 个：本地配音到 AI 画图全覆盖

 

一条推文引爆的 10 个仓库，星数到底水不水

X 用户 @abir35627 最近发了一条清单，列出 GitHub 上 “本月爆火的 10 个免费仓库”。帖子自带星数全是旧快照，我按 2026-11-08 的 GitHub 实测快照重新核了一遍：VoiceStudio 104,104 星、ppt-master 74,611 星、gods-eye-view 63,446 星、REA 441,611 星、diagram-design 65,717 星、paperclip 112,090 星、mattpocock/skills 317,925 星、ECC 299,287 星、andrej-karpathy-skills 230,682 星、claude-mem 114,596 星。其中后 4 个原帖归为一组 “让 Claude Code 更好用”，本文合在一起讲。VoiceStudio、REA、paperclip 本站已有专文，文末一句话带过。

ppt-master：把 PDF 扔进去，吐出带动画、数据图表、旁白的原生 PPT

ppt-master v6.8.0（10 月 30 日发布）不是那种生成一堆截图拼凑的玩意儿，它直接输出 .pptx，形状、动画、数据图表、Speaker Notes 全保留，MIT 协议随便商用。核心逻辑是：LLM 先把长文档拆成大纲，再按母版逐页生成 XML，最后打包成 Office Open XML。按官方介绍，它直接输出 .pptx 而不是截图拼凑；中文特殊字体需要自己嵌入，否则在别人机器上可能回退成默认字体。星数 7.4 万，属于能直接上手用的品种。

gods-eye-view：浏览器里的间谍卫星，实时飞机、船舶、地震、公共摄像头全叠加

gods-eye-view 把 ADS-B 飞机、AIS 船舶、USGS 地震、全球公共摄像头流全塞进一个 Three.js 3D 地球里，还能语音指令 “把镜头飞到东京湾”。8 月曾登顶 GitHub Trending 日榜周榜。许可证存疑：GitHub API 返回 Other，多家第三方称 MIT，成稿以仓库 LICENSE 文件原文为准、不直接写 MIT。前端纯 JavaScript，部署丢静态托管即可，但数据源全靠公开 API，高峰期飞机轨迹会掉帧、摄像头流 403 概率高，适合做可视化大屏演示，别指望做关键任务监控。

diagram-design：拒绝 Mermaid 糙图，45 种图型输出自包含 HTML+SVG 可直接改色、改布局

diagram-design 定位 “AI 画图技能”：给一段文案或品牌色，它吐出单文件 HTML，内嵌 SVG、CSS、JS 零依赖，浏览器打开就是成品，想改哪儿拖进 Figma 或手写 CSS 都行。README 现写 45 种图型（帖子写 44 种），覆盖流程图、架构图、用户旅程、数据看板。MIT 协议。按官方介绍，它按文案与品牌色输出单文件成品，改色、改布局都在浏览器里直接改，不用再走 Mermaid 先渲染再手动微调的老路。短板是复杂交互图（如可钻取的桑基图）还得自己补 JS，但作为 “可交付的设计稿” 起手式已经顶格。

Claude Code 四件套：技能库、脚手架、Karpathy 经验、跨会话记忆

原帖把后 4 个仓库归为 “让 Claude Code 更好用”，确实是一套组合拳：

  • mattpocock/skills —— Matt Pocock 日常真用的 .agents 目录直接拷出来，31 万星证明大家缺的不是模板而是 “有人帮踩过坑的模板”。Shell 脚本、MIT 协议，拿来即用。
  • ECC —— 智能体脚手架性能优化系统，主打 技能、直觉、记忆、安全、研究优先开发，兼容 Claude Code、Codex、Cursor、OpenCode。官网 ecc.tools，JavaScript、MIT，29.9 万星说明 “配置地狱” 是共性痛点。
  • andrej-karpathy-skills —— 单个 CLAUDE.md 提炼 Karpathy 关于 LLM 编程翻车点的 4 条规则，纯 Markdown、无许可证声明，引用时注明未声明开源协议。23 万星全靠 “Karpathy 背书”，内容密度极高，建议打印贴显示器边上。
  • claude-mem —— 跨会话持久记忆：记录每轮做了什么，AI 压缩后注入下一会话。官网 claude-mem.ai，TypeScript、Apache-2.0。解决了 “新会话等于失忆” 的硬伤，11.4 万星印证刚需。

四个仓库链路清晰：skills 给现成指令、ECC 给工程化骨架、Karpathy 给避坑心法、claude-mem 给长时记忆，串起来就是一个 “会越用越顺手” 的 Claude Code 工作站。缺点是全靠自行组装，没官方整合包，新手得自己串联配置文件。

一句话带过已有专文的 3 个重量级选手

VoiceStudio（debpalash/VoiceStudio）本地免费版 ElevenLabs，646 种语言全程离线、Python、AGPL-3.0、默认语音模型权重 CC BY-NC 非商用、官网 voicestudio.sh，本站已有专文详测；REA（morluto/rea）无源码逆向分析原生二进制、TypeScript、MIT、10.9 万 fork、10 月初一周从不到 1 万冲到 32 万+，本站已有专文拆解；paperclip（paperclipai/paperclip）把 AI 智能体当公司管、组织架构/目标/预算/审批全有、TypeScript、MIT、6,512 个 open issue 提醒别盲目上生产、注意同名坑 Spark-Mojo/paperclip 不是官方，本站已有专文实测。

别只看星数，看协议、看维护、看能不能离线跑

这 10 个仓库有 7 个 MIT/Apache-2.0 随便商用，VoiceStudio AGPL-3.0 且模型权重非商用、gods-eye-view 许可证存疑、Karpathy 仓库无协议声明 —— 拿去做产品前先读 LICENSE。离线能力上，VoiceStudio 全程离线是卖点，ppt-master 在本地生成文件；gods-eye-view 的数据源则全靠公开 API，高峰期会掉帧。下个月榜单大概率又变，但 “协议清晰、维护活跃、离线优先” 这三条筛选标准不会过时。
