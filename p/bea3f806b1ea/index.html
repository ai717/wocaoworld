ArtCraft 爆火：AI创作IDE 不再是提示词输入框，先搭场景再出图

几天 2.8 万 star：这个 AI 图像工具换了个打法

最近刷 GitHub Trending 的人，大概率被 ArtCraft 挡住过——本周总榜前三，单日新增几千 star，截至发稿仓库已经攒到 2.8 万。团队给它的定位是 “intentional crafting engine”，口号就一句话：The IDE for artists。翻译成人话：它不打算再做一个提示词输入框。

玩 AI 出图久了都有体感：提示词写得越长越像许愿。想让人物站在画面左三分位、镜头略低仰拍、前后景怎么分层，全靠在文字里跟模型反复拉锯，抽卡抽到心梗。ArtCraft 把流程整个反过来。

不是 prompt 框，是给 AI 生成套一层创作环境

它的核心思路是 README 里那句 Build the scene before you generate it——先搭场景，再生成。你在 2D 画布和 3D 视图里把戏排好：图片转成可摆位的 3D mesh，角色摆好姿势，相机架好角度，最后才按下生成。具体能干的事看仓库演示：

  • 3D 合成：背景、前景、道具分层摆在三维空间里出深度；Image to Location 能把虚拟演员放进同一个房间，连拍多组分镜。
  • 角色姿势与身份迁移：先用一个人偶定死姿势和机位，再把你的角色身份套上去，长相、位置、动作分开控制。
  • 场景分镜加 kitbashing：组合现成 3D 资产包调机位、摆物体、控景深，把影视 previs 的流程搬进了出图工具。

模型层它不锁死自己一家：仓库里挂着一份 62 个模型的目录，图像侧有 Nano Banana Pro、GPT Image、FLUX、Seedream，视频侧覆盖 Seedance、Kling、Veo、Sora，外加 Suno 的音乐和 Hunyuan3D、Tripo 这类网格模型，外部还接了 Midjourney、Grok、World Labs。整个桌面应用用 Rust 写的，Windows 和 macOS 有 stable release，Linux 得自己编译，协议是 MIT 与 Apache-2.0 双协议。仓库在 storytold/artcraft，下载走 官网。

为什么这事现在值得讲

拿节点式 ComfyUI 对照一下就明白它在挤哪块生态位。ComfyUI 自由度拉满，管线想怎么拼怎么拼，代价是折腾：连节点、管采样器、调尺寸链，美术同学进去五分钟就想退出来。ArtCraft 走的是收敛路线——把编排折叠成可视化的 3D 场景工具，用一点自由度换确定性。

prompting 和 crafting 的差别就在这：前者你对着屏幕许愿，后者你在片场导戏。做影视 previs、广告分镜的人对先摆相机再出图几乎是刚需，插画师最头疼的人物一致性和构图控制，恰恰是提示词永远写不明白的部分。这波 star 暴涨，本质上是社区对提示词彩票终于不耐烦了。

冷静评述：热度之外先泼两盆冷水

第一盆：开源的是 IDE 外壳和工作流，背后那 62 个模型绝大多数是各家云 API，出图要付调用费，star 高不等于白嫖到底。第二盆：3D 编排有学习曲线，得懂一点场景摆位和相机语言，纯靠提示词吃饭的用户上手有门槛。

另外项目刚冲榜，README 里好几个预览还标着 coming soon，Linux 只有源码编译路径。建议先下个桌面端摸两天画布，确认它聚合的模型和你手头的订阅对得上，再决定要不要深度投入。
