ClashMac 评测：这款 macOS 双代理工具凭什么火出圈？

在 macOS 代理工具赛道沉寂许久后，ClashMac 突然杀出重围，成为近期 GitHub 与电报群中讨论度最高的网络工具。这款专为 macOS 打造的工具，不仅颜值在线，更把双代理模式——系统代理（HTTP/SOCKS5）与增强模式（TUN）——直接做成了独立开关，可单独或同时启用，直击开发者与高级用户的碎片化代理需求。

ClashMac 的双代理模式到底强在哪？

传统代理客户端往往只提供一种工作模式，用户要么全局代理拖慢内网访问，要么 PAC 规则复杂难维护。ClashMac 的双模设计打破了这一僵局：系统代理处理常规 HTTP/SOCKS5 流量，轻量且兼容性好；而增强模式基于 TUN 虚拟网卡，能在内核层接管所有流量，实现真正的全局无感代理。两种模式可任意组合，既能单独开启系统代理保活内网连通，又能同时启动 TUN 覆盖虚拟机、终端等非代理应用，无需反复切换配置。

颜值方面，ClashMac 采用极简 macOS 原生风格，状态栏图标、流量面板、规则编辑界面的完成度极高，完全不像一个早期开源项目。据体验者反馈，其资源占用控制得当，即便在 M 系列芯片上长时间运行，CPU 负载也保持在极低水平。

项目已开源，仓库地址：https://github.com/666OS/ClashMac。目前仍未发布正式版，但据称功能已足够日常使用，社区活跃度正在快速攀升，对于追求原生体验的 macOS 用户来说，ClashMac 无疑值得持续关注。
