斯坦福CS329Z免费公开课：手写Agent骨架含Claude Code原理

 

开头先划重点：这不是Claude学院那种「教你用产品」的认证课

今天刷到 Anthropic 官方学院免费课的同学请注意：那篇是厂商教你用自家工具、考完发证书的「上手向」内容。而这篇要讲的 Stanford CS329Z: Engineering AI Agents，是斯坦福大学 2026 秋季首开的研究生硬核课（3 学分），讲师 Diyi Yang、Michael Ryan、John Yang 直接把讲义、阅读清单、课程表全扔官网，视频更是从 2026-11-10 起在 Stanford Online YouTube 频道 每日更一讲。核心区别只有一条：这门课不教你调用框架，逼你从零手写 Agent 骨架——包括 Claude Code、Codex 背后那层 Harness 到底怎么声明工具、解析回复、执行命令、压缩上下文。

发生了什么：一门全新研究生课「破壁」了，视频正在陆续上线

课程周期 2026-09-23 至 12-02，每周一、三太平洋时间 13:30-14:50，共 19 讲。模块覆盖 Agent 基础、RAG、工具调用/函数调用/MCP、框架与编排、Agent 设计模式与脚手架、记忆与多智能体系统、优化、数据、评测、LLM-as-Judge、安全与护栏、编程 Agent。原本视频锁在校内 Canvas，直到 2026-11-10 Michael Ryan 发推（原推）宣布公开，首讲《What Are AI Agents? Agentic Systems Explained》已上线（链接，2026-09-23 录制，Diyi Yang 主讲）。截至 2026-11-13 仅前几讲可看，后续每日更一讲，切记别信「全套已出」的标题党。

为什么重要：作业一逼你「禁用一切框架」从零造轮子

这才是白嫖党最该关注的硬货。作业一《Building an Agent Harness》（117★，MIT 协议，2026-09-30 建仓）明文要求：禁用一切 agent/LLM 框架。Part 1 要你基于真实企业邮件存档，裸写四条 LLM 流水线——邮件优先级分类、每日摘要、手写 BM25 检索、多跳 RAG 问答；Part 2 给虚构公司 Cardinal Energy 写一个带终端沙箱、上下文压缩、跨会话记忆、人工批准/否决/重定向、护栏的助手。满分 118 分（88 分自动测试 + 30 分两篇设计说明），其中 48 分是无模型调用的确定性测试，零成本可跑。讲师实测做模型调用部分需自备 OpenRouter API Key，5 美元以内搞定。作业二（26★）则聚焦评测体系。官网课程表只列 HW1/HW2 两份作业（Bulletin 写三份以官网为准）。

好在哪：零框架硬核、自动评分白嫖、真实数据不造假

  • 真·从零造轮子：不许用 LangChain、AutoGen、CrewAI 任何封装，连工具声明、回复解析、命令执行、上下文管理都要亲手写，这才是看懂 Claude Code 原理的唯一路径。
  • 自动评分即时反馈：GitHub Actions 跑测试，48 分确定性测试本地就能过，不用等教务审核，想刷分随时推。
  • 数据来自真实业务：Part 1 用的企业邮件存档非合成数据，手写 BM25 与多跳 RAG 的坑（分词、分块、召回阈值）全是生产级痛点。
  • 沙箱与护栏落地：Part 2 强制实现终端沙箱、人工介入回环、跨会话记忆压缩，这些才是把 Demo 变产品的关键工程细节。

短板在哪：门槛高得离谱、视频未全出、拿不到学分证书

  • 先修卡死普通人：官方要求 CS224N/224V/CS336 或同等水平、扎实 Python、调用过 LLM API。零基础想「跟着视频学」大概率卡在作业一 Part 1 的 BM25 手写与 RAG 多跳逻辑上，别问我怎么知道的。
  • 「免费」≠ 拿证/拿学分：选课拿学分不对校外开放，有无证书未核实，标题正文别暗示能拿斯坦福证书。
  • 视频进度看天吃饭：截至成稿日仅前几讲上线，后续每日更一讲，想系统刷完得等到 12 月初。
  • 「手写 Claude Code」是比喻：作业写的是 Harness 骨架，不是复刻 Claude Code 本体，正文第一时间澄清，别被标题党带偏。

怎么蹭这波课：别盲目跟风，先自测 Python 与 LLM API 实战力

如果你已经会熟练调用 OpenAI/Anthropic API、能裸写异步 HTTP 客户端、懂基本的向量检索与提示工程，直接克隆 assignment1-harness 跑测试、补设计文档、再按课程表追视频填坑，性价比极高。如果你还在纠结「requests 还是 httpx」、不知道 BM25 公式长啥样、从未处理过上下文窗口溢出，建议先啃完 CS224N 或 CS336 公开资源再回头。白嫖名校研究生课的前提是：你得有资格坐在教室里听得懂，而不是只捡现成轮子转转。
