Craft Anything：一周 1.7 万星，让 Claude 照着重做

 

一周 1.7 万星：一个指着成品让 AI 重做的 Rust 引擎

2026 年 11 月 6 日实测，Craft Anything 仓库已经拿下 17,553 Star、3,205 Fork，这还是个 10 月 31 日才创建、上线一周就推了 4 个 Release 的早期 alpha。背后团队是 ArtCraft，之前开源过 PhotoCraft、FilmCraft 等一整套对标 Adobe 的开源应用，这次直接把野心写在 README 里：给它一个网站、App 甚至游戏，让编程 Agent 照着重做一个。核心引擎是纯 Rust 写的，README 里写着 320 个工具（引擎层 300 个，剩下的是 AI 与安装层），每个工具同时是一条 CLI 子命令和一个 MCP 工具。先说清楚一点：它本身不带模型、也不托管推理，检查目标不需要 AI，真正写代码的活交给装在你本机的编程 Agent。

四步走完一次重建：先看、再造、再比对、再改

整个流程只有四步，每一步的产物都会落盘。Study 先 inspect 原版：页面在各个宽度下的样子、代码、文件、运行方式，每个结论都有证据支撑。Build 让编程 Agent 按你的要求从头建一个新项目，语言、框架或游戏引擎可以指定，不指定就用默认。Check 把造出来的东西跟原版逐项比对：网站按 1440、768、390 三档宽度逐页截图比对，给出每一页有多像；游戏跑自己的自测，App 跑起来看。Ready 打开、试玩或预览结果，不满意就接着改，一轮轮逼近原版。最常用的两条命令是 craft-anything-cli rebuild https://example.com "Recreate this website" 和自检用的 craft-anything-cli doctor，后者会检查安装、Agent 登录态与引擎是否就绪。每个项目文件夹里都留着 craft.json（请求、目标、状态与历史）、capture/（从目标录到的东西）、app/（生成的项目）、checks/（每次与原版的比对结果）这些家底，方便回头查账。

清洁室是默认项，Deep 模式得手动开

这是最值得先搞明白的一组开关。默认的 Clean room 模式什么都不读：不读原版代码、不读文件、不读页面源码，只看访客能看到的东西——截图、可见文本、实测的布局颜色字体间距、打开过的菜单。想读代码和文件就得手动开 Deep 模式：在标题栏或设置里切，或者 settings_set deep_mode true，单次 CLI 加 --deep。Deep 模式下全部工具上阵，内置的反汇编、反编译、调用图分析都会用上，本机装了 Ghidra 也会调用它。README 特意提醒：清洁室只是“它提供什么、拒绝什么”的一条规则，不是操作系统级沙箱，跑起来的编程 Agent 依然以你的身份行动，能读什么、写什么、跑什么取决于 Agent 自己的权限。

账单不在它这儿，在你的 Claude 套餐里

代码是 MIT 或 Apache-2.0 双协议，软件本身不收钱。但重建过程调用的是你本地已登录的 claude 程序，Token 全走你自己的 Claude 套餐额度，用 Opus 还是 Sonnet、返工多少轮，钱包说了算。Claude Code 是第一个支持的构建器，Codex 适配器写好了但还没在真实安装上验证过，GitHub Copilot 可以走 ACP 接入，Gemini CLI、Qwen Code、opencode、goose、Hermes、Maki 这些 ACP Agent 里只有 Maki 实测跑通过。游戏那头覆盖 12 个引擎的识别：Unreal、Unity、Godot、Source、GameMaker、RPG Maker、Ren’Py、MonoGame、LÖVE、CryEngine、Cocos、Cube，Unreal 和 Godot 的游戏用原引擎重建，其余走 Unity。源码构建要 Rust 1.97 或更新，Release 页提供 Windows、macOS、Linux、FreeBSD 安装包与 Web 版。它还处于早期 alpha：API Key 构建、非 Claude 构建器、App 与游戏的行为检查都只做到“搭好未实测”，部分引擎工具只在替身样本上测过。

上线时间点很微妙：Anthropic 刚说完不许复刻游戏

madrobot 的报道提到，Craft Anything 11 月 1 日上线，距离 Anthropic 在 10 月 30 日要求 Claude Code 不再复刻已有电子游戏只隔了两天。两件事有没有因果别瞎猜，但 README 里的责任使用条款摆得非常明确：只用于自己拥有或获准检查的软件，不绕 DRM、登录与反作弊，重建只复现布局、样式与行为，Agent 被要求不复制 logo、照片与文字，除非确认你拥有它们或拿到了许可。想玩的先跑 craft-anything-cli doctor 自检，Rust 版本、Claude 登录态、引擎状态哪个不通先补哪个。别指望开箱即用，但如果你手头有“想看懂对方怎么实现、又不想人工读混淆代码”的需求，这大概是目前最像标准化流程的答案，前提是先把自家 Claude 额度充饱了。
