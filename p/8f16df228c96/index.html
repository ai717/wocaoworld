Godot助手接入：把Claude塞进编辑器只需63MB

别再手动复制粘贴代码了，AI该直接进编辑器改场景树

写Godot游戏时最烦什么？不是逻辑难，是改个节点属性、重构个脚本、排查个报错，全得在编辑器和聊天窗口来回横跳。Godot-MCP Community Edition 10月25号刚发社区版 1.0.0，作者 Unsigned Exe Studios 走 MIT 协议，Windows 版压缩包才 63MB，.NET 8 自包含二进制，解压双击就能跑，连 Python 运行时都省了。核心思路很简单：在编辑器里跑个 WebSocket 服务（ws://127.0.0.1:6505），桌面端做个 Hub，把 Claude Desktop、LM Studio、Ollama 的 MCP 配置一键同步进去，AI 直接对着你的项目文件、场景树、甚至编辑器截图干活。

双形态启动：想看面板双击 WPF，想挂系统服务跑无头 CLI

解压出来俩可执行文件：GodotMCP.Panel.exe 是 WPF 面板，浅色/深色主题随系统，顶部一排按钮——Sync Config 一键把 claude_desktop_config.json、LM Studio 和 Ollama 的 mcp.json 全刷进去；Start Server 启动本地回环 WebSocket。另一个 GodotMCP.Cli.exe 走 stdio JSON-RPC 2.0，适合塞进 systemd 或 Windows 服务里后台跑，完全无界面。两种形态共用同一套核心库，端口固定 6505，仅绑定 127.0.0.1，零遥测、零上报。第一次双击面板 Windows SmartScreen 会拦，点“更多信息 → 仍要运行”就行，毕竟没买代码签名证书。

25 个工具五组全覆盖：从启停编辑器到 AI 看截图改 Bug

工具分五组，名字直观得像 API 文档：引擎生命周期组有 godot_start_editor、godot_stop_editor、godot_get_editor_version；项目文件组能 godot_read_file、godot_write_file、godot_list_files；脚本改写组直接给 godot_rewrite_script、godot_format_code；场景树节点组最实用——godot_get_scene_tree 拿完整树、godot_get_node 查单节点、godot_set_node_property 改属性、godot_call_node_method 调方法；诊断与 AI 视觉组压轴：godot_get_diagnostics 抓编译错误、godot_get_editor_screenshot 截当前视口图喂给多模态模型，让 Claude “看图改 Bug” 变成字面意思。实测让 Claude “把 Player 节点的 gravity 改 9.8、顺手把跳跃逻辑重构成状态机”，它真调用 godot_set_node_property + godot_rewrite_script 干完了，Diff 面板里逐行确认再应用，比人手敲快得多。

翻车现场：防火墙、端口冲突、Godot 版本没对上

① 企业级杀毒/防火墙把 6505 端口当后门拦了 → 加入例外或临时关杀毒测通再开。② 已经跑别的 MCP 服务占了 6505 → 改源码重编或杀掉占用进程，官方暂不支持配置文件换端口。③ Godot 编辑器版本与工具内置协议版本对不上（目前锁 Godot 4.3+）→ 更新编辑器或等作者适配。④ LM Studio / Ollama 本地模型上下文窗口太小，塞场景树 JSON 直接截断 → 换大上下文模型或手动精简树。⑤ godot_get_editor_screenshot 返回黑屏 → 编辑器最小化或在后台，得把窗口激活到前台再截。

别把它当万能外挂：本地模型推理慢、大项目跑起来也可能吃力

实测把 2000 行 GDScript 扔给本地 7B 模型重构，LM Studio 跑 15 秒才吐完首 token，Ollama 暴力量化版更慢；Claude Desktop 走 API 快但得联网且算 token 钱。场景树 JSON 一旦超过模型上下文窗口，工具直接报错截断，作者建议先用 godot_get_scene_tree 拿扁平化路径列表，再按需 godot_get_node 取细节。最大坑是：AI 改文件走 godot_write_file 直接覆盘盘，Godot 编辑器里没有“撤销 AI 操作”按钮，只能靠 Git 回滚，建议先 git commit -am 'pre-AI' 再放 AI 进场。另外 godot_call_node_method 只能调无参或基础类型参数的方法，复杂类型（Array、Dictionary、自定义 Resource）还得自己在脚本里包装静态桥接函数。社区版定位是“把 AI 拉进编辑器干脏活累活”，架构决策、核心玩法原型还是得人来把关。
