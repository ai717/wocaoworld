不用视频模型也能拍片：Lemo 99种影片风格全靠代码手搓

 

99种风格，每种都是一支代码拍出的片子

拍片不一定非要视频模型。Lemo-Opuscar 是 Lemomo 给 Claude Code 做的风格工具箱：99 种影片风格，分 15 类——剪辑纪录、水彩油画、白板手绘、传统手艺、版画、平面字体、线稿图解、卡通、游戏、胶片质感、屏幕界面、光线线条、3D 微缩、仪器证据、数据地图。每种风格都是一份风格提示词，加一支完全用代码做出来的演示短片。画布和 WebGL 页面逐帧渲染，配乐是免费采样库做的原创曲，旁白是 TTS——没有视频生成，没有素材库。11 月 12 日刚加了 33 种新风格，从 66 种涨到 99 种，星数也跟着涨到了 16,857。

举个例子：水彩风格的片子，是一笔一笔画出来的；霓虹灯管风格，是光在画布上走出来的；像素 RPG 风格，整支片子都是游戏画面。画廊里每种风格都有自己的页面，带剧照、适合什么题材、还有一句能直接抄走的提示词。

三句话讲清它怎么拍：挑风格、看演示、开口说

用法就三步。挑风格：在画廊里按画面样子翻，或者搜你要做的东西——解说、发布、新闻、MV。看演示：每种风格都有一支代码做出来的短片，先看片再决定。开口说：装好 Skill 之后，一句话就行：“Make a film in the Neon Tubes style about the coffee farm my family runs.”想加长度、旁白、自己的照片音乐，都可以在一句话里写上。

拿不准就空手进：装好之后只敲 /lemo-opuscar:lemo-opuscar，它会先问你语言，再问你要干什么——用现成风格拍一支、把某个风格改成你自己的，或者用你存好的风格拍。开拍前它还会问一次：故事板要不要先看（说要，它就先停下来给你看关键镜头，确认了再继续）。

装一次：两条命令进 Claude Code

两条命令：claude plugin marketplace add lemomo-ai/lemo-opuscar，claude plugin install lemo-opuscar@lemolab。第一次用，它会把指南、工具和风格提示词下载到 ~/lemo-opuscar，所有片子共用；每支片子的工程，从源码到成片，都放在你启动的那个文件夹里。注意：这是给 Anthropic Claude Code 做的插件，不是 Meta Muse；官方说 Claude Fable、Opus、Sonnet 都能用，effort 开到 high，其他模型可能复现不好。

一支片子30到60分钟：成本账先算清

一支片子，Agent 要跑 30 到 60 分钟，Token 花得不少。前置条件：Node 20+、ffmpeg 7+、Python 3.11+（Ubuntu 24.04 自带的 ffmpeg 6.1 太老，得用静态构建版）。默认输出 1920×1080、24fps，其他尺寸可以提要求。有三种风格要自带生图工具：Manga Panels、Text Flash Cuts、Comic History Cartoon（标了 ✦ 的那三个），没有的话开不了机，其他 96 种都不需要。

想把某个风格改成你自己的也行：品牌色、logo、人物、频道调性，改库里的风格或者从空白页起一个。最多一轮改五处，改完先给你看一帧真的效果图，再出 15 到 30 秒的演示片，满意了才存下来。存下来的风格放在 ~/lemo-my-styles/ 里，库更新、重装都不会动它。

2.0.0 改授权：文档非商用，代码仍 MIT

2.0.0 版改了授权，写清楚点。代码还是 MIT，没变。文档——每种风格的 STYLE.md 和各份指南——改成 CC BY-NC 4.0：可以非商业分享和改编；另外作者多给了一条许可：用它们拍自己的片子，商业片也行；但其他商业用途，比如把风格拿去卖、塞进付费产品或服务里赚钱，要另外买商业授权，联系 lemomo.studio@gmail.com。演示短片、海报、剧照是 CC BY 4.0，可商用，须署名。用库拍出来的片子归你，商业片也行，不用署名。2.0.0 之前发布的版本和从它们 fork 的分支，保留原来的授权。作者在 README 里写了改的原因：风格库被人重新包装，塞进付费产品里卖了。

代表作可以看 OPUSCAR 98：一支 6 分 31 秒的片子，98 部奥斯卡最佳影片，每部都用一种贴合的风格重画，全是 Claude Opus 5.5 写代码做出来的。

老法师避坑提醒：授权只认 2.0.0 这一版——文档拿去商用要另外买授权，但你拍出来的片子完全归你；别拿其他模型硬套这些风格，官方明说只有 Claude 系能复现好；一支片子 30 到 60 分钟加不少 Token，批量开片之前先跑一支小的试成本。
