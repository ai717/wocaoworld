1.6 万星的闲鱼监控雷达！AI 替你 24 小时蹲好价

 

蹲闲鱼最气人的三件事

第一，好价都是半夜上架的，你睡着的时候被人捡走了。第二，关键词筛来筛去，包邮的、成色好的、当面交易的，眼睛看花也翻不完。第三，蹲了三天终于刷到一台成色不错的 MacBook Air，点进去一看：已售出。闲鱼捡漏这件事，拼的从来不是眼光，是谁先看到。

所以当 ai-goofish-monitor 今天登上 GitHub 日榜时，一点都不意外：16,446 个 star，2,846 个 fork，MIT 开源——它干的就是一件事，让 AI 替你 24 小时蹲在闲鱼上，好价一出现立刻喊你。

它是什么：1.6 万星的捡漏流水线

这个项目基于 Playwright（浏览器自动化）+ AI 多模态模型，自带完整的 Web 管理后台。工作流程是条流水线：按你的任务搜索商品 → 发现新上架 → 抓商品详情和卖家信息 → 下载商品图片 → 丢给 AI 做深度分析 → AI 觉得值才推送通知 → 全部存进 SQLite 留档，连价格历史都记下来。

它和普通爬虫脚本的区别在于“AI 判断”这一步：你不用写复杂的筛选规则，直接用自然语言描述需求——比如“帮我盯 14 寸 M4 MacBook Air，电池循环 100 以内，价格低于 7000 就喊我”——后台会异步生成分析标准。多任务可以并发跑，每个任务独立配关键词、价格区间、筛选条件和 AI Prompt，互不干扰。

Docker 一把梭：四行命令跑起来

部署是真省心，官方推荐 Docker，一把梭：

git clone https://github.com/Usagi-org/ai-goofish-monitor && cd ai-goofish-monitor

cp .env.example .env

docker compose up -d

镜像里已经内置了 Chromium，不用在宿主机上折腾浏览器。起来之后打开 http://127.0.0.1:8000 就是 Web UI。注意 .env 里有三个必填项：OPENAI_API_KEY、OPENAI_BASE_URL、OPENAI_MODEL_NAME——模型必须支持图片输入，因为 AI 要看商品图做判断。用 OpenAI 兼容接口就行，愿意的话也可以接本地模型省 API 钱。

第一次用：先交登录态，再让 AI 定标准

闲鱼的商品页要登录才能看全，所以第一步是交登录态：用项目提供的 Chrome 扩展导出闲鱼登录态 JSON，粘贴到后台的“闲鱼账号管理”里，会存成 state/acc_1.json。多账号可以轮换着用，还能配代理池，触发风控就自动切换重试。

然后创建任务有两种姿势。AI 模式：填“详细需求”，提交后弹个进度窗，后台慢慢生成分析标准，适合“我也说不清规则但我知道什么是好价”的场景。关键词模式：直接写关键词规则，秒建任务，适合目标明确的硬通货（比如某款显卡、某个绝版手办）。筛选条件很细：包邮、新发布时间范围、省/市/区三级区域，还能配 Cron 定时跑——比如只在每天早晚高峰各扫一轮。

通知渠道给得足：ntfy.sh、企业微信、Bark、Telegram、Webhook，手机、电脑、群聊，怎么顺手怎么来。

别把它当印钞机：三条红线

第一，遵守闲鱼的用户协议和 robots 规则，别把请求频率拉太高——号被限制了哭都没处哭，项目 README 里专门写了这条。第二，Web UI 默认账号密码是 admin/admin123，跑起来第一件事就是改掉，别把后台裸奔在公网上。第三，AI 的判断是辅助，不是圣旨：卖家精修图、暗病描述，AI 也可能看走眼，大几千的单子下手前自己再过一遍。

另外说句公道话：这项目 2025 年 7 月就创建了，不是今天刚出生的。它今天重新冲上日榜，说明的恰恰是另一件事——“AI 替人蹲活”这种需求是真刚需，经得起时间考验。原文参考：ai-goofish-monitor GitHub 仓库与中文文档。
