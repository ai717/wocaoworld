GPT-5.5 Instant 发布：更智能、更清晰、更个性化的 ChatGPT 体验

OpenAI 已将 ChatGPT 的默认模型更新为 GPT-5.5 Instant，这一升级在事实准确性、响应质量和个性化方面带来了显著提升。据内部评估显示，在高风险领域（如医学、法律和金融）中，幻觉现象比 GPT-5.3 Instant 减少了 52.5%；在用户标记的困难对话中，不准确声明减少了 37.3%。此外，模型在视觉推理、数学和科学任务上也有改善，回答更加简洁紧凑，减少了冗余和格式过度，并更善于利用聊天历史、文件和 Gmail 提供个性化回应。

新模型即日起向所有 ChatGPT 用户推出，并作为 API 的 chat-latest。付费用户的 GPT-5.3 Instant 可再使用三个月。个性化增强功能率先向 Plus 和 Pro 用户开放，后续将覆盖更多计划；新的记忆来源控件让用户可以查看和管理用于个性化回复的上下文。
