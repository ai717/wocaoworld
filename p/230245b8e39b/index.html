LibreGet下载器：1800个站点一个框全拿下

 

先认清真身：LibreGet就是帖子说的OmniGet

原帖 说的开源多平台视频下载器 OmniGet，1800 多个站点一键拿，查仓库时先遇到一个岔路：GitHub 上同名的 tonhowtf/omniget 是个 MCP 服务器，不是下载器。描述最接近的真身是 OpenSelena/libreget，也就是 LibreGet——仓库话题标签里就挂着 omniget，名字应为同一项目的曾用名或转述名。当前约 7200 星，GPL-3.0 开源，Tauri 2.0 加 Rust 与 Svelte 写的桌面应用。

它能下什么？一句话：课程、视频、音乐、图片、文件全包。原生支持 38 个课程平台（Udemy、Hotmart、Coursera、Skillshare 等），视频音频覆盖 YouTube、Instagram、X、TikTok、抖音、B 站、Twitch、Vimeo、Bluesky、Threads、Pinterest，图片画廊走 gallery-dl 覆盖 250 多个站，剩下的交给 yt-dlp，合计约 1800 个站点。下载完还能接着干活：内置播放器、PDF 阅读、音频转写、格式转换，158 个工具分 25 类，连 Telegram 与磁力链接都接。

粘贴链接就开下：课程、短视频与批量三路

上手只有三步：去 Releases 页按系统下安装包（Windows 有安装版与便携版，macOS 分 Apple Silicon 与 Intel，Linux 有 deb、rpm 与 AppImage），打开后粘贴链接，工具自动识别站点、给出标题、缩略图与清晰度选项，点回车就开下。断点续传、失败重试、按站点自适应并发都有：YouTube 最多 16 路并行分片，被限速的站点自动降并发。

三条常用路：买过的课程想存本地防下架，用课程插件整课下载、断点续看；短视频与播客批量存档，粘贴一堆链接或丢一个 .txt 文件批量下；已登录内容走浏览器扩展同步 Cookie，不用手动导出。命令行用户也能装：

winget install -e --id OpenSelena.LibreGet

brew install --cask OpenSelena/tap/libreget

剪贴板热键更省事：复制链接后按 Ctrl+Shift+D 直接后台开下，按 Ctrl+Shift+M 只抓音频，YouTube 链接秒变 MP3。

能下不等于能随便下：版权与登录两条红线

先把红线说清楚：LibreGet 能下 1800 个站，不代表每个站的内容都能随便下。买过的课程存本地是合理使用，下载别人付费课程再分发是侵权；公开视频存档学习是一回事，批量搬运再上传是另一回事。工具本身在 README 里写明了隐私立场：yt-dlp 与 FFmpeg 自动安装并校验 SHA-256，不上传你的文件，登录状态只通过浏览器扩展同步 Cookie。

实操上还有两处要注意：首次启动各系统都会弹未签名警告，Windows 点“更多信息”再“仍要运行”，macOS 要跑两行 xattr 与 codesign 命令清隔离属性；Linux AppImage 在 Debian 12 与 Ubuntu 24.04 以上要先装 libfuse2，不然会报缺库。便携模式建一个 portable.txt 就能把全部数据收到 U 盘里带走。

 别把 tonhowtf/omniget 那个 MCP 服务器当成下载器装错了，真身是 OpenSelena/libreget。下载前先想清版权：自己买的课程存本地没问题，搬运分发就是另一回事。首次启动的未签名警告是开源桌面应用的常态，按官方步骤清掉就行，别从不明渠道下“已签名版”。

需要一个“粘贴链接就开下”的下载器、又不想装一堆单站工具的人，LibreGet 值得装一个：免费、开源、1800 个站一个框搞定。
