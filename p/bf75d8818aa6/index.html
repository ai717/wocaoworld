103 个免费无审查模型塞进一个网站：hft.md 目录

 

103 个模型按一张排行榜排好队

hft.md 的无审查模型目录把 103 个免费开源权重收进一个页面，都是去除了安全限制的微调版本，底座覆盖 Gemma、Qwen、Llama、GLM 等主流系列。页面按 UGI 排行榜排序，每个模型都标了无审查智商分、推理分和回答分，榜首是 gemma-4-31B-it-heretic，无审查智商分 65.7。

目录的价值不在数量，在筛选。103 个模型如果只列名字就是垃圾场，hft.md 给每个模型配了统一的卡片：底座来源、参数量、显存需求、Hugging Face 链接、Ollama 命令和 API 入口。想找能跑的模型，先按榜单看一圈，再按硬件筛一遍，比在 Hugging Face 上一个个搜省事得多。

按硬件筛选：先看显存再挑模型

目录最实用的功能是按硬件筛选。18 个模型标注可在笔记本上跑，其余需要云端 GPU。每个模型卡片都写明了显存需求，比如 gemma-4-31B-it-heretic 需要约 21GB 显存或 Mac 内存，Qwen3.5-27B-heretic 约 18GB，70B 级别的模型要 44GB 起步。

挑模型的顺序应该是反过来的：先看自己手里有多少显存，再去榜单里找这个档位分数最高的。笔记本用户重点看 18 个可本地跑的条目，云端用户可以往 70B、123B 的大模型看。显存不够硬上大模型，下载几十 GB 权重之后跑不起来，浪费的是时间和硬盘。

Ollama 一行命令就能跑起来

每个模型都给了开箱即用的 Ollama 命令，比如榜首的模型只要一行：ollama run hf.co/mradermacher/gemma-4-31B-it-heretic-GGUF:Q4_K_M，装好 Ollama、粘贴进终端，下载约 18.7GB 之后就能直接对话。想把它接进自己的程序，页面还给了 Python 示例：OpenAI(base_url='http://localhost:11434/v1', api_key='x')，Ollama 在本地跑起免费 API，代码直接调。

除了 Ollama，目录还给了 LM Studio 的用法和 Colab 免费 T4 的试跑入口。没有本地显卡的人也能先试：Colab 免费 T4 能跑通小模型，确认效果之后再决定要不要租云端 GPU。

这个目录的三处提醒先看完

第一处提醒是站点的出身：hft.md 本身是交易类页面做的，模型描述里带着交易语境，每张卡片都有为交易写的一段话。把它当目录用没问题，把它的描述当评测结论就错了，分数和推荐都要自己再判断。

第二处提醒是权重来源：这些都是第三方微调版本，不是官方原版。跑之前先看模型卡和来源，确认底座和微调者是谁，权重文件从 Hugging Face 的哪个仓库来。来路不明的权重别往生产环境里放。

第三处提醒是用途边界：这个目录只解决找模型的问题，不提供绕过安全限制的操作教程。本文也只介绍目录和用法，不展开任何绕过限制的具体做法。

老法师避坑提醒：无审查不等于无风险，第三方微调权重的来源和训练数据都不透明，跑之前先看模型卡。显存不够别硬上大模型，几十 GB 权重下载完跑不起来，白白浪费时间和硬盘。站内描述带交易语境，别把它当评测结论。
