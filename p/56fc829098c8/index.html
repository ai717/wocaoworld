三站11月2日实测：8家AI编程免费档谁能真白嫖

 

Google Antigravity 把 Claude 全家桶移出了免费档

先看 FreeTierFinder、AppyPie、Metarix 三家第三方情报站 11 月 2 日同日实测：Google Antigravity 个人 $0 档只剩 Gemini 3.8 Flash，Claude Sonnet 4.6、Claude Opus 4.6、GPT-OSS-120b 全部移出免费档。Tab 补全还能无限用，但 Agent 模式按周限流。免费档的潜规则向来如此：好模型留给付费用户，免费档负责养用户习惯。

本文所有价格、额度、模型版本均引用上述三站 2026-11-02 同日实测整理，第三方整理口径，动手前以各家官网定价页为准。

Google Antigravity 的 “静默降级” 最伤人：免费档只剩 Flash，Agent 周限流卡死重度用户

Antigravity 这次操作堪称教科书级 “煮青蛙”：Tab 补全保持无限量留住轻度用户建立肌肉记忆，Agent 模式 —— 也就是真正能干复杂重构、跨文件改代码的能力 —— 按周配额限流。2026-11-02 之前免费档还能蹭 Claude Sonnet 4.6、Opus 4.6、GPT-OSS-120b 三个强模型，凌晨一点模型下拉框刷新，三个选项直接变灰不可选，只剩 Gemini 3.8 Flash 孤零零躺在那里。社区有人抓包发现：Agent 周配额约等于 50-60 次完整对话轮次，超过即报错 “Weekly limit reached, upgrade to continue”。对于把 Antigravity 当主力驱动器的独立开发者，周三周四直接干瞪眼 —— 除非掏钱升级个人付费版（价格至今未公开）。

对比 Kiro Free：同样 50 Credits 起步，但 能跑 Claude Sonnet 4.5。代价是登录门槛：必须用社交账号登录或注册 AWS Builder ID。想当日常驱动器显然不现实，但作为”备胎强模型”插在工具链里，关键时刻救急还行。

GitHub Copilot Free：2000 次补全听起来美，Chat/Agent 共用 Credits 才是真坑

Copilot Free 官方大字报”月 2000 次代码补全”，听起来够用。但注意：Chat 和 Agent 走的是同一池 AI Credits，官方只给了小额度。补全次数看着多，稍微用两次 Agent 对话，额度就见底。含 Copilot CLI 是个惊喜：终端里不用开 IDE 也能调，但同样吃 Credits。Pro $10/月起，对比 Cursor Pro $20/月，轻度用户其实 Free 档先顶着完全够。

OpenAI Codex 免费档是个 “黑盒”：能用 GPT-6 Luna 但额度不公开，随时可能断供

Codex 绑定免费 ChatGPT 账号即可用，桌面端跑 GPT-6 Luna（OpenAI 面向编程微调的新模型），支持 “Quick coding tasks”。问题在于：官方从未公开免费额度上限、重置周期、并发限制。Go $8/月解锁更高配额，但免费档的不确定性太大 —— 适合偶尔改个 Bug、写个脚本，绝不适合作为生产环境主力。免费档随时可能收紧，重要项目别押宝在上面。

JetBrains Junie Lite：IDE 绑定的 “限时福利”，2026 年底前能薅多少算多少

Junie Lite 在 JetBrains IDE / Junie CLI 里直接调用小模型，日常补全、简单重构、写测试几乎无感。活动明确标注截止 2026-12-31，之后是否转正、是否收费、小模型是否升级，全是未知数。如果你本来就全家桶订阅了 IntelliJ IDEA Ultimate、PyCharm Professional，如果你本来就在用 JetBrains 全家桶，顺手开 Junie Lite 是零成本收益；专门为它买 IDE 订阅则不划算。对比 OpenCode：后者 MIT 开源、三端通用、不绑定 IDE，但免费内置模型随时可能下线，重度用量走 Pay-as-you-go，长期看更像 “自带模型的客户端” 而非完整产品。

Cursor 14 天 vs Windsurf 30 天：试用期红利别当永久免费档用

Cursor 14 天 Pro 免信用卡试用，Windsurf (Devin Desktop) 30 天 Pro 试用，试用期内解锁 Pro 功能。但本质是限时试用，非永久免费档，到期后降级，具体规则以官网为准。实测建议：把试用期当 “高强度冲刺期” —— 集中两周/一个月把积压的重构、新项目脚手架、遗留代码清理全跑完，试用结束再评估是否续费。别指望试用期结束后还能白嫖核心功能，大厂不做慈善。

自托管 Cline/Continue：最灵活也最累，BYO Key 约等于 “自己当运维”

Cline、Continue 开源自托管，核心逻辑是 BYO Key (Bring Your Own Key)：你接入任意兼容 OpenAI API 的模型（DeepSeek、Qwen、Moonshot、自建 vLLM 等），Token 成本直接走你的 API 账单。实测跑 DeepSeek-V3 / Qwen2.5-Coder-32B，月均 $1-5 能覆盖独立开发者日常用量。优势：模型随便换、数据不出本地/自建服务器、无厂商锁定。劣势：你得自己搞部署、监控、熔断、Prompt 工程、Context 窗口管理 —— 这本质上是把 “运维 AI 基建” 的活揽自己身上。适合有运维能力、对数据合规有硬性要求、或想长期压低边际成本的团队/个人；纯应用层开发者别碰，调试配置文件调两天不如直接掏 $10 买 Copilot Pro 省心。

按场景选工具：别贪多，认准主力 + 备胎

  • 日常主力（轻量补全+偶尔 Agent）： GitHub Copilot Free 凑合用，Credits 够用则用，不够上 Pro $10/月最稳；Google Antigravity 只做 Tab 补全留着，Agent 别指望。
  • 关键时刻需要强模型救急： Kiro Free 绑好 AWS Builder ID 放工具箱，50 Credits 留着写核心算法、修疑难 Bug 用 Claude Sonnet 4.5。
  • 短期高强度冲刺（重构/新项目/交付）： 先跑 Cursor 14 天，不够再开 Windsurf 30 天，合计 44 天全功能无限用，冲刺结束再决策续费。
  • 全职 JetBrains 全家桶用户： 顺手开 Junie Lite 薅到 2026 年底，活动结束前评估是否转正。
  • 长期低成本、数据不出域、有运维能力： 自建 Cline / Continue + 便宜模型 API，月均 $1-5 最香，但别低估运维成本。
  • 偶尔改改脚本、不想绑卡、不想装插件： OpenAI Codex 网页版/桌面端随用随开，别当主力。

别妄想一把梭哈找到 “完美免费档” —— 大厂免费档的本质是获客漏斗，好模型、高额度、低限制永远留给付费墙内。认清每家的硬约束（模型上限、配额重置周期、登录门槛、试用期截止日），组合拳打法：主力一个稳的、备胎一个强模型的、冲刺期薅试用期、长期看自托管。Google Antigravity 11 月 2 号踢走 Claude 只是开始，Cursor、Windsurf 试用期结束后的定价、Junie Lite 活动到期后的规则、Copilot Free Credits 会不会再缩水，下一个变天随时发生。手里握着两三套可切换的工具链，心才不慌。
