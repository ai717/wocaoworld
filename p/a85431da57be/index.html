Easel自媒体运营智能体：一个人搞定7平台内容矩阵

一个人运营 7 个平台的内容矩阵，账号人设记串、热点永远赶不上、写稿剪辑发稿全靠肝——Easel 就是冲着这个痛点来的。它是浙江大学 REAL Lab 开源的 AI 自媒体运营智能体，把发现、策划、创作、发布、归因串成一条流水线。

Easel 是什么：浙大甩出来的自媒体运营全栈智能体

Easel 是浙江大学 REAL Lab 在 GitHub 开源的项目，采用 Apache-2.0 协议，2026-08-28 建仓，截至 2026-09-28 已有约 1800+ stars、182 次提交，内置 113 个 skills。它基于 OpenClaw Agent 构建，简单说就是：你给它一个账号画像，它负责从找热点到发文到复盘的全流程。

和市面上那些只会写文案的工具不一样，Easel 的野心是做全栈运营：不只是生成内容，而是把运营这件事本身自动化——登录账号、按各平台调性适配内容、真实发布、回收数据再沉淀回去。113 个 skills 就是 113 种可插拔的能力模块，覆盖了运营链条里的脏活累活。

五层工作流：从找热点到数据复盘一条龙

Easel 的核心设计是五层流水线，每一层都有明确产出：

层级 干什么 产出
发现 热点与趋势聚合扫描 每日热点清单
策划 选题、标题、脚本、内容日历 选题库和发布计划
创作 图文、音频、视频、短剧生成 成品内容素材
发布 多平台适配与真实发布 各平台已发布内容
归因 回收数据、复盘效果 沉淀回账号画像

最有意思的是最后一层归因：发布出去的内容数据会被回收，写进账号画像的长期记忆里。跑得越久，它越懂你的账号——这才是智能体和普通工具的本质区别。

7 个平台真发布：小红书到公众号一次配齐

Easel 支持 7 个平台的登录、内容适配与真实发布：

平台 支持情况
小红书 支持登录与发布（有风控警告）
抖音 支持登录与发布
快手 支持登录与发布
知乎 支持登录与发布
B 站 支持登录与发布
微信视频号 支持登录与发布
微信公众号 支持登录与发布

README 明确警告：谨慎自动发布到小红书。平台可能检测自动化操作，存在验证、限流、账号风控风险，建议预览加发布前检查，最好用户确认后手动发布。

大白话翻译一下：Easel 能帮你把内容做到待发布状态，但小红书这块千万别无脑全自动。矩阵号被限流一次，心态直接崩——预览确认再动手，这是官方亲口交代的。

上手三步：克隆、安装、跑起来

  1. 克隆仓库：git clone https://github.com/ZJU-REAL/Easel.git，然后 cd Easel。
  2. 引导式安装：运行 bash setup.sh，脚本自动检查 Python 3.10+、Node.js 22.19+、FFmpeg 和 Playwright Chromium，缺什么一目了然。
  3. 配一个 LLM：在 .env 里填一个可用的大模型即可——可以用 ANTHROPIC_API_KEY，也可以用 OpenAI 或 OpenAI-compatible 服务（OPENAI_API_KEY / OPENAI_BASE_URL），国内的中转 API 也能接。

装好之后，Web 工作台默认跑在 http://localhost:7860，打开就能用。常用命令就五个，记一下：

  • easel web：启动 Web 工作台
  • easel chat：终端里直接对话
  • easel doctor：环境检查，出问题先跑它
  • easel ping：连通性测试
  • easel skill <name> -i “…”：直接跑某个技能

门槛不算高，但也不是纯小白向——本地部署、配 API Key、跑脚本，至少得是个能折腾的技术型运营。

账号画像：人设装进 profiles，一个团队也串不了味

Easel 用 profiles/<名字>/ 目录来存账号画像，包含定位、风格、受众、平台、偏好红线、长期记忆六个维度。画像跨平台、跨会话复用：你在小红书养出的人设，拿到抖音也不会串。

这个设计解决了一个真实痛点：矩阵账号最怕人设漂移，今天 A 风格明天 B 风格，粉丝直接取关。把画像变成结构化配置，智能体每次创作前都先读一遍画像，风格稳定性天然有保障。

适合谁，不适合谁：先想清楚再折腾

  • 适合：一个人运营多平台矩阵的内容创业者；有技术折腾能力的自媒体运营；想批量测试选题方向的 MCN 小团队。
  • 不适合：纯小白（本地部署和 API 配置会劝退）；只想一键爆文的投机党（小红书风控会教你做人）；对内容质量要求极致的头部大号（AI 产出还得人工精修）。

总的来说，Easel 是 2026 年少见的真干活型开源 AI 项目——不是 demo 级玩具，而是把自媒体运营的整条链路都工程化了。约 1800+ stars 的热度说明大家是真需要这么个东西。项目在 GitHub，Apache-2.0 开源，感兴趣直接去围观。
