AI视频流水线补齐：8个GitHub仓库按环节分工一次讲清

 

八个仓库拼成一条视频生产流水线

AI 视频工具满天飞，真正卡人的不是单个模型行不行，而是每个环节都要单独折腾。这组被转发的 8 个 GitHub 仓库，刚好把一条完整生产流水线补齐：从生成、驱动、抠像到合成、字幕，每段都有开源件可用。原始汇总帖在这里：beginnersblog1 的 8 仓库汇总帖。这篇不按工具罗列，按流水线环节讲谁干什么活。

生成环节：三个引擎各管一摊

ComfyUI 是总调度台，用节点连线把生图、生视频的步骤串起来，换模型不用重写流程。Wan2.2 和 LTX-Video 是视频生成引擎，一个偏质量、一个偏速度，本地跑要看显存家底。把它们挂进 ComfyUI 节点图，同一套工作流就能切换引擎出片。

驱动环节：让静态脸动起来开口说话

LivePortrait 负责表情和头部动作驱动，一张照片就能跟着参考视频动。MuseTalk 管口型对齐，喂一段音频，嘴型跟着台词走。数字人短视频的「会说话」基本就靠这两件，本地部署命令大致是 git clone 拉仓库后按 README 装依赖，显卡不够就先用云端试跑再决定要不要本地化。

合成与字幕：最后两公里别掉链子

SAM2 做视频抠像和主体跟踪，换背景、加特效都靠它先把主体分出来。Remotion 用代码批量合成视频，片头、字幕样式、转场都能模板化，适合日更账号批量出片。WhisperX 负责语音转字幕并对齐时间轴，自动字幕的准确率比纯语音识别高一截，命令入口是 whisperx audio.mp3 --model large-v2 这类一行调用。

环节 仓库 干什么活
调度 ComfyUI 节点工作流总控
生成 Wan2.2 / LTX-Video 文生视频与图生视频
驱动 LivePortrait / MuseTalk 表情驱动与口型对齐
合成字幕 SAM2 / Remotion / WhisperX 抠像、批量合成、字幕对齐

 这八件全装本地对显卡和硬盘是硬考验，生成类模型动辄几十 GB。先用云端或小模型把流程跑通，确认哪个环节真是你的瓶颈，再决定本地部署哪几件，别一上来全家桶。

拼流水线之前先想清产量

日更一条和周更一条，工具选型完全不同。产量低就用现成平台省心，产量高、要批量套模板的，Remotion 加 WhisperX 这类代码化合成才划算。流水线的价值不在仓库数量，在每个环节都不用手工返工。
