DeepSeek Harness 做幼儿园视频 Agent，家长投资人找上门

DeepSeek Harness 是什么

2026 年 8 月 13 日，DeepSeek 正式把自家的 Agent 运行时 DeepSeek Harness（CLI 名 dsh，仓库 deepseek-ai/deepseek-harness）以 MIT 协议、v0.1 developer preview 的身份开源。发布三天 GitHub star 就冲破 11.7 万，DataCamp 也在第一时间做了拆解。核心口号是 “everything is a plugin”：模型适配器、工具、会话、沙箱、甚至 Agent loop 本身全是可替换插件，由 Cordis 插件内核统一调度。模型不再是固定中心，而是众多插件里的一个普通部件。

三条上手路径：npx @deepseek-ai/dsh web 直接拉起 Web UI，Settings → Models 粘 API key 即可免重启；Python SDK 大约 15 行就能跑出同等能力；还有面向 Apple Silicon Mac 与 64 位 Windows 的桌面版公开预览。会话采用 append‑only 事件日志，支持恢复、分叉、搜索、回放；运行模式分 Standard / PTC / Minimal / Creator，Creator 模式还允许 Agent 在对话里直接写新插件。

行业影响：可替换运行时 vs 锁死运行时

Claude Code、Codex 这类产品把底层运行时锁死，开发者只能在上层写提示词或工具。Harness 把运行时的每一层都剥离成插件，开发者能替换模型适配器、沙箱、甚至循环调度器。代价是官方自己承认：没做安全审计、API 会在版本间 breaking、沙箱在不同平台表现不一，明确不建议拿去生产环境。这也是为什么它目前更像一个 “折腾验证想法” 的沙盒，而不是现成的交付级框架。

突破点清单

  • everything is a plugin：模型、工具、会话、沙箱、循环全可热插拔
  • 会话即事件日志：可恢复、分叉、搜索、回放，天然支持实验追踪
  • 四种入口覆盖全场景：CLI、Web UI、Python SDK、桌面预览
  • Creator 模式让 Agent 能在聊天里自己动手写新插件，越用越顺手
  • 第三方估算成本：V4‑Flash 单任务约 $0.045~$0.09，远低于 Claude Code + Opus 的 $0.195~$0.65

真实局限与冷静评述

幼儿园案例来自 X 上开发者 ai_xiaomu 的 build‑in‑public 分享：用 Harness 把孩子在园日常视频自动剪成周集锦，再生成蒙氏成长报告。发帖后家长与投资人主动找上门，付费意向属当事人自述，并非官方融资新闻。这个故事恰恰证明了：个人开发者只要想法清晰，Harness 能在几小时内把原型跑通、拿给别人看。但别被星标数冲昏头——没有安全审计、API 随时会 break、沙箱跨平台不稳定，官方自己都说别上生产。所以把它当作 “快速验证、拿来演示、再决定重写” 的利器，才是靠谱玩法。
