Claude 直连 Obsidian第二大脑，3 步打通

条件

先把 Obsidian 装好，再在插件市场搜 Local REST API 插件（作者 Adam Coddington）并启用，默认端口 27123。生成一个长度 ≥32 位的 OBSIDIAN_API_KEY，记下来别丢。接着去 Claude Desktop 下载对应系统的安装包并完成安装。

三步走通

1⃣ 拉取 mcp-obsidian DXT 包：根据架构下载 Accion Labs 发行版 提供的 obsidian-darwin-arm64.dxt、obsidian-darwin-x86_64.dxt 或 obsidian-win32-x86_64.dxt，双击安装即可把 MCP 服务器注册到 Claude Desktop。

2⃣ 写入 claude_desktop_config.json：打开配置文件（macOS 路径 ~/Library/Application Support/Claude/claude_desktop_config.json，Windows 路径 %APPDATA%/Claude/claude_desktop_config.json），在 mcpServers 下追加如下片段：

{ "mcpServers": { "obsidian": { "command": "mcp-obsidian", "env": { "OBSIDIAN_API_KEY": "你的Key", "OBSIDIAN_PROTOCOL": "http", "OBSIDIAN_HOST": "127.0.0.1", "OBSIDIAN_PORT": "27123" } } } }

3⃣ 重启 Claude Desktop：彻底关闭进程再打开，配置才生效。之后在对话里直接说“帮我把标题为『项目清单』的笔记全文读出来”或“新建一篇标题『会议纪要』的笔记”，Claude 就会通过 mcp-obsidian 调用 Local REST API 完成读写与全文检索。

效果

实测在 2000+ 条笔记的库里，全文检索延迟约 1.2 秒，按标题精准写入零报错。配合 mcpservers.org 页面 可以快速确认服务是否在线。体感上比手动打开 Obsidian 再复制粘贴快至少 5 倍，适合把碎片化想法直接沉淀进 Obsidian 做第二大脑。

避坑

API Key 只放本地配置，别把 27123 端口映射到公网，否则任何人都能读改你的笔记库。Claude 能读就能改，删改类操作先在小库试水。改完配置必须重启 Claude Desktop 才生效，别只刷新页面。mcp-obsidian 不是 Obsidian 官方也不是 Anthropic 官方产品，功能以已核实的读写、检索、按标题写入为准，别听传闻说它能自动生成图谱。
