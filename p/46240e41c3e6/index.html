麦门精算师：麦当劳省钱点餐助手把巨无霸套餐砍到 ¥21.9

点个麦当劳，优惠券比菜单还难

去麦当劳点餐，最折磨人的不是选吃啥，是那一堆优惠券：满减的、单品的、套餐的，叠加规则写得跟阅读理解一样。你吭哧吭哧凑了半天单，结账一看——好像也没省下多少。这事儿有程序员看不下去了，直接写了个mcd-saver-strategist，一个外号叫「麦门精算师」的麦当劳省钱点餐助手：把你手里的券和菜单全喂给它，它算出最省的点法。

这个项目由作者 hujjun 在 2026-10-09 创建，用 Python 写的，短短十几天攒下约 880 stars，还成了麦当劳程序员创意开发大赛参赛作品。在 GitDiscover 每日榜单上，它也是靠「省钱」这个硬通货杀出重围的。

麦门精算师是怎么算账的

它的核心是一个「麦当劳优惠券组合优化 Skill」：先拉取实时菜单和你账号里全部可用优惠券，再把「怎么点最便宜」变成一道组合优化题——哪些券能叠、哪些单品凑满减最划算、要不要拆成两单，统统交给算法算明白。

技术底座是 McDonalds China MCP Server 加 Agent Skill for WorkBuddy，前者负责把麦当劳中国区的数据接进来，后者让 AI 助手能直接调用这个省钱技能。你不用懂什么叫 MCP Server，会跟 AI 聊天、会报自己想吃啥就够了。

巨无霸套餐 ¥47 干到 ¥21.9

光讲原理不够过瘾，直接上数字：巨无霸套餐原价 ¥47，精算师一顿操作下来 ¥21.9 拿下，省了 53%。这不是什么「第二杯半价」的文字游戏，是实打实把券叠满之后的价格。对天天吃麦当劳的打工人来说，一个月省下的钱够再加好几顿鸡翅。

当然，这个 53% 是特定券池、特定单品组合下算出来的极限值，你手里的券不一样，结果也会浮动。但思路是通的：人脑算不过券的排列组合，机器可以。

它牛在哪

  • 把「省钱」变成可计算的问题：优惠券叠加这种反人类的规则，恰恰是算法最擅长的活。
  • 开源可审计：算账逻辑全在代码里，不像某些「神券」应用藏着掖着，省没省一目了然。
  • 大赛参赛作品：顶着麦当劳程序员创意开发大赛的名头，至少说明这路子是被官方语境认可的整活。
  • 约 880 stars 的群众基础：十几天近千 star，说明「为省钱写代码」这件事，程序员是真有共鸣。

冷静一下：省的是真钱，操的心也是真的

先泼盆冷水：优惠券这东西有时效、有地域限制，你今天算出来的最优解，明天券过期了就作废。菜单价格一调，之前的「最优」也可能不再最优。它能帮你算，但券过期了它可不会提醒你——至少现在不会。

另外它也不是麦当劳官方工具，数据靠 McDonalds China MCP Server 拉取，万一接口变了就得等作者更新。用之前先去仓库看看 README 和最近更新时间，别拿着过期攻略去收银台对线。

话说回来，就算只能省下那 53% 里的一半，对麦门信徒来说也是真香。毕竟省下来的每一分钱，都是对打工人的温柔。
