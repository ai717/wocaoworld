MotionSites提示词库实测：5个决定让AI不再长一个样

AI 做出来的落地页全是紫色渐变加三个圆角卡片，连动效都像复制粘贴

前两天我在 MotionSites 逛了一圈，发现它根本不是什么建站器，而是一个把「怎么写 Prompt」做成商品的库。挑一个 3D 风格的 hero section，复制旁边的 Prompt，扔进 Lovable、Bolt、Cursor 或者 Claude，几秒钟就能跑出带 Framer Motion 和 GSAP ScrollTrigger 的 React 代码。创始人在 dev.to 里直说：好 Prompt 不是越长越强，而是帮模型把五件事决定死透。

为什么 AI 生成的站点都长一个样

市面上大多数「AI 建站」演示都逃不开三板斧：紫色渐变背景、三个一模一样的特性卡片、fade-up 入场动画。这套组合在模型训练数据里出现得太多，导致生成时直接走「概率最高」的路径，出来的页面连配色、字体、间距都像一个模子刻出来的。换句话说，模型没被强制去做「字体系统、配色规则、网格布局、单一动效、真实素材」这五件事，所以只能靠统计规律凑合。

MotionSites 的 Prompt 到底在机制上解决了什么

MotionSites 把这五件事封装成一套可复用的模板，字段分别叫 TYPE、COLOR、LAYOUT、MOTION、ASSETS、DO NOT。把模板塞进 Lovable Knowledge、CLAUDE.md 或 Cursor rules，模型每次生成就必须遵守：

  • TYPE：把字体当系统写死，例 headlines in Fraunces, weight 600, line-height 1.2
  • COLOR：给 4~5 个命名色 + 强调色只用在主按钮和一个高亮词
  • LAYOUT：用 12 栏网格 + 1200px 容器描述结构，明确 DO NOT 里列出 hero 居中、三个同款卡片、emoji 当图标、装饰色块
  • MOTION：只保留一个动效瞬间，写清时长与缓动曲线，例 900ms, cubic-bezier(0.16, 1, 0.3, 1)，并尊重 prefers-reduced-motion
  • ASSETS：用真实产品截图替代占位图

这套模板把「模糊的审美偏好」变成「可执行的约束」，模型不再靠猜，直接按规则写代码，生成的页面自然不再千篇一律。

创始人公开的 5 决定模板，直接抄走

dev.to 帖子里把完整模板贴了出来，复制进你的 AI 编程工具就能立刻生效。核心片段如下：

TYPE: headlines in Fraunces, weight 600, line-height 1.2
COLOR: primary #0A1F44, accent #FF6F00, surface #FFFFFF, text #1A1A1A, muted #6B7280
LAYOUT: 12-column grid, 1200px max-width, DO NOT: hero centered, three identical feature cards, emoji icons, decorative color blocks
MOTION: single reveal, 900ms, cubic-bezier(0.16, 1, 0.3, 1), respects prefers-reduced-motion
ASSETS: real product screenshots only

把这段塞进 Lovable Knowledge 或 CLAUDE.md，下一次让模型「帮我做一个 SaaS landing page」时，它就会自动套用这套规则。
