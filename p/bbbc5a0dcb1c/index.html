5 美元 VPS 跑 OpenClaw，WhatsApp 指挥 AI 助理

为何要把 AI 助手塞进 5 美元 VPS

去年我还在为 Notion $10/月、Todoist $5/月、习惯打卡 $3/月三张账单头疼，直到在 作者原帖 看到一位开发者把 OpenClaw 装在 Hostinger $5/月（2vCPU 8GB RAM）的 VPS 上，配合 Tello eSIM $5/月给助理配个真手机号，直接在 WhatsApp 里发指令就能搞定日历、邮件、语音笔记、习惯打卡。算下来一年省下 $216，还把数据全掌握在自己手里，这才是真·白嫖。

五美元服务器、美版 eSIM 和三把 API 钥匙

1️⃣ 一台 $5/月 VPS（Hostinger 或同价位），root 权限、Docker 已装好。
2️⃣ Tello eSIM（或任何支持 WhatsApp 的实体卡），用于给助理注册独立号码；国内直连 WhatsApp 受限，建议改用 Telegram Bot 做备用通道。
3️⃣ OpenAI API 的 OAuth token（复用 ChatGPT Plus），Gemini API key 做 fallback，Brave Search API key 做联网搜索。
4️⃣ 域名或动态 DNS（可选），方便 SSH 隧道固定端口。
5️⃣ 私有 GitHub 仓库，用于每天 23:00 自动推送 workspace/ 下的 HABITS.md、MEMORY.md、NOTES.md、PROJECTS.md、PROFILE.md、USER.md 以及 drafts/ 草稿。

一条命令把容器跑起来

docker run -d \
  --name openclaw \
  --shm-size='2gb' \
  -v /dev/shm:/dev/shm \
  -v $PWD/data:/data \
  -p 127.0.0.1:18789:18789 \
  -e OPENAI_OAUTH_TOKEN=your_token \
  -e GEMINI_API_KEY=your_key \
  -e BRAVE_API_KEY=your_key \
  ghcr.io/hostinger/hvps-openclaw:latest

容器启动后，只监听 127.0.0.1:18789。外部访问必须走 SSH 隧道：

ssh -L 18789:127.0.0.1:18789 user@your-vps

浏览器打开 http://localhost:18789 即可看到 OpenClaw 管理界面（官网 openclaw.ai、文档 docs.openclaw.ai）。

把 WhatsApp 变成指挥台

在容器内的 openclaw.json 里配置 allowFrom 白名单，只放家人的 WhatsApp ID。重启会把配置覆盖，所以要准备一份 golden config，配合 systemd 或 cron 在容器启动后自动覆盖回去。WhatsApp 发送 /calendar add 明早 9 点开会、/email reply 请查收附件、/habit done 早跑 5km 等自然语言，助理会通过 gog CLI 操作 Google 日历和 Gmail，习惯打卡和待办则直接写进 workspace/ 的 markdown 文件——Notion 和 Todoist 已经被砍掉，这里不再需要它们。

五个能让你半夜爬起来修的坑

• Chromium 无头模式必须加 --shm-size=2gb 并挂载 /dev/shm，否则大页面直接 OOM 崩溃。
• 残留 SingletonLock 会导致第二次启动卡死，启动脚本里加一行 find /data/.openclaw/browser -name SingletonLock -delete 2>/dev/null。
• OpenClaw 重启会重写 openclaw.json 丢失 allowFrom，必须用 golden config 自动恢复，否则陌生号码也能指挥助理。
• 国内 VPS 直连 WhatsApp 会被墙，Tello eSIM 是美卡，建议同时配置 Telegram Bot 做双通道，保证指令送达。
• OpenAI 走的是 OAuth 复用 ChatGPT Plus，token 记得放进 .env 文件而不是硬编码进配置；密钥定期轮换，别偷懒。

每天自动把笔记推到私有 GitHub

在 VPS 上加一条 cron：

0 23 * * * cd /root/openclaw-workspace && git add . && git commit -m "daily backup $(date +\%F)" && git push origin main

这样 HABITS.md、MEMORY.md、NOTES.md、PROJECTS.md、PROFILE.md、USER.md 以及 drafts/ 全量上传，随时可在本地克隆复盘。整套流程跑通后，Notion、Todoist、习惯打卡三个订阅全部取消，年省 $216，数据 100% 自控，这就是把 OpenClaw 变成「私人首席助理」的最短路径。
