融资570万美元，cto.new 让顶级模型无限量免费

 

融资 570 万，干了一件让同行肉疼的事

算一笔账：一个 10 人小团队，一年光 AI 编程工具的订阅费就要 2.28 万到 7.2 万美元。Cursor 的 20 美元套餐越砍越狠，Claude Max 100 美元起还限量不明，ChatGPT Pro 直接 200 美元一个月。AI 编程从「人人可用」变成了「有钱才配用」，这就是 cto.new 要掀桌子的理由。

11 月初，Engine Labs 宣布完成 570 万美元融资，领投的是 Kindred Ventures 和 PROfounders，Wonder Ventures、Entrepreneurs First、Script 跟投。融资的用途只有一个：把 cto.new 做成「全球第一个完全免费的 AI 软件工程平台」，让每个开发者、创业团队零成本用上旗舰模型。

Alloys：一个会话里混着用三个大模型

cto.new 官方博客里最抓眼球的承诺是：无限制使用所有主流前沿模型——GPT-5 Codex、Claude Sonnet 4.5、Gemini Pro，不锁供应商。更狠的是它叫 Alloys 的功能：同一个 agent 会话里可以混搭多个模型，比如让 GPT-5 Codex 写代码、Claude Sonnet 4.5 做评审，省得来回切窗口。

除了模型，平台还打包了智能任务规划（把复杂项目拆成可执行的小块）、自动代码评审和优化，以及跟现有工作流的深度集成：GitHub、Linear、Jira、Slack 全接上。官方的说法是，它不只想当个写代码的助手，而是要当你整个技术团队的「AI 首席技术官」：理解代码库、管理技术债、给架构提建议、守代码质量标准。

不止写代码，它想当你的整个技术团队

这个定位其实踩中了一个真实变化：AI 编程工具正在从「补全代码」进化到「管整个工程」。规划、评审、修技术债这些以前靠人肉开会的活儿，现在都想塞进 agent 的工作流。cto.new 把规划、评审、集成打包进一个免费平台，等于把 Cursor、Linear AI 助手、Code Review 机器人这些分散的订阅合并成一单——只不过这一单是 0 元。

对独立开发者和学生党来说，这事最实在：以前看教程里大佬用 Claude Max 跑全流程，只能眼馋；现在注册个账号就能在 cto.new 上试同样的活儿。社区也在 Discord 上聚起来了，玩法和模板流转得很快。

免费这事，靠烧钱能烧多久

冷静一下：570 万美元听着不少，但前沿模型的推理成本是按 token 烧钱的。一个「无限制用 GPT-5 Codex」 的用户，一个月烧掉的 API 成本可能就顶普通人一年工资。Engine Labs 自己也承认，这笔钱就是用来「补贴其他公司收几百美元才能用的算力」。

官方画的饼是「规模化创造的价值大于付费墙」，但具体靠什么赚钱、免费额度有没有隐藏上限，博客里都没细说。现在去 cto.new 注册就能用，趁着免费窗口，先把手头的项目丢进去跑一遍是最实在的——白嫖要趁早，规则以后随时可能变。
