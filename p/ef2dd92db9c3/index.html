10 个免费仓库拼出手机3D全息公寓：拍照就能住进未来

 

拍照到全息：十个仓库串起的四段链路

给公寓拍张照，剩下的事交给十个免费开源仓库。原帖给出的链路分四段：先拍房间照片做 3D 扫描，再换风格改设计，然后捏出三维模型，最后塞进手机里以 AR 全息的方式查看。帖子互动不低，点赞 410、书签 495、浏览 3.5 万，说明不少人想把这条链跑通。十个仓库各管一段，谁也别抢谁的活，拼起来才是一条能走完的流水线。

换风格不用重拍：ControlNet 与 TRELLIS 分工

链路的头两段决定成片像不像样。拍照之后，roomGPT 负责按文字描述改户型风格，ControlNet 控住原图的构图与结构，改完还是这间房，不会改成另一套。风格定下来，TRELLIS 与 Hunyuan3D-2 接手，把图片转成带结构的 3D 资产；Gaussian Splatting 则用高斯泼溅把扫描结果做得更细腻，墙面与家具的边缘不会糊成一团。想自己跑通，克隆仓库是第一步：git clone https://github.com/Nutlope/roomGPT，再按各仓库的说明装依赖，别指望一个命令装完十个。

手机里看全息：model-viewer 兜底渲染

模型捏出来还不算完，得让人一眼看到。Blender MCP 让 AI 直接在 Blender 里摆场景、调灯光、改材质，改一句提示词就能换一套布景；model-viewer 负责把成品嵌进网页，手机打开就能旋转查看；React Three Fiber 则用来搭更自由的 3D 页面，交互与动画都能自己写。最后一步交给 bolt.new，一句话生成展示页面，手机扫码就能看。渲染层装依赖也简单：npm install three @react-three/fiber @react-three/drei，页面骨架几分钟就能立起来。

环节 仓库 干什么
风格改造 roomGPT 按文字描述改户型风格
结构控制 ControlNet 控住原图构图再改风格
扫描重建 Gaussian Splatting 照片转细腻 3D 场景
图片转 3D TRELLIS / Hunyuan3D-2 单图生成三维模型资产
场景搭建 Blender MCP AI 在 Blender 里摆场景调灯光
网页查看 model-viewer 手机浏览器直接看 3D 模型
交互页面 React Three Fiber 搭可交互的 3D 展示页
快速建站 bolt.new 一句话生成展示页面

7000 美元说法先打问号：这条链的真实成本

原帖说找设计师做同类效果 7000 美元起步，这个数字是作者自己的口径，没有核验过，别当成报价单来引用。真实成本要分开算：十个仓库本身免费，MIT 与 Apache 这类开源协议允许个人与商用，但跑模型要显卡，3D 扫描与生成环节吃显存，本地跑不动就得租云端 GPU。Blender MCP 与 model-viewer 这类环节不花钱，贵的是算力与时间。按这个口径写预算才老实：软件零成本，算力与调试时间才是账单的大头。

老法师避坑提醒：别被“7000 美元起步”带偏，那是作者口径、未经核验；也别以为十个仓库装完就能一键出片，版本冲突与显存不足才是新手最常翻车的地方，先在小房间上跑通再谈全屋。

照着抄作业：今晚就能跑通的最小组合

最小组合不用十个全装：roomGPT 改风格、TRELLIS 转模型、model-viewer 上手机，三件就能走通拍照到查看的全程。跑通之后再加料：想换家具加 Hunyuan3D-2，想调灯光接 Blender MCP，想做分享页再套 bolt.new。这条链的价值不在工具多，而在顺序清楚：先定风格，再建模型，最后才谈展示。顺序乱了，十个仓库也只是一堆散件。
