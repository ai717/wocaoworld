Anatomy等距图解：用 Claude Code 一句话生成可拖动机器 SVG

想画机器原理却不想手写 SVG

以前要把齿轮、摆轮、发条的运动关系画成等距示意图，得么么在 Illustrator 里手搓路径，或者写一堆 svg 标签，改一次参数就得重画一遍。最近在 GitHub 发现了 Anatomy，一个 MIT 协议、完全免费的 Claude Code 技能，安装后只要在聊天框扔一句自然语言，几分钟到几小时就能吐出可拖动、可缩放的等距 SVG 机器，数字还是实时模拟跑出来的，不是图像模型生成的死图片。

条件

  • Node.js 20.10 或更高版本
  • 已安装 Claude Code（也兼容 OpenCode、Codex，基于开放 Agent Skills 格式）

步骤

  1. 打开终端，跑安装命令：npx skills add wheresryan22/anatomy -g -a claude-code
  2. 重启或刷新 Claude Code，技能列表会出现 anatomy
  3. 在对话框输入示例提示：/anatomy explain how a mechanical watch keeps time, interactive
  4. 等待渲染完成，得到一个可拖动、可缩放的等距 SVG，鼠标悬停齿轮还能看到实时转速数值

成本与限制

作者自己测过，简单的手表机芯约 1 小时 54 分，复杂的发动机模型甚至跑了 14 小时。官方 README 也直说“约 2 小时左右、不是秒出图”。原理是 Claude 现场写 JavaScript 代码生成 SVG（可选 WebGL 层、3D 还在 beta），图里的数字由实时物理模拟驱动，不是一次性出图的图像模型。所以别把它当聊天玩具，它是批量渲染工具，适合做教学演示、技术文档插图、快速原型验证。

星标数据的多源口径

根据 Kunal 报道，10 月 12 日仓库已超 6507 star、464 fork；同一天另一口径显示 4103 star、323 fork；到 10 月 19 日左右 DevSly 快照约 19.7k star、1.5k fork。成文时以这三个来源为准，不做实时精确数字。

避坑指南

这不是聊天玩具，是批量渲染工具；先拿小概念试一张，别一上来就丢复杂系统；出图慢是正常的，不要以为卡住了。

适用场景

把原理图嵌进 Notion、Obsidian、技术博客，或是给新人做入职培训时的可交互图解，省去手绘和反复修图的麻烦。配合 Claude Code 的上下文记忆，还能连续追问“把发条扭矩改成 0.8 Nm 再渲染一次”，几分钟就能看到新版本。

耗时这件事值得单独说一句：作者自己的图从 1 小时 54 分到 14 小时不等，社区画廊的作品从 14 分钟到约 3 小时都有。也就是说，出图时间波动很大，取决于概念的复杂程度和 agent 当天的状态。把它当成批量渲染工具来排时间，别当成聊天窗口里的秒出玩具，心态对了才不会觉得它“卡住了”。
