近 900 个免费模型：一个注册表收齐全套素材

做小游戏与产品展示最费时间的不是写代码，是找模型。开源注册表 ToxSam/open-source-3D-assets 收录了 991 个以上免费 3D 模型，树木、岩石、城堡、角色都有，统一风格的合集按主题分好，下载下来就是 GLB 文件，直接拖进 Three.js、Blender、Unity 或 Godot 就能用。原帖发的时候还不到 900 个，注册表一直在长，现在已经过了 991 个。

可商用无需署名：CC0 意味着什么

这个注册表的关键卖点是授权干净：大部分合集是 CC0，等于把作品放进公共领域，个人与商业项目都能用，不用署名、不用付费、不用担心版权追索。合集主要来自 Polygonal Mind 的系列，风格统一，拼在同一个场景里不会穿帮。每个模型的授权都在 projects.json 里写明，下载之前先看一眼授权字段，CC0 之外的个别合集按标注处理。用之前查一下很简单：curl -s https://raw.githubusercontent.com/ToxSam/open-source-3d-assets/main/data/projects.json | head -20，注册表结构一目了然。

Agent 也能直接用：按描述搜模型、预览再下载

注册表不只是给人翻的，也给 Agent 用。原帖称它提供 MCP 接入，Agent 可以按描述搜模型、预览、下载，不用人工一个个翻合集。注册表本身是结构化 JSON，永久链接指向 GitHub、IPFS 或 Arweave 这类永久存储，模型文件不会今天能下、明天失效。做小游戏的独立开发者最受益：场景里的树、石头、城堡一次找齐，美术外包的钱先省下来。

老法师避坑提醒：CC0 不等于所有合集都免署名，个别合集可能有自己的授权要求，下载前先看 projects.json 里的授权字段；GLB 文件有大有小，手机端场景一次塞太多模型还是会卡，先控数量再谈效果。

跟拍照建模那条链怎么分：素材库与全链是两回事

本批另一条是拍照到手机 3D 全息的全链，十个仓库从拍照、换风格一路做到 AR 查看；这条是素材库，直接拿现成模型用。两条角度不同：想快速搭场景就用素材库，想把自家公寓变成 3D 模型就走全链。小游戏开发尤其适合素材库：角色、道具、环境一次配齐，省下的时间留给玩法本身。做 DOIN 小游戏选题的人也可以把这个注册表记下来，当作长期素材来源。
