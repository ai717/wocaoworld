ai-job-search 实战：用 Claude Code 全自动找工作

找工作，居然被做成了 Agent 工作流

投简历这事，可能是当代打工人最痛的重复劳动：海投石沉大海，改简历改到半夜，面试准备全靠临场发挥。本周 GitHub 涨星最猛的项目 ai-job-search，干了一件很野的事——把整套求职流程做成了一个跑在 Claude Code 上的 AI 工作流，一周涨了 1.28 万星（whatstrending.ai 本周加速榜）。更野的是，作者本人就是靠这套流程找到工作的：地球物理学家出身，2025 年底被裁，69 份定制申请、20 个一面，最终 2026 年 6 月入职 AI 工程师。这不是 demo，是真刀真枪跑出来的 offer。顺带说一句，项目 star 涨得这么快，说明「用 AI 搞定重复劳动」这个需求是真实存在的，不是极客自嗨。

 

前置条件：先看好账单

动手前先说清楚成本，免得你装到一半骂人。第一，Claude Code（CLI 版）——注意它没有免费 tier，需要 Pro/Max/Team 订阅或者 Anthropic API credits（按量付费，偶尔用反而更便宜）。第二，Python 3.10+ 和 Bun（跑职位搜索 CLI 工具用）。第三，LaTeX 发行版（简历用 lualatex 编译，求职信用 xelatex）。这套配置对程序员友好，对纯小白有门槛，量力而行。

四步跑起来：从 fork 到面试

第一步，fork 仓库：gh repo fork MadsLorentzen/ai-job-search --clone。注意，GitHub 的 fork 永远是公开的，而后面 /setup 会把你的姓名、联系方式、工作经历、薪资期望写进仓库文件——公开 fork 等于公开简历，这一点后面避坑细说。

第二步，填档案：跑 /setup，按引导把你的个人 profile 填好，这是后面所有定制化的地基。第三步，搜职位：跑 /scrape，Agent 会按你的条件去招聘网站扫职位，逐个打分并给出匹配度推荐。默认的职位搜索技能是按丹麦市场做的（Jobindex、Jobnet 这些），国内用的话需要换成本地招聘站，模式是设计成可替换的。

第四步，申请：看中某个职位，跑 /apply <url>，Claude 会评估匹配度、打分，然后起草定制简历和求职信——还有个 reviewer agent 负责挑刺，改完再出终版。最后 /interview 帮你准备面试。整套流程下来，你干的活从「写简历」变成了「做选择题」。

 这四条不看会吃亏

第一，隐私红线：公开 fork 会泄露简历！/setup 写入的个人信息都在版本控制里，千万别直接用公开 fork 推简历，要么用私有拷贝，要么脱敏。第二，Claude Code 没有免费版，API 按量付费通常比订阅便宜，适合偶尔求职的人。第三，默认职位源是丹麦的，国内用户要自己换招聘网站技能。第四，摆正预期：作者投了 69 份定制申请才换来 1 个 offer，量大管饱是常态，工具提效不包分配。

另外提醒一句：项目 README 里专门声明，没有任何官方代币或付费赞助计划，打着项目名义卖币的都是骗子，支持作者只认 Ko-fi 捐赠和 GitHub 贡献。

 工具不替你面试

说句大实话：ai-job-search 再强，也替你去不了面试现场。它真正解决的是求职里最磨人的部分——搜职位、读 JD、改简历、写求职信、跟进进度，这些重复劳动被 Agent 接管后，你省下来的精力可以全部砸在面试准备和真实沟通上。工具把「体力活」自动化了，「脑力活」还得你自己来。

还有一个隐藏价值：这套工作流的核心流程（自我画像、匹配度评估、起草-评审）是语言和国家无关的，只有职位搜索技能需要本地化。社区已经有人在给 Codex、Gemini CLI 做适配 fork，不用 Claude Code 也能蹭上这套方法论。方法论是通用的，工具只是载体。

本周 5 大爆款仓库盘点视频里也提到了它和求职隐私提醒。如果你正在找工作，或者单纯想看看 Agent 是怎么被用到生活里的，这 1.28 万星的项目值得花一个周末折腾一下——毕竟作者已经用它证明了一件事：这套流程，真的能换来 offer。
