火宝短剧开源了：全自动生产线能跑，棺材板还没被踹飞

仓库是真的，几十分钟无人值守是广告词

chatfire-AI/huobao-drama 把剧本、分镜、角色、镜头视频、配音和合成串成一条 Web 流水线，星标已经上万。口号是一句话生成完整AI短剧。开源降低的是把流程搭起来的门槛，不是把拍摄、审核和投放一起包圆。

它能干的是：大模型拆剧本、抽角色和场景，再调用绘图与文生视频、图生视频接口出分镜，最后拼成片。设置页里填 API Key 和模型，文本、图片、视频、语音往往要分别付费。视频按秒计费，一条竖屏短剧就能把测试额度打穿。人可以少盯按钮，账单和返工不会消失。

小团队怕的不是开源，是同质化和人物漂移

接单公司以前拼的是编剧、拍摄和周期。现在谁都能 clone 仓库，题材撞车会更快。真正把成片卡死的，仍是同一张脸换场就漂、服装灯光对不上、对白和口型各说各话。火宝短剧适合打样：这个钩子值不值得拍。把它当成「十几个人半个月的活，一个人喝茶等着」，会在第一集就看见道具失踪。

环节 仓库能自动走 仍然要人盯
剧本和分镜 能从一句话或大纲拆场 逻辑、尺度、版权
出镜画面 能按镜头调生成接口 脸、服装、空间是否连续
配音字幕 能接 TTS 和压字 情绪、错字、平台安全词
上架变现 不能 审核、投流、同质化限流

开源意味着可以魔改工作流、换模型、接自己的素材库。也意味着别人用同一套默认提示词批量产「霸总雨夜」。平台对搬运和未授权改编并不手软。小说、脸和声音没有授权，生产线越快，下架越快。

门槛被踩低的是试错，不是稳赚

一个人真能把从想法到成片的等待缩短到几十分钟量级，前提是模型队列不堵、Key 没欠费、你接受第一版只是能播的草稿。小团队若还靠代工过活，要改的是报价结构：卖的不再是「能拍出来」，而是人设稳定、前三秒留人和过审。工具把棺材板拍响了，土还得自己填。
