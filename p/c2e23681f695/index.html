OpenAI 为 Codex 推出 iOS 构建插件，SwiftUI 预览与热重载一步到位

OpenAI 为 Codex 推出了一款全新的 Codex iOS应用构建插件，彻底打通了从代码生成到实时预览的最后一公里。开发者现在可以直接在 Codex 的应用内浏览器中查看和测试 iOS 应用、打开 SwiftUI 预览，并享受热重载功能，无需在多个工具之间反复横跳。

核心亮点：Codex iOS应用构建插件如何重塑开发流程

长期以来，iOS 开发受困于繁琐的构建与预览环节。此次推出的 Codex iOS应用构建插件 精准解决了这一痛点。它内嵌高性能浏览器引擎，原生支持 SwiftUI 预览渲染，每次代码改动都能即时推送到预览窗口，实现真正的热重载。这意味着开发者可以在一个窗口内完成编码、调试和视觉验证，大幅缩短反馈循环。

一站式体验：从编码到验证零切换

该插件最显著的优势在于集成度。你不再需要启动 Xcode 的模拟器，也不用在浏览器和 IDE 之间频繁切换。Codex 的应用内浏览器直接承载了 iOS 应用运行环境，并提供了完整的交互能力。无论是点击按钮、滑动列表还是测试手势，都能在 Codex 内部完成，真正实现了“所见即所得”的开发体验。

为 SwiftUI 而生，热重载带来即时反馈

插件对 SwiftUI 的预览支持达到了原生级别。当你修改布局或样式时，预览窗口会像魔法一样瞬间刷新，保留当前状态。这种即时反馈机制不仅降低了初学者入门的门槛，也让经验丰富的开发者得以进行更细腻的视觉微调。据 OpenAI Developers 透露，该功能基于 Codex 的实时协作引擎，延迟极低，足以支撑高频次迭代。
