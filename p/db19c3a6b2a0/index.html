不登录不填 Key，在 DeepSeek Harness 里直接白嫖前沿模型

白嫖的姿势：装个插件就行

dsh-our-free-model 是 DeepSeek Harness（dsh）的一个开源插件，卖点就一句话：装上之后，DeepSeek V4.1 Flash、Kimi K3 这些前沿模型直接出现在模型列表里，不用登录、不用注册、不用填 API Key。项目 MIT 开源，2026 年 10 月 30 日实测已经 5 万多 star——「不想管 Key」是真刚需。

免费的底气：直连两个公共网关

免费不是魔法。README 写得很直白：插件把请求直连OpenCode 的 Zen 网关和Kilo AI 的公共网关，中间不经过任何第三方中转，请求由谁处理、数据发往何处，全写在「上游是哪些源」和免责声明里。因为上游网关本来就对公众开放免费额度，插件只是把标准 OpenAI 接口协议转发过去，所以才敢承诺不限量。模型清单也不写死，每次刷新都去上游重新拉，可用性取决于你自己机器的网络出口。

插件还做了两件贴心事：一是模型选择器只显示当前网络出口真正可用的模型，上游声明了但网关拒绝路由的直接隐藏，不让你对着灰掉的按钮干瞪眼；二是思考强度下发的是真实预算而不是提示词忽悠，有档位菜单的模型按原值透传给上游，设置页每张模型卡都标注了实际下发的上限。

怎么装：别碰 npm 那个同名包

先说坑：npm 上有个同名包是第三方打包的，内容跟官方仓库不一致，README 加粗警告不要装。正确姿势是去 GitHub 拿官方源码，纯 dsh web 版跑 dsh plugin --profile web add /绝对路径/dsh-our-free-model，装完重启一次客户端。如果不想装 dsh，仓库里还有 packages/standalone 独立本地服务，npm run start:standalone 跑起来，默认占 18900 端口，自带网页管理后台。

插件支持应用内升级：设置页一键检查更新，下载、校验、备份、热重载一条龙，失败自动回滚，不用手动折腾。README 里还单列了「已知边界」和免责声明：Kilo 渠道的免费池由上游提供，prompt 可能被记录用于改进服务——敏感内容别往里塞，白嫖也要讲基本法。

能白嫖多久？先看明白边界

天下没有永久免费的午餐：模型清单跟随上游，上游哪天收紧额度、改接口，插件里的免费车道就跟着变。插件设置页里有用量看板和运行日志，token 花在哪一目了然，数据全留本机不上传。另外插件还带了 OpenAI 兼容的本地转发端口，本机其他工具改个 base URL 就能蹭这些模型。白嫖可以，重要生产流量别全押在这上面。
