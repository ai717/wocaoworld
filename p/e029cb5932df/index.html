一张图捏出量产AI女主：四张定妆图先把脸锁死

 

女主总变脸：先拿四张定妆图把人锁死

AI 短剧最常见的翻车不是剧情差，是女主每集换张脸。原帖给出的解法是先锁人再拍片：用一张图做出四张定妆图，全身定妆照锁长相与服装，场景图锁氛围，三视角定妆图从正、侧、背三个角度锁住 360° 外形，微表情特写锁表情与发丝。四张图齐了，再连同参考视频一起喂给视频 Agent 生成完整视频，女主从头到尾都是同一个人。帖子浏览 8.7 万、点赞 404、书签 709，每一步都附了完整 Prompt，照着抄就能复现。

四张定妆图怎么做：每张只锁一件事

四张图的顺序不能乱。第一张全身定妆照定下女主的脸、身材与服装，这是全片的锚；第二张场景图定氛围，光线、色调与环境一次定好，后面所有镜头都向它对齐；第三张三视角定妆图最关键，正、侧、背三个角度把外形锁死，转身镜头才不会崩；第四张微表情特写锁表情与发丝细节，哭戏与笑场都有据可依。每张图只锁一件事，提示词里写清要锁什么、不要改什么，改动范围越小，一致性越高。

工具只用 YouArt：免费额度与无限画布怎么用

原帖用的工具是 YouArt，每日有免费额度，画布无限大，四张定妆图可以铺在同一张画布上对照着调。需要注意一点：YouArt 底层是 Anthropic Claude 模型，不是 Meta Muse，别跟本批另一条的 Muse 工具搞混。免费额度每天刷新，定妆图阶段多试几版不心疼，真正烧额度的是后面视频 Agent 生成成片的环节。画布无限大还有个好处：四张图并排摆在一起，肉眼就能看出哪张跑偏了，当场重画。

老法师避坑提醒：定妆图阶段别贪多，四张锁死再往下走，边拍边改只会越改越乱；免费额度只覆盖出图，视频 Agent 生成成片另算账，成片前先拿短片段试一致性，别一上来就生成整集。

这篇讲的是制作方法：别跟变现文案混为一谈

这条讲的是制作方法：怎么让 AI 女主在全片里保持同一个人。同期另有一条抖音 AI 美女号的变现文案在走 MoneyLab 核验，没进本批，两件事不是同一口径。做短剧的人关心的是定妆、一致性与量产节奏，变现文案关心的是账号起号与收益算法，读的时候别串台。方法本身是通用的：换男主、换配角、换产品代言人，四张定妆图的路子照样能用。

参考视频的作用也不能省：定妆图锁住静态长相，参考视频锁住动态习惯，走路姿态、转身速度、说话时的手势都在视频里。视频 Agent 生成时同时吃进四张定妆图与参考视频，静态与动态两边都有锚，成片才不容易在中段走样。先拿十几秒的短片段试跑，确认女主没换脸再生成整集，免费额度要花在刀刃上。
