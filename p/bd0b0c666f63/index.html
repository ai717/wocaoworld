HGhub 开源 6 天 5600 星，黄果短剧三端客户端

 

一个练手小玩具，6 天涨了 5600 星

作者自己在 README 开头就先泼了冷水：HGhub 只是他体验 Tauri 2 移动端开发时做的“小玩具”，开源几天后不知为何收到了大量 star，“实际上德不配位”。话是这么说，数字摆在那里：仓库 2026-11-03 才创建，到 2026-11-10 凌晨已经 5,617 星、2,090 fork，最新版 v1.2.0 在 11 月 9 日刚发。短剧赛道热是一回事，一个第三方客户端能火成这样，另一回事是它把“免费刷短剧”做成了开箱即用的三端应用：Windows、macOS、Android 全覆盖，Fluent 设计，沉浸式竖屏播放。

先把话说清楚：HGhub 是黄果短剧的第三方客户端，不是官方出品。它不提供、不存储、不分发任何音视频内容，所有内容来自第三方站点，版权归原作者与上游站点所有。作者也在 README 里写明，本项目仅供学习与技术交流。想白嫖的心态可以理解，但这篇的每一句提醒都不是客套话，往下看就知道为什么。

动手前，先分清你走哪条路

只想刷剧的人，什么工具链都不用装，直接去 GitHub Releases 下安装包就行，这是唯一的官方下载渠道。仓库源码页不放任何可执行文件，其他网站、网盘、QQ 群、公众号、第三方下载站分发的所谓 HGhub 安装包一律非官方，作者不保证其安全性与完整性。想自己编译、改代码、学 Tauri 2 的人，才需要准备工具链：桌面端要 pnpm 和 Node；Android 还要 Android SDK 与 NDK，并配好 ANDROID_HOME、NDK_HOME 与 JAVA_HOME（JDK 17）；iOS 则要 Xcode、xcodegen、CocoaPods 再加一个 Apple 开发者账号，自己签名装到自己的设备上，最低支持 iOS 15。还有一个容易被忽略的细节：工程如果放在 exFAT 盘上，因为 exFAT 不支持符号链接，千万别动 .npmrc 里的 node-linker=hoisted，删了它安装那步就会报错。

装安装包、自己编译、手机端打包，三条路这样走

最省事的一条路是装官方安装包：Windows 拿 NSIS 安装程序，macOS 拿 .app 加 .dmg，下完双击就能用。第二条路是源码编译桌面端：先 git clone https://github.com/Minireel/HGhub.git，进目录跑 pnpm install，想边改边看就跑 pnpm app:dev 做桌面端热重载，改满意了跑 pnpm app:build 打包。第三条路是手机端：Android 先跑 pnpm android:init 生成一次工程，再用 pnpm android:dev 在真机或模拟器上调试，pnpm android:build 就能产出 APK，文件在 src-tauri/gen/android/app/build/outputs/apk/ 里；iOS 先导出 APPLE_DEVELOPMENT_TEAM 再跑 pnpm tauri ios init --ci 生成 Xcode 工程，然后 pnpm tauri ios build --export-method debugging 打包，产物在 src-tauri/gen/apple/build/arm64/HGhub.ipa，再用 xcrun devicectl 装到设备上。一个贴心的小细节：设置里“播放 → 启动时静音”默认是开着的，每次启动应用都是静音状态，播放时手动开声音；把这个选项关掉之后，下次启动会恢复上次的静音状态，音量也会被记住。

剧是怎么播出来的：三招全写在 README 里

HGhub 的播放链路没有藏着掖着，README 的“实现要点”一节写得明明白白。第一招是统一边缘信封：站点把 /api/** 收敛成一个 POST /api/edge/request 入口，HGhub 只对接这一个入口，不用处理 Cookie。第二招是封面解密：封面是 AES-128-CBC 密文，Rust 侧解密后经自定义协议输出，前端 <img> 直接就能用。第三招是 HLS 代理：m3u8 与分片经自定义协议转发，并改写 #EXT-X-KEY 与分片地址，绕开 WebView 的 CORS 与防盗链。自定义协议还分平台：Windows 与 Android 用 http://hg.localhost/*，macOS 用 hg://localhost/*，Rust 侧的 lib.rs 与前端的 api.ts 各自按平台生成一次基址，两处必须一致，否则封面与视频会全部加载失败。作者特意强调了一句：不做签名逆向，只复用浏览器同源行为，接口字段均有文档与实测样本。整套技术栈也值得抄作业：壳是 Tauri 2（Rust 1.90+），前端是 React 19 + TypeScript + Vite 7 + Tailwind CSS 4，播放靠 hls.js，网络层是 reqwest + rustls，想学 Tauri 2 三端开发的人，这个仓库的目录结构本身就是一份现成的教材。

翻车点都在这里，动手前先认清

作者原话：“意识到可能存在的潜在危险后，我立刻更换了开源协议为 PolyForm Noncommercial 1.0.0，并在 Readme 中写入了大量保护自己的文段。在之后的更新中，我不再会维护任何获取上游数据的工作，维护方向将偏重于 UI/UX 与使用体验。”

  • 仿冒版已经出现了：hichuv/HGhub 是恶意修改版，在旧版源码基础上擅自加入卡密验证、VIP 付费解锁等变现功能，代码改动不透明、安全性无法验证。请勿下载、勿注册、勿付费；如果你装了这个版本，建议立即卸载，改用官方 Release 包。官方版本从未、也不会加入任何卡密、VIP、付费解锁或广告功能，遇到要你输卡密或付费开通的 HGhub，那一定不是官方版本。
  • 许可证变了：自 v1.1.0 起适用 PolyForm Noncommercial 1.0.0，禁止任何商业用途，包括打包出售、接入付费或会员或广告变现、作为收费服务或商业产品的一部分分发；个人学习、研究、自用与非营利使用不受限制。v1.0.1 及更早版本按 MIT 发布，已发出的副本继续按 MIT 授权。
  • macOS 用户会撞上 Gatekeeper：Release 里的 dmg 没有用 Apple 开发者证书签名和公证，从网上下载后会被拦下，提示“已损坏”或“无法验证开发者”。把 HGhub 拖进“应用程序”后，在终端执行一次 xattr -cr /Applications/HGhub.app 再打开。
  • 随时可能失效：作者已经停更上游数据的获取工作，维护方向只剩 UI/UX，上游接口一变，封面与播放列表随时可能加载失败；镜像线路仅支持游客浏览，跨站点切换和首次升级后需要重新登录。
  • 构建报错先看盘符与 SDK：pnpm install 报 ERR_PNPM_EISDIR，多半是工程放在 exFAT 盘上，保留 node-linker=hoisted 就能过；Android 构建提示找不到 SDK 或 NDK，先检查 ANDROID_HOME、NDK_HOME 与 JAVA_HOME 有没有配对。

一句话总结：想白嫖一个能看的短剧客户端，认准官方 GitHub Releases，别碰任何第三方分发；想学 Tauri 2 三端开发，仓库的目录与实现要点是现成的教材；但别指望它长期稳定，更别拿去做任何商业化的事——作者把丑话说在前头，许可证也改了，红线踩不得。
