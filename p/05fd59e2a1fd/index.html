《高性价比人生指南》：GitHub上1.3万星的601条备选单

这本书在GitHub上到底长什么样

高性价比人生指南是一份开源循证生活手册，仓库地址是github.com/eternity4719/HowToLiveBetter。作者把目标写得很直：用最少的钱、时间、精力和毅力，换回寿命、金钱、时间和人身自由。License是Unlicense，等于公有领域，谁都能读、改、转发。

用户口中的「13000+ Star、601条」对得上仓库成长曲线。README徽章曾写601条；到2026年9月下旬，在线页和仓库简介已滚动到608条左右，星标在不同镜像页显示约1.3万至1.5万。条目还在加，被裁补偿、押金被扣、少生病、少花冤枉钱这类问题都收进分节正文，不是口号合集。

作者反复强调同一句话：这是按性价比排好的备选单，不是任务清单。挑走一两条就算数，作者自己也没做到其中大部分。在线检索页在eternity4719.github.io/HowToLiveBetter，PDF、EPUB和离线单文件HTML挂在Releases，正文更新后自动重打包。

每一条都回答两个问题：花掉什么，换回什么。证据只引期刊论文和官方文件，末尾再用一行「说人话」把统计数字翻成日常说法。

每条建议怎么记账，证据分几档

多数鸡汤书只给态度。这本书把态度拆成可核对的四列：成本、收益口径、证据等级、原始出处。成本再拆花钱、花时间、要不要毅力；收益不跨口径硬比，寿命归寿命，钱归钱，人身自由单独记账。

字段 怎么用 读者能直接做什么
花掉什么 不花钱 / 少花钱 / 多花钱；顺手 / 几小时 / 每天占用；不用毅力 / 要一点 / 要很多 先筛「顺手且不花钱」的条目，避免一上来挑战意志力
换回什么 寿命、钱、时间精力、人身自由，不混算 同一页里不要拿「省200块」去压「少一次交通事故」
证据等级 A荟萃或RCT，B有研究，C共识或官方口径 A级优先执行，C级当地图不是当处方
说人话 把相对风险、百分点翻成生活句子 不用自己去啃森林图

仓库徽章把证据拆过一版：A级400余条、B级100余条、C级数十条，具体数随增补浮动。核实记录放在仓库docs/核实记录/，改数字要留痕迹，不是匿名改口。

  • 只引期刊论文和官方文件，不引自媒体金句
  • 按性价比排序，不是按「健康/金钱/法律」目录先排队
  • 回报算在谁头上也分档：自己最高，配偶和直系亲属其次，陌生人最低但不等于零

从少生病到被裁补偿，目录覆盖哪些真问题

书不是「早起打卡」合集。第1节「不要早死」管交通、火灾、燃气、毒蘑菇、溺水、跌落、疫苗、癌症筛查、心理危机和家庭应急装备；第2节「不要慢慢死」管烟酒、运动、睡眠、饮食、久坐。后面才轮到精力、时间、订阅和费率。

第5节「不要浪费钱」写订阅、彩票、利息、保险、基金费率、公积金提取、车险、预付款、直播带货、医保个人账户。第6节是反面清单：看起来性价比高、算完账并不高的保健品和体检套餐。第7节对着没钱的时候能领什么；第8、9节对着法律与财产、普通人容易踩的红线。

租房买房单独成节：押金被扣、房东赶人、长租公寓暴雷，对应的是流程和证据，不是情绪发泄。被裁该拿多少补偿，落在失业、合同和经济补偿金的官方口径上，书要求先查条目再开口，不鼓励凭记忆报一个「N+1」口头禅。

恋爱婚育、创业办证、程序员接单红线、账号被盗第一步，各有专节。仓库还附了几篇长文：结婚划不划算、家庭应急装备清单、遇到陌生人出事该不该停、做平台要办哪些证、生物钟和夜班。英文、俄文、西班牙文有非官方译本，一切以中文原文为准。

怎么读才不把它做成新的待办焦虑

打开检索页，用关键词、章节、证据等级、成本三个维度交叉筛。想少生病且今天就能做，先滤「不花钱 + 顺手 + A级」。想处理押金或裁员，直接搜「押金」「经济补偿」，不要从头通读608条。

仓库后来加了人生决策skill：让AI先从book/里把相关条目查出来，再按成本、收益量级和A/B/C排序回答，并注明第几节第几条。查不到就说查不到，不许凭印象编数字。本地浅克隆一次约1.3MB。

适合当备选单的读法只有三种。

  • 出事当天：搜对应节，抄官方步骤和材料清单
  • 季度一次：从反面清单划掉正在订阅的智商税
  • 身体账：只执行A级、低毅力的那几条，例如把食盐换成低钠盐这类已被条目写清成本收益的动作

不适合的读法是打卡打完全书。作者把这句话写在封面位置，不是客套。条目会继续增补——2026年9月25日还在加「生气别靠发泄、家暴保护令、职场被欺负」一组——星标和条数都会变，以仓库README和在线检索页为准。

有空就打开GitHub仓库或检索页，挑一条今天能做的。备选单的价值在少做冤枉事，不在集齐徽章。
