Cloudflare Workers AI 每天免费 1 万 Neurons

 

Neurons 到底是什么计量单位

Cloudflare 给 Workers AI 的免费额度用的单位叫 Neurons，每天免费给 1 万，官方原话是免费额度允许任何人每天使用总计 10000 Neurons。Neurons 是 Cloudflare 自己的计量单位，不是 token 数，别拿 token 的价格直接换算。跑开源大模型和 Embedding 都算在这 1 万里面，免费计划和付费计划都能用。

这笔额度不用绑卡、不用申请，注册就能领。按 perq.sh 11 月 12 日的核验表，Cloudflare 这一行在 29 个在售免费额度里，验证时间是 2026 年 11 月 12 日早上 6 点 19 分，来源指向 Cloudflare 开发者文档。

每天 1 万额度够干多少活

1 万 Neurons 每天听起来不少，实际用量要看模型。跑小模型做分类、摘要、Embedding，一天几千次调用都够；跑大模型做长文生成，几次重活就能吃掉大头。免费额度每天刷新，用不完不累计，今天省下来的不会留到明天。

横向对照一下同类免费额度，心里更有数：

平台 免费内容 领取条件
Cloudflare Workers AI 每天 10000 Neurons 无需绑卡
OpenRouter 免费模型 每天 50 次请求 无需信用卡
AkashML 100 美元一次性额度 无需绑卡

三家都是不用绑卡就能领的免费额度，区别在形态：Cloudflare 是每天刷新的推理额度，OpenRouter 是每天 50 次请求，AkashML 是一次性 100 美元。日常练手用 Cloudflare 的每天刷新最顺手，做一次性重活可以叠加 AkashML 的额度。

免费和付费计划都能领吗

能。Cloudflare 官方口径写得很清楚：Workers 免费计划和付费计划的用户都能用这 1 万 Neurons。免费计划的用户不用升级，付费计划的用户也不用另外申请，额度是平台级的，不是某个套餐的专属福利。

调用走 Workers AI 的接口，用 @cf/meta/llama-3-8b-instruct 这类模型 ID 指定模型，请求发到账号的 AI 接口地址，带上 API Token 就能跑。第一次调用之前先确认账号和 Token 配好，接口返回 401 多半是 Token 不对，返回 429 是撞上限了。

三个最适合练手的场景

第一个场景是 Embedding 和向量检索：把文档切块、调 Embedding 模型生成向量、存进向量库，1 万 Neurons 每天够跑一个中小型知识库的增量更新。第二个场景是小模型分类和摘要：客服消息分类、文章摘要、情绪判断，用小模型跑又快又省。

第三个场景是给自己的小项目接一个免费推理后端：个人博客的问答助手、浏览器插件的翻译功能，先用免费额度跑通全流程，有真实流量了再考虑付费。免费额度最大的价值不是省钱，是让你在不花钱的情况下把整条链路跑通。

老法师避坑提醒：Neurons 是 Cloudflare 自己的计量单位，不是 token 数，别拿 token 价直接换算。免费额度每天刷新，用不完不累计。免费层有速率限制，大并发会先撞限流，重活上生产之前先测好峰值。
