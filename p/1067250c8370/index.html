独立开发者 4 天用 Claude Opus 5.5 搓出恐怖游戏

 

先别急着充值，搞清这笔账怎么算

有人在 X 上晒进度：@rewind02 用 Claude Opus 5.5 跑在 Claude Code 里（疑似自动档位），配合 Godot 4.7（免费开源，MIT 协议），4 天把一款恐怖游戏的环境推到接近终版。据原帖作者自述，核心 API 成本约 90 美元，含实验约 180 美元——外部无法审计，别当成标准报价。订阅 Claude Pro 只要 20 美元/月，但 Opus 在 Code 里跑 auto 模式会疯狂吃 token，真要复刻得先掂量钱包。

第 2 天环境已接近终版，约 10 个批次 = 约 100 个道具，每组 10 个道具共享同一材质（省 credits 且风格统一）

灵感来源直指《寂静岭》与《零》，Pinterest 收参考图定调性，再扔给 Opus 让它自己跑。这不是「一键生成」，是把 AI 当成会写代码、会启动引擎、会截图迭代的超级实习生。

环境真装起来：Godot、Blender、Meshy 账号一个不少

动手前把这几样备齐：
Godot 4.7 官网直接下，免费开源 MIT 协议，别下错版本；
Blender 5.2 LTS 官网下，免费开源 GPL，用来手工拆分 Meshy 出来的批次模型（省 Claude 用量）；
Meshy 账号 注册 官网，免费档每月 100 credits、约 10 个资产，产出为 CC BY 4.0 必须署名，商用授权得升 Pro 20 美元/月起——别等上架 Steam 才发现版权不清；
Nano Banana 即 Gemini 2.5 Flash Image，Gemini App 内免费有额度，API 按量约 0.039 美元/张，用来批量出道具参考图和 2×2 网格贴图；
Claude Pro 订阅 20 美元/月，Opus 5.5 在 Code 里跑 auto 模式（改文件、跑脚本、启动 Godot、截图、持续迭代）才是核心引擎。

8 步走完：从 Pinterest 找调性到烘 AO 进道具

Step 1 上 Pinterest 搜《寂静岭》《零》关键词，存一堆氛围图扔给 Opus 定基调。
Step 2 开启 Claude Code 里跑 Opus（疑似自动档位），让它自动改文件、跑脚本、启动 Godot、截图、持续迭代——别指望它全自动到底，关键节点得人盯着。
Step 3 建筑和大结构直接用代码建，Godot 里写 GDScript 生成楼层、走廊、房间，比手搬模型快十倍。
Step 4 Opus 为每组 10 个相关道具写提示词，Nano Banana 每组出一张参考图，10 组约 100 个道具的视觉基准定下来。
Step 5 每张参考图进 Meshy t2.5（image-to-3d，smart topology）转成带贴图的批次，免费档够跑完但得署名。
Step 6 在 Blender 里手工拆分批次（省 Claude 用量），再由 Opus 按位置摆放进 Godot 场景。
Step 7 贴图：Nano Banana 出 2×2 网格图，Opus 裁成 4 张，法线与粗糙度从颜色推导，triplanar mapping 免 UV 展开——这招省下大把美术时间。
Step 8 做旧：Opus 沿墙角布置污渍贴花，把 AO 烘进道具，氛围感直接拉满。

哪里最容易翻车：免费档署名坑、credits 烧法、Blender 手工拆分的取舍

Meshy 免费档 CC BY 4.0 必须署名，商用必须买 Pro，别把免费产出直接塞进商业项目；Nano Banana API 约 0.039 美元/张，批量 100 多张道具图 + 贴图网格，钱包会痛；Opus auto 模式疯狂吃 token，作者自报 90 美元核心成本、180 美元含实验，真复刻别只算订阅费；Blender 手工拆分批次 是省 token 的关键取舍——不拆让 Opus 干，上下文窗口炸裂、账单飞涨；每组 10 个道具共享材质 是技巧（出处 dev: One_Cheek_8843），省 credits 还能统一风格，别贪多材质。Godot 版本作者未披露具体小版本，别强行对号入座。

想复刻的先掂量掂量：token 预算、美术风格锁死、商用授权另算账

这套流程核心优势是「代码搭结构 + AI 批量出美术 + 免 UV 贴图」，适合程序员主导、美术预算为零的小团队。但三个硬伤绕不开：Opus 在 Code 里跑 auto 模式不是官方功能名，随时可能变行为；Meshy 免费档产出 CC BY 4.0 必须署名，商用另付费；Nano Banana 批量出图的风格一致性 靠提示词锁死，一旦跑偏重来极贵。真要上手，建议先跑通 Step 1-3 验证代码生成质量，再砸钱跑 Step 4-8。别被「4 天出环境」冲昏头，那是大佬配合全套工具链的极限数据，普通人预留 2 周才现实。
