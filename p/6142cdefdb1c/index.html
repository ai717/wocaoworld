SolidCraft：纯 Rust 免费 CAD，还能让 AI 帮你画零件

 

五周 1.6 万星，Rust 写 CAD 凭什么火

SolidCraft 是纯 Rust 写的开源参数化 3D CAD，2026 年 10 月 7 日建仓，到 11 月 13 日核查时已经拿到约 1.6 万星，Apache-2.0 开源。五周冲到这个数字，靠的不是营销，是它把 Fusion 360 和 FreeCAD 那套参数化建模做成了轻量开源版：桌面、网页、命令行同一套命令，浏览器打开就能用。

免费 CAD 的老问题是又重又难装。SolidCraft 的解法是三端同构：Windows、macOS、Linux 都有桌面版，网页版在 solidcraft.io 上免安装，命令行和 MCP 服务跑的是同一套命令。想画个支架，打开网页就能动手，不用先下载几个 G 的安装包。

草图约束与参数化时间线怎么玩

SolidCraft 的建模流程和商业 CAD 是一个路子：先画草图、加约束，再拉伸、倒角、抽壳，改一个尺寸，整个模型按参数化时间线重新生成。功能清单包括草图约束、参数化特征、装配、钣金，文件支持 STEP、IGES、3MF、STL、OBJ 和 glTF 进出，还能导出 URDF。

仓库自带的例子很说明问题：一个树莓派 4 的外壳，从空设计开始，按电路板参数定草图尺寸，拉伸、倒角、抽壳、开孔、刻字，最后把高度从 24 毫米改成 32 毫米，模型全部重建。官方还给了对照数据，76 个公开参考零件里 75 个的体积、面积、质心和包围盒与 FreeCAD 的计算结果一致，剩下一个是已登记的 bug。

内置 MCP：让 AI Agent 直接上手建模

SolidCraft 最有野心的一块是内置的 MCP 服务。跑 solidcraft-cli mcp 就能启动模型上下文协议服务，AI Agent 可以直接驱动建模命令。Claude Code 里的接法是一行命令：claude mcp add solidcraft -- solidcraft-cli mcp，接好之后就能在对话里让 Agent 画零件、改尺寸。

除了 MCP，SolidCraft 还支持 JSON 脚本驱动：把 UI 里执行的同一批命令写成 JSON 列表，用 solidcraft-cli run 跑一遍，出的就是 STEP 文件。这种设计让 CAD 从手工软件变成了可以进自动化流水线的工具，批量出零件、参数化生成变体都不用打开界面。

还缺什么：先看清它不是完整替代品

官方自己说得很实在：目前是早期但可用的状态，适合做简单零件。复杂装配、大型项目和高级仿真还没到火候，76 个参考零件里那个没通过的 bug 就是提醒。想拿它替代 Fusion 360 做生产，现在还早；想免费练手参数化建模、或者给 AI Agent 接一个能出图的工具，它已经够用了。

上手路径建议走网页版：打开 solidcraft.io，不用安装，先画一个支架跑通草图到导出的全过程。觉得顺手再装桌面版，Windows 安装包是免费代码签名提供的，系统弹出 SmartScreen 警告时按提示操作。AI 驱动建模是加分项，不是必选项，先把手动建模跑顺，再接 MCP 也不迟。

老法师避坑提醒：早期版本别拿去接生产订单，复杂装配和大型项目还在路上。Windows 安装时 SmartScreen 可能报警，这是免费代码签名还没换成生产证书的缘故，按提示点更多信息再运行。插件接口还在 0.x 阶段，小版本升级可能破坏兼容，装插件前先看清版本要求。
