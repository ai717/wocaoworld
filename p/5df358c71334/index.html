Mac 本地免费跑大模型：Local Code 开源助手实测要点

先看内存条：三个模型档位怎么选

想在 Mac 上玩 Local Code，第一步不是下载，是看自己的统一内存。官方给的模型选项很实在：Qwen 3.8 27B 有 9.6GB、21.3GB、29.2GB 三档量化，内存小的 Mac 选小档；DeepSeek 4 Flash 0731 约 89.4GB；DeepSeek 4.1 Flash 1017 更是 376GB 和 412GB 两档——这已经不是给普通 Mac 准备的了，没有 128GB 以上统一内存就别惦记。

选档位的逻辑也简单：内存有多大，就下多大的档。8GB 的 MacBook Air 老老实实 9.6GB 档，做文本摘要、代码补全够用；16GB 及以上再考虑 21.3GB，体验会顺很多。别想着小内存硬上大模型，加载到一半被系统杀掉，纯属浪费时间。

从 getlocalcode.app 到第一次对话

安装走官网：去 getlocalcode.app 直接下载，README 原文就这么写的，双击装上就能用。官方发布帖落款 2026 年 10 月 28 日，公测其实从 9 月 12 日就开始了，MacRumors 在 10 月 30 日做了报道。仓库建于 10 月 21 日，叫 drawthingsai/local-code-community，背后是 Draw Things 团队——就是那个做 iOS 上本地跑 Stable Diffusion 的团队，搞本地推理是他们的老本行。

目前只有 Mac 版，App Store 版本官方说在路上。Windows 和 Linux 用户先别等，短期内没戏。下载完把模型拉到本地，断网也能聊，提示词和文件都在本机处理，不经过任何云端。

沙盒不是摆设：四种环境干真活

Local Code 和一般聊天 App 的区别，在于它内置了 Python、Node.js、Shell、浏览器四个沙盒，模型不只会说话，还会动手。官方列的能力包括：做幻灯片、生成图片和视频、分析表格、处理 Word 和 PowerPoint 文档——都是真实任务，不是演示动画。

比如让它做一份带图表的报告，它可以在 Python 沙盒里跑数据分析、画图，再把结果组装成文档；要批量处理文件，Shell 沙盒直接上；前端小活丢给 Node 沙盒。四个沙盒共享同一个模型上下文，任务链条不断。Mac 的 App Sandbox 会限制它的文件访问权限，这是苹果的安全机制，不是 bug，第一次用记得按提示授权。

免费的边界：本地免费、云端另算

价格口径要掰开看：本地跑模型完全免费，这是 GPL-3.0 开源项目的基本盘。但如果你想用云端模型，得走自己的 API Key，或者买它的预付 credit，$9.99 起。免费的是软件和本地算力，不是云端 token。

另外 GPL-3.0 是 copyleft 许可，个人用、公司内部用都没问题，但要二次分发或嵌进闭源产品，就得把衍生代码也开源。以及提醒一句：它还是公测阶段，遇到怪 bug 别惊讶，去 GitHub 提 issue 比干等靠谱。
