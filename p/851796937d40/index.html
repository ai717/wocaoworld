10 个开源仓库拼成 AI内容工厂：调研到分发全链路实测

 

别再手动拼凑工作流了，这 10 个仓库直接给你一条龙

刷到 @Zara__Ai 的那条推 时，我正盯着硬盘里七八个半吊子脚本发呆：一个跑 Whisper 转字幕、一个调 Edge-TTS 配旁白、再手动套 CapCut 模板、最后还得人工上传排期。中间断点多、格式对不齐、API 账单更是查无此人。她甩出来的 10 个仓库，恰好把「调研→脚本→配图→配音→配乐→剪辑→分发」七个环节全覆盖，且大多走本地推理、只在 LLM 调用处掏钱。下面不废话，直接上实测对比与避坑要点。

前置调研层：别让大模型瞎编，先喂它真数据

Social Media Research Skills 不是传统爬虫，而是给 Social Media Agent 这类 Agent 预置的 13 个「技能包」：爆款挖掘、评论挖矿、竞品拆解、广告库拆解、趋势发现……仓库 MIT 协议免费，但底层数据全走 ScrapeCreators 付费 API，别看到「免费」就以为能白嫖全网数据。配合 Local Deep Research 用：后者 Docker 一键起（curl -O docker-compose.yml && docker compose up -d 打开 http://localhost:5000），挂本地 Ollama 模型多轮搜索、迭代推理，最后吐带引用的调研报告，纯本地零成本。再接 Social Media Agent，扔进竞品 URL 自动出 X/LinkedIn 草稿，带人工审核与定时发布。注意：Agent 仓库免费，跑起来得绑 Anthropic LLM、FireCrawl（新用户 500 点数）、Arcade 授权，隐形账单别忽视。

生成层：图文声乐视频，哪个环节最烧显存？

配图环节 FLUX.2 是 Black Forest Labs 官方最小推理库。klein 4B 版 Apache-2.0 可免费商用，消费级显存亚秒出图；但 9B 与 32B dev 版走 FLUX Non-Commercial License 禁商用，官方 API 另收费——这点搞错直接侵权。配音用 Kokoro，82M 参数、pip install kokoro 即用，8 语言 54 音色，本地免费跑；第三方托管 API 大约 $0.65~0.80/百万字符，量大可算账。配乐直接上 ACE-Step 1.5，2B turbo 版 <4GB 显存就能跑完整带人声歌曲，git clone && uv sync && uv run acestep 打开 http://localhost:7860，另有在线站 acemusic.ai 免费试水。视频剪辑有两条路：Short Video Factory 是国人写的 Electron 桌面端，Releases 下载即用，提示词+素材一键批量出营销短视频，Edge-TTS 免费语音+自动剪辑+字幕全本地；AI YouTube Shorts Generator 专攻长视频转竖屏 Shorts，LLM 判高光+Whisper 转录+9:16 自动裁剪无水印，本地模式仅 LLM 调用花钱（默认 gpt-4o-mini 或 gemini-2.5-flash）。想把上游全串起来，OpenCreator（原 KrillinAI）是目前唯一把下载/翻译/配音、图片生成、语音、Avatar、剪辑全塞进一个本地优先工作区的项目，约 14000 stars，Apache-2.0。桌面版去 Releases 拿安装包，Web 版 git clone 后访问 http://127.0.0.1:19861/，软件免费，跑模型需 Codex 登录（ChatGPT 账号或 API Key）。

打包分发层：把成品变成播客、Shorts、定时帖

Podcastfy 是 NotebookLM 播客功能的开源平替，pip install podcastfy 后把 PDF、网页、视频、音频扔进去，多语言双人对话播客直接出。包免费，需自备 LLM 与 TTS Key（或用免费 Edge TTS）。配合前面的 Short Video Factory 或 AI YouTube Shorts Generator 出竖屏，再走 Social Media Agent 排期发布，基本形成「素材进、成品出、自动发」的一条龙。

横向对比：协议、显存、隐形钱包、上手曲线一眼看穿

仓库 覆盖环节 协议/商用 真实成本 上手难度
Social Media Research Skills 选题调研/竞品拆解 MIT（仓库免费） 底层 ScrapeCreators API 按量付费 低（npx 安装技能包）
Local Deep Research 深度调研报告 MIT 纯本地 Ollama 零成本 中（Docker+配置模型）
Social Media Agent 文案生成/排期发布 MIT Anthropic+FireCrawl+Arcade 组合付费 高（需多平台授权）
FLUX.2 配图生成 klein 4B Apache-2.0 可商用；9B/32B 禁商用 本地免费/官方 API 付费 中（需部署推理库）
Kokoro 配音/TTS Apache-2.0 本地免费/第三方 API ~$0.65/百万字符 极低（pip install 即用）
ACE-Step 1.5 配乐/带人声歌曲 MIT 本地免费/在线站免费试用 中（uv 环境+显存≥4GB）
Short Video Factory 短视频批量剪辑 AGPL-3.0 全本地免费 低（Releases 下载双击）
AI YouTube Shorts Generator 长转短/高光裁剪 MIT 仅 LLM 调用成本（gpt-4o-mini 等） 中（需配置 Whisper+LLM Key）
OpenCreator 全链路工作区 Apache-2.0 软件免费/Codex 登录跑模型 中（桌面版开箱/Web 版需 Node）
Podcastfy 多模态转播客 Apache-2.0 包免费/自备 LLM+TTS Key 低（pip install+填 Key）

四类创作者的组装清单，别再全买全装

个人博主/周更视频号：Local Deep Research 做选题 → Kokoro 配旁白 → FLUX.2 klein 出封面 → Short Video Factory 批量剪 → Social Media Agent 定时发。全链路本地跑，月成本约等于几杯咖啡钱。
带货切片/矩阵号运营：AI YouTube Shorts Generator 批量切竞品长视频 → OpenCreator 统一翻译/配音/水印 → Short Video Factory 加字幕/钩子 → Social Media Agent 多账号排期。重点利用 OpenCreator 的批量翻译与 Avatar 功能省人工。
播客主/知识付费讲师：Local Deep Research 生成大纲 → Podcastfy 直接把文档/网页变双人对话播客 → ACE-Step 1.5 生成片头曲/转场音乐 → OpenCreator 做视频版切片分发小红书/视频号。
社媒运营/代运营团队：Social Media Research Skills 挖爆款/挖评论 → Local Deep Research 出竞品分析报告 → Social Media Agent 批量产出 X/LinkedIn 草稿 → 人工审核 → 定时发布。核心成本在 FireCrawl 与 Anthropic，建议先跑免费额度验证 ROI 再扩量。

别被「全自动」忽悠，每个仓库都有各自的坑：FLUX.2 版本许可证别搞错、Social Media 类工具底层 API 才是大头、OpenCreator 依赖 Codex 登录意味着得有 ChatGPT 账号或 API Key。先按场景挑 3~4 个跑通最短路径，再考虑往工厂里加机器。代码都在 GitHub，手快有、手慢无，克隆完记得给颗星再改代码。
