智谱GLM-5.2发布：编程能力逼近Claude Opus 4.8，开源即王炸

大模型编程赛道再掀巨浪。智谱于6月13日发布新一代模型 GLM-5.2，当天傍晚即面向Coding Plan全量用户开放，覆盖Lite/Pro/Max/团队版。更令人瞩目的是，官方原定下周上线的API与开源计划，在6月16日已提前落地——GLM-5.2 权重正式开源至Hugging Face，约753B参数，MIT协议，vLLM、SGLang、transformers等主流推理框架同步支持，独立API也同步上线并纳入Coding Plan。提速之快，姿态之开放，远超市场预期。

GLM-5.2核心亮点：百万Token上下文与High模式

GLM-5.2 将上下文窗口直接拉升至100万Token，为长文本理解与复杂代码重构提供了前所未有的空间。同时新增的High（高速/高强度）模式，让开发者可在推理速度与精准度之间灵活切换，真正实现“生产力优先”。

编程基准实测：逼近Claude Opus 4.8，开源模型首破80%

早期第三方测评显示，GLM-5.2 整体编程能力约为Claude Opus 4.8的94%左右。开源后社区实测进一步出炉：据Cline等测试，GLM-5.2 成为首个在Terminal-Bench上突破80%的开源权重模型，并在LLM Benchmark Code V3私有评测中位列全球第三。尽管官方完整benchmark尚未集中公布，但这一成绩已让开发者社区沸腾。

开放生态与配套工具：ZCode 3.0.0自研Agent内核

智谱强调大模型应是「开放、可用、可构建，并服务于每一位开发者」。GLM-5.2 的开源与API同步推进，正是这一理念的落地。配套编程工具 ZCode 同步升级至3.0.0，切换为自研Agent内核，新用户可免费体验GLM-5.2 的强大能力。目前，Fireworks AI、Z.ai开放平台等官方与第三方渠道均可调用，构建开发者生态的意图十分清晰。

更多信息请访问官方博客：https://z.ai/blog/glm-5.2，开源权重地址：https://huggingface.co/zai-org/GLM-5.2。
