Colab Playground：把 Colab 配额装进桌面点几下就开跑

 

Colab CLI 套了个壳：先讲清它到底管什么

Colab Playground 是官方 Colab CLI 的桌面图形界面，用 Rust 与 GPUI 写成，支持 Windows、macOS Apple silicon 与 Linux，免安装。它不是笔记本编辑器，也不替代命令行，所有操作都走 colab 命令，本质是把开运行时、选硬件、看余额这些命令行操作搬进图形界面。项目 2026 年 11 月 16 日才建仓，到 11 月 19 日已有 274 个 star，MIT 协议，尝鲜属性很明显。

多账号余额一眼看完：切换之前先看清影响

手里不止一个 Google 账号的人最懂这个痛点：哪个账号还有 Colab 计算单元，哪个已经烧空，切来切去全靠猜。Colab Playground 把多个账号统一管起来，余额总览一次看完，切换前还会列出这次切换会影响什么。开运行时能选 CPU、GPU、TPU 与高内存，还能设最低显存；Colab 随机给 A100 40GB 或 80GB，显存不够就退回重开，不用手动反复试。浏览器里开的运行时也会列出来，可以顺手停掉。本地跑源码也很直接：cargo run -p colab-playground 是演示数据模式，不会产生账单；cargo run -p colab-playground --release 才是接真实 Colab CLI 的模式。

费用保护分两层：运行时自动停才是真兜底

Colab 的计费规则很实在：运行时存在多久就收多久的计算单元，忙不忙都算钱，关掉应用与端口转发都不会停费，只有停机、自动停机或 Colab 自己回收才停。Colab Playground 的费用保护分两层：定时与闲置自动停止跑在运行时一侧，关掉应用也管用；花费上限与余额下限只在应用运行时才检查。两层别搞混，真兜底的是运行时侧的自动停止，上限与下限只是应用开着时的提醒线。余额、烧钱速度与剩余时间都在总览页实时显示。

填个 GGUF 仓库：Colab GPU 秒变聊天接口

插件机制是这个项目最讨喜的部分。自带 llama.cpp 插件，填一个 Hugging Face GGUF 仓库地址，就能在 Colab GPU 上一键部署模型，给出 OpenAI 兼容 API 与网页聊天界面，不用自己写部署脚本。插件脚本只跑在 Colab 运行时上，不跑在本机，装插件之前先认准来源。端口转发也顺手：运行时端口映射到本机的 127.0.0.1，部署好的模型在本机浏览器里就能直接用。

三天大的项目：尝鲜之前先认清这三点

第一，项目非常新，2026 年 11 月 16 日建仓，功能与文档都还在长，遇到小毛病别意外。第二，它管的是你自己的 Colab 账号与账单，CLI 在整台机器上只有一个登录账号，应用里切换账号会影响其他地方的 colab 使用，旧账号下没停的运行时会继续计费。第三，Windows 上 Colab CLI 跑在 WSL 里，装之前先确认 WSL 就绪。认清这三点再装，尝鲜才不会变成踩坑。
