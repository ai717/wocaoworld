7 个开源 Skill 解锁 Claude Code 游戏开发与 3D 全流程

 

别再把 Claude Code 只当代码助手，它连 Blender 骨架都能帮你绑上

上周在群里看见有人甩出一张截图：Claude-Code-Game-Studios 以「工作室模式」跑了 19 分钟，账单 约 $5，却直接吐出一个能在 Godot 4 里跑的完整小游戏原型。同一个人把同一需求扔给普通 Claude Code，38 秒、$0.15 就结束了——区别不在模型，而在那 49 个 Agent 和 72 个工作流技能组成的「虚拟工作室」是否被调度起来。这事儿戳中痛点：大家手里攥着 3.8 万星 的开源技能库，却把它当成普通聊天机器人用，Token 白烧、能力白浪费。

这篇不讲「如何入门」，直接把 GitHub 上能找到的 7 个面向「做游戏、做 3D」的开源 Skill 库摊开对比：Claude-Code-Game-Studios、agent-sprite-forge、teardown、blender-skills、3D OS (scenario-labs/skills)、prompt2rig、open-3d-skills。星数均为 2026-11-13 核查约数，全是 MIT/Apache-2.0 协议，**技能本身免费**，但跑起来要吃 Claude Code 订阅（Pro 起步 $20/月）+ 可能触发的图片/视频/3D 模型 API 费，成文前把「技能免费、用量不免费」讲清楚。

7 个 Skill 逐个拆解：能干啥、怎么装、藏着啥坑

1. Claude-Code-Game-Studios —— 把 Claude 变成「虚拟游戏工作室」

约 38,780 星，MIT，v1.3.0（2026-11-09）。49 个 Agent、72 个工作流技能，覆盖需求分析、架构设计、代码生成、资源管线、测试打包全链路。原生支持 Godot 4、Unity、Unreal Engine 5 三大引擎。安装就是三行：git clone https://github.com/Donchitos/Claude-Code-Game-Studios.git my-game → cd my-game → claude 进交互后输入 /start。前置只有 Git + Claude Code 订阅。README 自己承认「不是自动驾驶」，复杂项目仍需人类把关架构与美术风格。第三方实测：工作室模式 19 分钟约 $5，普通模式 38 秒约 $0.15，差价全在 Agent 协作与多轮迭代的 Token 上。

2. agent-sprite-forge —— 一句话生成「游戏级」精灵帧

约 5,589 星，MIT，v0.6.0（2026-11-13）。核心能力：自然语言 → 2D 精灵图 + 动作帧 + 透明 PNG 序列 + GIF/WebM/MP4。导出格式直接对接 Godot (SpriteFrames/Sprite3D)、Unity、Aseprite JSON、Tiled/LDtk 地图编辑器。关键细节：图片/视频生成走外部模型（OpenAI、Gemini、xAI、fal.ai 等），**按各家计费**，Skill 只负责编排 Prompt、切帧、重命名、打包。想白嫖只能自己接本地 Stable Diffusion / ComfyUI，官方没内置。

3. teardown —— 把发动机、机械表、挖掘机臂变成「可拆解的离线 HTML 3D 模拟器」

约 3,348 星，MIT。输出单文件 HTML，拖进浏览器就能拆、转、看爆炸视图，还带真实读数面板（转速、压力、扭矩等），支持录视频导出。安装走 Skills 协议：npx skills add elvarofficial/teardown -g -a claude-code → npm install && npx playwright install chromium，需 Node.js 20+。作者明示：**生成的是示意模拟器，不是工程仿真，面板数字是演示用的**，别拿去做真受力分析。

4. blender-skills —— 94 个 Blender 专家技能，但得配 MCP 插件才能「真动刀」

约 2,500 星，MIT，v1.3.0。技能覆盖建模、材质、绑定、动画、渲染、几何节点等 94 个细分场景，兼容 Cursor / Claude Code / Kiro / Codex。关键前置：必须装 MCP for Blender 插件，Skill 才能通过 MCP 协议真正在 Blender 里增删改查对象、跑脚本。安装方式：git clone 后把 .claude/skills 文件夹复制到项目或全局配置目录。没有 MCP 插件时，它只能给你吐 Python 代码片段，人工复制粘贴进 Blender 控制台跑。

5. 3D OS (Scenario 官方) —— 6 部门 80 技能，直驱 Blender/Maya/ZBrush/Unreal/Unity/Godot/Roblox

MIT，Scenario 公司维护。架构按「美术、技术美术、动画、引擎集成、管线、审核」六部门拆分，80 个技能。最大区别：**专家工具直接驱动本机 DCC 软件与引擎**，不走「生成代码再人工粘贴」这套。内容生成走 Scenario 账号（Scenario MCP），意味着模型费用绑定 Scenario 订阅/额度，不再是各家 API 任选。安装：npx skills add scenario-labs/skills。适合已有 Scenario 企业版或团队订阅的工作室，个人开发者算账时要把 Scenario 订阅费摊进去。

6. prompt2rig —— 文字 → 视频演动作 → 本地 GPU 提 3D 动作 → 重定向到 Mixamo 骨架 → 导出带动画 .glb

约 575 星，Apache-2.0。链路很硬核：Prompt → 视频模型（如 Gen-3、Luma 等，需 fal API key，按量付费）生成参考视频 → 本地跑 GVHMR / SMPL-X 提取 3D 动作 → 重定向到 Mixamo 标准骨架 → 输出 .glb。自带角色仅 X Bot、Michelle、Soldier 三个。大坑：**HQ 路线用的 GVHMR、SMPL-X 等为研究/非商业授权，商用不能直接用**，得自己换商业友好模型或买授权。适合原型验证、非商业短片、教学演示，商业游戏上线前请务必确权。

7. open-3d-skills —— 8 个面向「网页 3D」的技能，不碰游戏引擎

约 360 星，MIT。技能列表：Three.js 场景搭建、滚动驱动叙事影片、透明视频合成、光标交互绑定、爆炸视图展示等。定位 **Web 3D / 交互网页 / 产品落地页**，不生成游戏引擎资产。安装同 Skills 协议。适合前端做可视化、电商 3D 展示、数据大屏，别指望它帮你出 Unity Prefab。

真实成本与隐形门槛：别被「开源免费」忽悠了

七个仓库代码全免费、协议宽松，**但跑起来的钱包出血点在三层**：

  • 基础订阅：Claude Code Pro $20/月是门槛，想跑工作室模式、多 Agent 协作，Token 消耗指数级上涨，实测单次 19 分钟 $5，按天算就是 $150+，月费不止 $20。
  • 模型 API 费：agent-sprite-forge 要调图片/视频模型，prompt2rig 要买 fal 视频模型额度，3D OS 绑定 Scenario 订阅。这些费用**完全不在 Skill 仓库控制范围内**，官方文档也不会帮你算账。
  • 本地算力与授权：prompt2rig HQ 模式跑 GVHMR/SMPL-X 需要像样的 N 卡显存（建议 12GB+），且模型授权多为非商业，**商用必须自行置换模型或买授权**，这是隐形法律成本。

对比一下：teardown 和 open-3d-skills 仅消耗 Claude Code Token，本地跑完无额外模型费，属于「边际成本最低」的两个；blender-skills 装上 MCP for Blender 后也是本地跑 Python，只要显存够 Blender 跑几何节点就行，额外成本为零。

架构差异：谁在本地跑、谁在云端调、谁靠 MCP 直连

把 7 个 Skill 按「运行拓扑」分三派：

  1. 纯云端编排派：Claude-Code-Game-Studios、agent-sprite-forge、3D OS。核心逻辑在 LLM 推理侧，本地只跑构建脚本或导出器，重资产生成（图/视频/3D）全靠外部 API。
  2. MCP 直连本地 DCC/引擎派：blender-skills、3D OS（双轨）。通过 MCP 协议把 Blender、Maya、Unity Editor 当成「工具函数」暴露给 LLM，**LLM 直接下指令「新建立方体、加材质、导出 FBX」**，中间零人工复制粘贴，但要求本地装全套软件且版本对齐。
  3. 本地推理 + 本地导出派：teardown、prompt2rig（部分）、open-3d-skills。核心计算（GVHMR、Three.js 渲染、Playwright 录屏）在本机跑，LLM 只负责写胶水代码/配置参数，离线可用、数据不出门。

选哪派取决于你的管线现状：已有全套正版 DCC + 稳定 GPU → 选 MCP 直连派；团队轻量、靠云端模型出图 → 选纯云端编排派；做网页交互、教学演示、不想装几十 G 软件 → 选本地导出派。

按场景选工具，别全装

  • 想从零跑通一个 Godot/Unity/UE5 小游戏原型 → 直接上 Claude-Code-Game-Studios 工作室模式，接受 $5/次 的 Token 账单，别试图用普通模式省钱，省不出完整管线。
  • 只缺 2D 美术：角色走跑跳、UI 图标、地图瓦片 → agent-sprite-forge，自己接本地 ComfyUI 能省模型费，接云端 API 算单张成本约 $0.02-$0.15，批量出图算账再决定。
  • 做机械原理演示、产品拆解视频、教学课件 → teardown，输出单 HTML 扔给甲方/学生/网页端，零部署成本，记得在页面加水印「数据仅供演示」。
  • Blender 重度用户，想让 LLM 帮你跑几何节点、批量重拓扑、一键导出引擎格式 → 装 blender-skills + MCP for Blender，前置花半小时配环境，后续每天省小时级重复操作。
  • 工作室已买 Scenario 企业版，要把美术→技术美术→引擎集成全自动化 → 3D OS，别自己拼 MCP，官方维护的 80 技能覆盖全管线，订阅费摊到项目里算 ROIs。
  • 需要「文字生带动画 3D 角色」用于原型/短片/非商业演示 → prompt2rig，准备好 fal API key 和 12GB+ 显存，**商用项目前把 GVHMR/SMPL-X 换成商业授权模型**，否则交付就是侵权。
  • 前端做 3D 产品页、数据可视化大屏、滚动叙事长图 → open-3d-skills，直接生成 Three.js 代码粘进 Vue/React/Next.js，无需引擎运行时，包体最小。

最后唠句实在的：这 7 个 Skill 像 7 把瑞士军刀，刀刃锋利但得你自己会拧螺丝。**不要一次性全 clone 进项目**，会把 .claude/skills 目录塞成垃圾场，Token 还会因上下文污染乱跳。按当前冲刺目标选一把，跑通最小可玩版本，再考虑下一把。技能免费，你的时间和 Token 不免费。
