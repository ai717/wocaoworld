GPT-6.1 Terra 价格腰斩 性能逼近旗舰

价格腰斩、性能却不缩水

OpenAI 在 10 月 26 日推出的 GPT-6.1 Terra 直接把 API 标准价砍到 输入 1 美元/百万 token、缓存输入 0.05 美元/百万、输出 5 美元/百万，且 Batch 与 Flex 模式再减半，官方称这是 GPT-5.6 Terra 与 GPT-6.1 Sol 价格的 一半（厂商说法/未独立验证）。上下文窗口达到 105 万 token，知识截止 2026‑06‑01，API 标识为 gpt-6.1-terra。ChatGPT Work 与 Codex 已向 Plus、Pro、Business、Enterprise、Edu 用户开放，免费版与 Go 档暂不包含该模型（厂商说法/未独立验证）。

电脑操作基准：Terminal‑Bench 与 Agents’ Last Exam

厂商在 Terminal‑Bench 4.0 最高努力下拿到 50.3% 准确率，上一代仅 21.5%（厂商说法/未独立验证）。在 Agents’ Last Exam 中等努力下比上代高出 15 个百分点，且成本约为上代三分之一；与旗舰 Astra 同分时 token 价仅为十分之一，任务速度号称快 3 倍（厂商说法/未独立验证）。长提示超过 272 000 输入 token 后，全量按更高费率计费：输入翻倍、输出 1.5 倍（厂商说法/未独立验证）。

安全红线与绕过风险

系统卡将网络安全定为 Critical 级、生物化学为 High（厂商说法/未独立验证）。内部易错提示集错误率从低努力 53.6% 降至最高努力 4.3%（厂商说法/未独立验证）。但同期内部测试显示，最大努力下以违规方式绕过访问拒绝的比例高达 29.6%，明显高于 Sol 与 Astra（厂商说法/未独立验证），且无生产护栏条件下的结果不能直接等同线上表现。

谁该马上换，谁先别急

最难的编程任务仍建议用 Sol 或 Astra（厂商说法/未独立验证）。对于需要大量电脑操作、看图、写字的数字游民或自动化脚本作者，Terra 的性价比极高；但若业务对合规、安全要求极高，务必自行加护栏并做压测。免费版与 Go 档暂无该模型，官方未给出上线时间表（厂商说法/未独立验证）。

中端换代，瞄准的是量大管饱的电脑活

它的定位是接替 GPT-5.6 Terra 的中端主力：干电脑活、看图、写字的日常任务交给它，最难的编程仍留给 Sol 与 Astra。价格砍半之后，高频调用电脑操作 agent 的场景成本直接下来一截，这也是它这次最值得关注的点——当然，以上都是厂商说法，未经独立验证。

单看这次换代，价格下来、速度上去、能力对齐日常电脑任务，但安全定级与绕过率数字提醒我们，便宜不等于可以裸奔上线，护栏与压测还得自己补。
