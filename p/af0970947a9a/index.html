Inception新Key送1亿免费Token：Mercury 3白拿

 

新 Key 送 1 亿 Token：免费额度怎么领

每个新建的 Inception API Key 都送 1 亿免费 Token，适用 Mercury 3 模型，100 万上下文，不用绑卡就能开领。Inception 平台的规则很直接：注册账号、创建一个 API Key，1 亿 Token 自动到账，按官方文档的说法，不需要提供付款信息就能开始用。额度是一次性的，用完之后按量付费继续用，不是每月都送。10 月 20 日本站发过 Mercury 3 首发半价的文章，讲的是模型本身；这篇讲的是免费额度的领取与花法，角度不同。

1 亿 Token 能干多少活：先按官方价算账

Mercury 3 的发布价是输入每百万 Token 0.10 美元、输出每百万 0.35 美元，缓存输入每百万 0.01 美元，标价是输入 0.20 美元、输出 0.70 美元，发布价相当于五折。按发布价算，1 亿免费 Token 大约值 10 到 35 美元，取决于输入与输出的比例。跑测试、接原型、做小工具完全够用；跑生产流量就不够看了，用完就得绑卡付费。模型本身是扩散式大语言模型，官方称生成速度 1068 Token 每秒，OpenRouter 实测中位数 160 到 254 Token 每秒，别拿官方峰值当日常速度。

三行代码接进来：OpenAI 兼容不用改 SDK

接口兼容 OpenAI 格式，换个 base_url 与模型名就能用。调用地址是 https://api.inceptionlabs.ai/v1/chat/completions，模型 ID 是 mercury-3，现成的 OpenAI SDK 直接能接。Mercury 3 支持工具调用与结构化输出，100 万上下文一次能塞进整本手册再提问。除了自家平台，也能走 OpenRouter、Baseten 与 Vercel AI Gateway 接入，免费额度只在自家平台的新 Key 上有。

免费额度花在哪最值：先算清 1 亿 Token 的花法

第一类是跑通调用链：第一次接扩散式模型，先拿免费额度验证速度与质量，再决定要不要迁移。第二类是做小工具与原型：100 万上下文适合塞长文档做问答，免费额度够跑好几轮测试。第三类是对比评测：同样的提示词跑 Mercury 3 与其他模型，看速度与质量差多少，再决定主力用谁。三类之外，别拿免费额度跑生产流量，额度一空服务就停，线上业务别押在一次性额度上。
