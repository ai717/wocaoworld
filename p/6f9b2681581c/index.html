10 分钟Cloudflare 构建永久免费高速节点

在 2026 年，寻找一个既稳定又免费的网络出口似乎已成奢望。然而，回归技术本质，利用 Cloudflare 的全球边缘计算网络（Edge Network），我们依然能构建出一套“一次部署，终身免维护”的轻量级代理方案。

这套方案不仅能解锁 ChatGPT 与 Gemini，更因其依托于 Cloudflare 的原生骨干网，在稳定性与抗封锁能力上远超传统 VPS。

一、 基础设施：注册永久免费域名

一切稳健的连接都始于一个属于你自己的域名。2026 年，我们依然有渠道获取免费资产。

  • 资源获取：

    • 渠道一：https://ccwu.cc 或 https://us.ci

    • 优势：注册后可获得 5 个永久免费域名，根域名选择建议优先考虑 .ccwu.cc 或 .us.ci。

  • 解析托管：将注册好的域名托管至 Cloudflare (https://www.cloudflare.com/)。这是所有后续操作的控制中心。

二、 云端配置：存储与计算的结合

我们需要在 Cloudflare 内部构建一个微型应用。

  1. 创建 KV 空间：进入 Cloudflare 后台，导航至 存储和数据库 -> Worker KV。创建一个命名空间，它将作为配置信息的“持久化记忆”。

  2. 部署 Pages 服务：

    • 进入 Workers 和 Pages，选择创建 Pages 应用。

    • 核心源码：使用由 CMliu 开源的节点程序。你可以从 GitHub (https://github.com/cmliu/edgetunnel) 获取，或直接下载预打包的 main.zip。

    • 上传与构建：直接上传压缩包，CF 会自动完成边缘部署。

三、 逻辑绑定：环境变量与 CNAME

这是决定节点能否正常“呼吸”的关键步骤。

  • ADMIN 变量：在设置中添加环境变量 ADMIN，值即为你的管理员后台密码。

  • KV 绑定：将之前创建的 KV 空间绑定至 Pages，变量名统一填写为 KV。

  • 自定义域（CNAME）：不要直接使用 CF 分配的 .pages.dev（容易被墙）。在自定义域选项卡中，填入你的二级域名（如 moyu.ccwu.cc），并根据提示完成 DNS 的 CNAME 解析。

四、 最终形态：全协议支持与优选加速

通过访问 https://你的域名/admin，你将进入一个可视化的管理后台。

  • 协议全家桶：支持 VLESS、Trojan 等主流加密协议。

  • 订阅系统：内置订阅转换，支持 Clash、Sing-box、Surge 等全平台客户端。

  • 高手进阶：支持自定义 ProxyIP 链式代理及优选 API。通过优选 Cloudflare 的边缘节点 IP，你可以显著降低延迟，将 4K 视频体验提升至秒开级别。

这不只是一个简单的翻墙教程，这是一次对边缘计算能力的极限压榨。在零成本的前提下，你获得的是一个由全球顶级 CDN 支撑的永久节点。
