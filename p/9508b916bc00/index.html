MoneyPrinterTurbo近12万星：能批量出片，印不出平台分成

仓库很勤快，名字比现金流更夸张

harry0703/MoneyPrinterTurbo 把关键词变成一条流水线：大模型写文案、按关键词去素材库拉片子、配旁白和字幕、压上 BGM，最后用 ffmpeg 合成 MP4。星标大约 12 万，MIT 协议，Web 界面加 API，还能批量出几条再挑。本地、Docker、Colab 都能跑。它叠的是无脸频道那套工序，不是一台提款机。

模型可接 Claude、DeepSeek、GPT、Gemini、Kimi 以及兼容网关；语音有 Edge TTS、Azure、MiniMax、Fish Audio 等。画幅在 16:9 和 9:16 之间切。素材默认走 Pexels、Pixabay 这类需申请密钥的库存源，新版本也接了部分文生视频通道，并可改用本地文件。没有 LLM 密钥和素材密钥，界面只是空表单。

自动的是装配，不是选题和过审

同一关键词连出五条，画面仍可能是通用航拍加正确的废话。库存片段的授权通常允许个人和部分商业使用，不等于可以无视署名、再包装转售，也不等于短视频平台会给流量。账号被判同质化、搬运或误导时，合成速度帮不上忙。

环节 工具能代劳 仍然要人判
文案 按主题起草 事实、立场、平台违禁词
画面 按关键词检索或生视频 是否对得上旁白、会否重复
声音字幕 TTS 加描边字幕 口误、节奏、字体可读
发布变现 最多生成各平台说明文案 审核、投流、版权投诉

运行要 Python 3.11 和 ffmpeg，文档建议至少四核、4GB 内存，显卡不是必须。v1.3.5 起可为接口加密钥，避免局域网里谁都能调生成任务。配置文件和预设导出里可能带着各类 API Key，不能提交进公开仓库。

造片成本下降，频道策略没有跟着下降

无脸科普、清单、冷知识这条流水线被摊开后，后来者用同一套库存镜头会更挤。适合拿它打样、测旁白和字幕样式；不适合把「近 12 万星」读成稳赚信号。先算清每次生成烧掉的模型和素材额度，再决定要不要养号。印钞机印的是成片文件，分成表还在平台手里。
