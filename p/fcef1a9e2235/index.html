Claude Code 远程给电视去广告：禁 25 个小米包换苹果风主屏

开机先看赞助广告？这回连包名都不用你背

父母屋里的小米电视，开机先看赞助广告，桌面上还堆着推荐行。2017 年 Vizio 就因未经同意追踪 1100 万台电视观看行为赔了 220 万美元。Gathin T. 受不了这套，直接把 Claude Code 扔进同一 Wi-Fi，丢个电视型号和 IP，让 AI 自己顺着 ADB 把 25 个小米包 pm disable-user 了，再装一个 Apple TV 风格启动器 当默认主屏。提示词整理成 cleanyourtv 开源，两天几千人照着跑通。

先把电视调成「可被 AI 摆布」的状态

动手前只需三样东西：同一 Wi-Fi 下的电脑、电视型号、电视局域网 IP。电视端进「设置 → 关于 → 版本号」连按 7 下开开发者选项，再进「设备偏好设置 → 开发者选项」把 USB 调试 和 网络调试 全打开，记下屏幕上显示的 IP 地址。电脑端装好 adb 与 Claude Code，把仓库里的 PROMPT.md 里的电视型号和电视 IP 填上，剩下的交给助手。

注意：仅限 Android TV / Google TV（小米、TCL、索尼、海信等）；三星 Tizen、LG webOS 这类非安卓系统根本跑不起来。

一条提示词跑完「备份 → 禁包 → 换主屏 → 写还原」

把填好型号和 IP 的 PROMPT.md 发给 Claude Code，它会先连上电视、把当前包列表备份到电脑，并生成一键还原脚本。接着按 项目清单 逐条 pm disable-user --user 0 包名，只禁用不卸载，保留数据也保留回退路。禁用的是厂商遥测、广告服务与推荐行一类包，逐项确认自己在用的应用、投屏、语音遥控、系统更新是否保留，别把自家常用的功能一起禁了。最后把自制启动器装好并设为默认主屏。电视弹出「允许 USB 调试？」点确认，全程不用拔线、不用 root、不用刷机包。

翻车现场：已有网友把安卓电视搞成变砖——要么禁掉了关键系统服务导致启动循环，要么主屏没设好回不了桌面。动手前务必把备份的包列表和一键还原脚本拉到电脑留存，搞砸了只能恢复出厂设置，数据全无。把「系统更新」「投屏接收」「常用视频应用」对应的包名从禁用清单里划掉，哪怕多留几个广告包也比变砖强。

为什么不直接 root 或刷第三方固件？

pm disable-user 只是把包停用、进程冻结，不动系统分区，重启也不会自动恢复禁用状态。Root 要解锁、刷机，适配机型少、折腾成本高得多。cleanyourtv 的路子是「最小侵入、可逆、免 root」，代价是厂商下次 OTA 可能把禁用包再启用，但你手里有一键还原脚本对应的反向操作，再跑一次又干净了。同周网友 Mihir Gupta 实测把 192MB 原厂启动器换成 83MB 自制版。

ACR 追踪到底偷走了什么？

智能电视的 ACR（自动内容识别）会采样画面/音频指纹，上传到厂商或第三方数据库比对，生成「你在看什么、几点看、看多久」的画像，再卖给广告主定向投放。Vizio 2017 年被查出未经同意收集 1100 万台设备数据，最终赔 220 万美元和解。cleanyourtv 把 ACR 相关包、广告服务、推荐服务禁掉之后，电视就只剩下你自己选的应用和输入源。

还原脚本另存一份，下次 OTA 后再跑一次

全流程跑完，回到桌面见到干净的苹果风主屏、无开机广告、无推荐行。把电脑上的一键还原脚本另存一份，万一厂商 OTA 把包再启用，再跑一次提示词就能恢复干净。别指望一劳永逸，厂商会在系统更新里塞回遥测代码，但你手里握着「一键清场」的剧本。
