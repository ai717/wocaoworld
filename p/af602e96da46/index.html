今日 GitHub 榜首：claude-mem 专治 Agent 失忆

Agent 们集体失忆，开发者们受够了

每天关掉 Claude Code，第二天再打开，昨天的工具调用、踩过的坑、定好的约定，全没了。换个 Agent 更惨：从 Claude Code 切到 Codex，等于换了个失忆的新同事，一切重头讲。10 月 30 日，claude-mem 冲上 GitHub Trending 日榜前列，单日新增星标在 336 到 1100 之间，总星数约 10.6 万——大家不是在给代码点赞，是在给「别再让我重复讲需求」投票。

这事的根子在 Agent 的工作方式：会话一关，上下文就扔了。很多人靠手写备忘文档续命，项目根目录塞一堆 MEMORY.md，靠 Agent 每次自己读。可文档是死的，写的人记得写才有，换了工具链还得重来。claude-mem 的思路是把「记」这件事自动化：不用你写，它自己看。

它到底记了什么、又是怎么记的

跑起来之后，claude-mem 会自动抓取 Agent 会话里的工具调用观察——调了什么工具、传了什么参数、返回了什么结果，这些流水账它全收。然后交给大模型压缩成结构化的摘要，只留下结论和关键细节，扔掉废话。下一次开新会话，它把相关的摘要再注入回上下文，Agent 一上来就知道「上次这个坑踩过」「这个约定还作数」。

整个过程不需要你手动维护向量库，也不用改 Agent 的代码。它不替你做决定，只负责把过去搬到现在。作者 Alex Newman（@thedotmack）在 10 月 29 日刚发了 release 15.6.0，项目 Apache-2.0 开源——顺带澄清一句：有些第三方文章写它是 AGPL，那是旧信息，以仓库实际声明为准。

装一次，八个 Agent 都续上记忆

安装就一行：npx claude-mem install，装完主流编码 Agent 全覆盖：Claude Code、OpenClaw、Codex、Gemini、Hermes、Copilot、OpenCode，一个不落。Claude Code 用户还有更顺手的姿势，在会话里敲 /plugin marketplace add thedotmack/claude-mem 直接装成插件。

对多 Agent 混用的人，这个覆盖面是最大卖点：以前每个工具各记各的，现在记忆层是统一的。今天用 Claude Code 定的方案，明天换 Codex 继续，上下文不断。这也是它能一天涨上千星的原因——痛点太普遍了，谁手里都有两三个 Agent 换着用。

先别急着装：默认勾选的 30 美元试用

费用这块有个坑必须提前说。安装器默认预选的是 CMEM Pro 托管观察器：30 天免费试用，之后 $30/月。很多人一路回车装完，试用期当永久免费，一个月后账单来了才傻眼。想纯本地跑、不花一分钱，安装时显式加上 --provider host，把观察器切到本地模式。

还有一层是隐私：托管观察器意味着你的会话观察数据会发到它的云端。个人项目无所谓，公司代码库、客户数据这种敏感场景，老老实实选本地模式。功能上两者都能记，差别只在数据放哪、钱给谁。装之前想清楚这两件事，再动手不迟。
