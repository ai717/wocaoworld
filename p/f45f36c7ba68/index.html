10月28日Trending日榜单日涨1598星AI私人导师DeepTutor

为何要把导师塞进知识图谱

10 月 28 日 DeepTutor 在 GitHub Trending 日榜单日涨约 1598 星，连 ScriptByAI 也把它列为“能记住你哪里不会”的 Agent‑Native 学习助手。普通聊天框只会把历史记录堆叠，真正有用的记忆是结构化的学员画像与知识图谱，才能在下一次对话里精准定位弱项并自动出题。

先把环境搭起来

跑通全套需要 Python 3.11–3.14 以及 Node.js 20+，建议先在终端跑 python -V 和 node -v 确认版本。若缺失请用 pyenv 或 nvm 补齐，别等报错再折腾。

两条路线任选一条

PyPI 路线：pip install -U deeptutor 后依次执行 deeptutor init 与 deeptutor start，Web UI 默认监听 http://localhost:3782。Docker 路线：docker run --rm --name deeptutor -p 127.0.0.1:3782:3782 -v deeptutor-data:/app/data ghcr.io/hkuds/deeptutor:latest。二选一，别同时跑两套端口冲突。

知识图谱记忆与自适应出题

Knowledge Hub 把教材、讲义、论文统一塞进 RAG 管线，向量化后写入图谱节点；跨会话的学员画像记录“会什么、卡在哪、目标是什么”。Quiz Generation 会依据图谱里的弱点节点生成 2–4 题一组，独立评分，练到该节点分数达标才算过关，这才是“自适应出题”的核心。

TutorBot 性格、多通道与新版改进

可为每个 Bot 设定苏格拉底式、鼓励式、严谨式三种教学风格，各 Bot 记忆互不干扰。支持 Telegram、Discord、Slack、邮件、微信、Web 等多通道同步，CLI 与 SDK 也可在脚本里直接调用。v1.6.15（2026‑10‑19）新增 Guided Learning 大纲可预览重排、原生 Gemini 语音播放，配合语音练习更自然。

短板：软件本身开源免费，但跑模型得自己付费；部署比普通聊天框重，Docker 与 PyPI 二选一前想清楚再下手。

多用户场景下也有分寸：管理员可以管共享资源与 Book 访问，但每个用户仍然保有独立的学习空间、个人进度、私人 Partner 对话与账号绑定的模型凭据，别人看不到你的学习画像，这一点对学校、培训班这种多人共用一台服务器的场景很关键。

模型费另算，部署也比聊天框重

别把 DeepTutor 当成真人老师，它只负责把你上传的资料变成图谱并按规则出题。模型费用、显存占用、首次初始化的几分钟等待，都是真金白银和时间的代价，量力而行。
