Infinite Creation小说转长视频：12GB显存本地跑

上传小说剧本：本地流水线串行出片

把小说改成长视频，人工流程要拆书、定人物、画分镜、逐镜生成再剪辑，一集能耗几天。Infinite Creation 把这条链搬到本地：上传小说或剧本，本地 Agent 加 ComfyUI 加 MiniMax H3 自动完成人物圣经、风格指南、人物场景道具语音资产、分镜脚本、逐镜视频、背景音乐、字幕与 ffmpeg 合片。仓库 419 星、448 次提交，作者称面向小说改编、漫剧广告与故事讲解视频，是一条可审核、可中断恢复的生产流水线。

它有两个工作台：主工作台走小说到长视频；另一个「无限・秩影」接代码渲染的风格化成片，内置 66 个风格模板，上传素材加提示词由 Agent 写渲染代码输出成片，不占 ComfyUI 渲染队列。人物一致性靠每人物一张 canonical 参考图跨分镜复用，加统一外观描述和 H3 参考标签规则；场景站位表给每个场景建人物道具站位，消除跨镜左右漂移。

硬件门槛写死：12GB显存32GB内存

作者给的最低配置不含糊：显卡最低 12GB 以上显存，内存推荐 32GB 以上，硬盘至少 150GB；他的自用机是 RTX 3080 20GB 加 32GB 内存。前置软件要 Node.js 22 以上、pnpm 9 以上、Bun 和 ffmpeg，首次运行前必须先装 ComfyUI 并跑通仓库自带的工作流。启动命令是 git clone https://github.com/SwotAtmk/infinite-creation.git 后 pnpm install、pnpm run dev，默认打开 http://127.0.0.1:4710。

跑不动本地的可以接 RunningHub 云端算力，仓库给了接入说明。生成拆成文本创作、资产生图、音色设计、分镜视频四个独立阶段，可勾选单独跑或续跑，按显存约束自动拆批；任务持久化加幂等跳过，进程崩了重启可继续，不重复生成。设置页可配每生成 N 个自动释放 ComfyUI 显存，默认 3。

字幕音乐可控：分镜能单独重做

可控性是它和一键生成工具的分界：关键阶段可确认，单个分镜可重做，变更日志可回滚。字幕有三种模式：剧本台词直接生成零依赖；本地 whisper 按成片音轨识别，需 Python 3.9 以上，本机没有会自动下载约 25MB 便携运行时；外部 audio2srt 服务转写，本机无需 Python。三种模式识别不可用时自动回退剧本台词，并保留无字幕版本与 SRT 文件。背景音乐在视频阶段自动生成，也可手动生成后一次性应用到多个章节。

外部 Agent 也能接管：除内置 openclaude 外，可切换到本机已装的 Claude Code、Codex CLI、Gemini CLI 等，通过本地 MCP 工具桥暴露领域工具，模型账号与登录态走各自 CLI。技能系统默认预装 MiniMax-H3 视频 Skill 与 novel-to-video 主技能，把 SKILL.md 丢进 skills 目录即可扩展；上传新的 ComfyUI 工作流 JSON 会自动解析节点生成规格并起草对应技能。

许可与成本：商用要单独申请

仓库许可标为 PolyForm-NC 1.0.0，非商业使用，商用要按仓库的商用申请走，这一点做漫剧变现的人先看清。本地跑的成本主要是电费和时间，云端算力按平台计费；作者也提醒第三方 ComfyUI 一键整合包可能涉及收费，理性支持、不要信陌生人卖资料。AMD 显卡作者强烈建议用 plan3 环境，模型与节点和旧方案不通用，两套工作流不要混着跑。

 12GB 显存是作者给的下限，8GB 可运行版本要自己适配，Intel Mac 基本跑不动。先手动跑通 ComfyUI 全部示例工作流再开 Agent 全自动，否则报错分不清是环境还是流水线的问题。商用前先看 PolyForm-NC 条款并走商用申请。

适合谁：有小说或剧本存量、想批量出长视频且手头有 12GB 以上显卡的人。没有显卡先接云端算力小批量试一集，确认人物一致性和分镜质量再扩量。
