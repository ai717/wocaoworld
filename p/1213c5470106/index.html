OpenMontage不是一键成片：它把编程助手变成制片组

控制面是Agent，Python只是工具箱

calesthio/OpenMontage 自称开源的智能体视频生产系统，星标已数万。它不是再做一个文生视频按钮。研究、提案、脚本、分镜、找素材、剪辑、配音字幕和渲染，写在 YAML 流水线和 Markdown 技能里，由 Claude Code、Cursor、Copilot 这类编程助手按阶段执行。架构文档写得很直：没有单独的 Python 总导演，Agent 本身就是控制面。

仓库里大约十二条生产线，覆盖讲解片、口播、录屏、纪录片蒙太奇、电影感预告、动画、播客切片、本地化配音等。多数骨架仍是研究到发布那几站。每站有验收标准和可选人工卡点，贵的生成步骤前先看方案，比一键烧完额度更像摄制组。

两种成片路径，别混成同一种「AI视频」

一条路用免费库存和公开档案拼真运动镜头，再剪时间线、渲染。另一条路调 Veo、Kling、Seedance 一类模型出画面，再用 Remotion 或 FFmpeg 合成。官方示例里有过大约五美元打出预告片的记录，那是生成成本，不含你的时间和返工。从 YouTube、Shorts、Reel 或本地成片反推方案也可以，但平台条款和素材版权不因开源而消失。

流水线类型 更适合 先准备什么
讲解 / 动画生成 科普、产品说明 模型 Key、预算上限
口播 / 录屏 已有人声或操作画面 素材文件、字幕语言
纪录片蒙太奇 少花钱的真镜头 可合法使用的库存源
切片 / 配音 长视频再利用 原片授权、目标语言

工具层接图像、视频、TTS、音乐和分析，具体供应商可替换。技能文件教 Agent 怎么选工具、怎么记决策。这能减少「每次重写提示词」，不能保证口播不漂、字幕不错、事实引用都对。卡点关掉之后，它会一直往下做。

把它当制片系统，而不是成片按钮

需要编程助手、Python 环境和至少一条可用的生成或库存通道。适合已经能写提示词、也愿意在方案页点同意的人。只想输一句话出竖屏的，会觉得重。团队感来自分工文件，不是来自自动上班的员工。先选一条流水线跑通研究到成片，再谈把剪辑台交给仓库。
