K-Vault：基于 Cloudflare Pages 的免费图床与文件托管解决方案

如果你正在寻找一个 免费、可扩展、支持多后端存储 的图床或文件托管方案，那么 K-Vault 是一个非常值得关注的开源项目。

它基于 Cloudflare Pages 构建，结合多种存储服务，实现了一个 低成本甚至零成本运行 的文件托管系统。无论是日常图床、文件分享，还是自动化资源分发，都可以轻松胜任。

https://github.com/katelya77/K-Vault

一、K-Vault 核心优势

无限上传能力
支持不限数量的图片和文件上传（受后端存储限制）

完全免费运行
依托 Cloudflare 免费额度，在合理范围内几乎零成本

免费域名支持
默认提供 *.pages.dev 二级域名，同时支持绑定自定义域名

二、多存储后端支持

K-Vault 最大的亮点之一，是支持多种存储方式：

  • Telegram（频道/群存储）

  • Cloudflare R2

  • S3 兼容存储（如 MinIO 等）

  • Discord

  • HuggingFace

可根据需求灵活切换或组合使用。

三、实用功能详解

Telegram Webhook 回链
上传文件到频道/群后，机器人自动返回直链

KV 写入优化
支持签名直链，减少 KV 读写消耗，提高性能

内容审核机制（可选）
可接入图片审核 API，自动过滤违规内容

多格式支持
支持图片、视频、音频、文档、压缩包等多种类型

在线预览
支持 PDF、DOCX、TXT、图片、音视频等直接预览

分片上传
结合 R2/S3 支持最大 100MB 文件上传

访客上传功能
支持限制上传大小与每日次数，适合公开图床场景

多种管理视图
网格 / 列表 / 瀑布流，方便文件管理

存储分类管理
不同存储后端文件可视化区分

四、适用场景

  • 个人图床 / 博客配图

  • 文件分享 / 临时存储

  • Telegram 自动化存储

  • 公共资源托管站

  • 开发者自建存储服务

五、总结

K-Vault 通过 Cloudflare Pages + 多存储后端的组合，实现了一个 免费、灵活、可扩展的文件托管方案。
无论你是普通用户还是开发者，都可以用它快速搭建属于自己的图床系统。
