用 dumbtv 一键瘦身 Fire TV，彻底告别广告与追踪

 得有 ADB 和一台 Fire TV

想把 Fire TV 变成「纯净版」其实不复杂，核心只需两样东西：一台已开启「开发者选项 → ADB 调试」的 Fire TV，以及一台能跑 adb 的电脑（Win/Mac/Linux 均可）。如果你还没把电视的 IP 记下来，先在设置里查一下，后面 adb connect 要用。

克隆仓库并连上设备

打开终端，跑官方给的一键克隆命令：

git clone https://github.com/humblemuzzu/dumbtv && cd dumbtv

接着把电视接入局域网，执行：

adb connect :5555

看到 connected to :5555 就算成功。这一步要确保电脑和电视在同一网段，且防火墙没拦 5555 端口。

四个脚本的分工

仓库里准备了四个按顺序跑的脚本，每个只做一件事，方便出问题时定位：

  • ./scripts/preflight.sh：环境自检，确认 ADB 连通、设备型号在支持列表里，顺便把当前已安装包列表备份一份。
  • ./scripts/configure.sh：把约 50 个 Amazon 广告、赞助行、ACR 指纹、遥测、实验性包一次性 禁用（并不删除），README 原文写的是「Disables Amazon’s sponsored rows, ad services, screen fingerprinting (ACR), telemetry and experiments」，也强调「Disabled, never deleted.」。
  • ./scripts/all.sh：把前两步串起来，再把自带的极简启动器推送进去。启动器只有 54 KB，开源、无联网权限、零权限，README 原文：「54 KB, open source, no internet access, no permissions」。
  • ./scripts/verify.sh：跑完后自动查一下已禁用包数量、启动器是否生效、DNS 过滤规则是否生效。脚本会逐项核对已禁用包、启动器状态与 DNS 规则，确保没有漏网之鱼。

跑完验证与还原

如果一切顺利，电视重启后直接进干净桌面，不再弹「赞助内容」行。万一哪步出岔子，或者想恢复原厂体验，只要跑：

./scripts/restore.sh

脚本会把备份的包列表逐个 pm enable，把启动器卸载，把 DNS 规则清掉，设备瞬间回到出厂状态。

DNS 屏蔽原理与媒体口径差异

除了包级禁用，dumbtv 还在设备端植入一份 hosts 规则，官方描述：「blocks about 400 Amazon telemetry, ad and update hosts」。这能拦住系统级的上报请求，但 It’s FOSS 实测提到：YouTube 广告走的是 Google 域名，hosts 挡不住，得靠路由器或 DNS 服务再加一层。另外，部分媒体（TechCrunch、It’s FOSS）称禁用包约 65 个、启动器 41 KB，与仓库 README（约 50 个、54 KB）有出入，撰写时以 README 为准并已在文中注明。

风险提示（来自 It’s FOSS）：① YouTube 广告无法靠 DNS 屏蔽；② 手滑误删系统关键包可能导致变砖，脚本只禁用不删除就是为了降低这风险；③ 折腾完记得在开发者选项里关掉 ADB 调试，防止局域网内被随意连接；④ 仓库创建于 2026‑10‑18，MIT 协议，代码完全公开，放心审计。

官方落地页见 dumbtv.org，想深究代码直接看 GitHub 仓库。只要按步骤走，十分钟左右就能把一台「广告机」变成「纯播放器」，省下的不仅是眼球，更是后台偷跑的流量和电量。
