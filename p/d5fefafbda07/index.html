微信小游戏上架施工单：4步从建游到接流量主

 

施工单的四步：从建游到接流量主

第 76 条的同一位作者把微信小游戏上架拆成一张 4 步施工单：摸清规则、装工具、一句话建游加预审体检、导出压包直传体验版，再补过审材料接流量主。施工单原文在这篇长文里，工具就是dsh-game-studio（v0.1.0-rc.6）。作者拿自己的 3D 三消《一箱见底》跑完整条路，自称个人主体一把过审、1.0.7 热修当天放行，微信搜一搜可试玩；这属于作者自述，本站未实测核验。

施工单给新手留了 30 分钟最小完整流程：先照 Step 1 到 Step 3 跑通一款单关卡 3D 小游戏，拿到手机微信里能打开的体验版二维码，皮肤、音效、过审材料和搜一搜运营素材按 Step 4 补齐。文中安装命令、建游提示词、过审截图清单和填写范本都给了可复制版本，动手前先收藏在手边。

规则账先算清：个人主体与4MB红线

施工单第一部分先算规则账，几条都是作者的实战口径：纯中文名、不接现金充值和道具内购、只走广告流量主的个人主体游戏，作者称无需等版号可直接提审；1 张身份证可开 5 个号、1 个号只发 1 款游戏；开发测试零费用，开通流量主的号要交 30 元一年认证费；单机小游戏可先上线攒 UV 再等备案，攒满首波 100 UV 开通流量主；新游种子计划 90 天内只有一次开启机会，等新手引导和留存打磨稳了再点。这些说法以微信平台官方当日页面为准，资质要求不要照抄帖子当规则。

技术红线有三条：主包 4.00 MB 硬上限，Three.js 运行时加几张未压缩 AI 高清贴图分分钟撑破；右上角胶囊会挡按钮；多 WebGL 上下文会黑屏。dsh-game-studio 把微信预审体检和胶囊模拟做进工具链：试玩画面叠绘真实比例胶囊防遮挡，自动拦截多 WebGL 黑屏风险、英文残留和主包超限。导出时 game_studio_export_wechat 打出小于 4.00 MB 的 wx-minigame/ 目录，game_studio_upload_wechat 用本机微信开发者工具 CLI 传体验版。

安装两行命令：四宿主都能挂15个工具

Step 1 是装工具。省心法是把仓库的 INSTALL.md 发给 Codex、Claude Code 或 Antigravity 让它自装，再跑 npm run doctor 确认 15 个 MCP 工具可用；手动法是终端四行：git clone https://github.com/ZSeven-W/dsh-game-studio.git，进目录 npm install，跑 npm run setup:all（也可单选某个宿主），最后 npm run doctor 体检浏览器、生图服务与微信 CLI。DSH 桌面端另有 dsh plugin add @zseven-w/dsh-game-studio 一行装法。

Step 2 是建游加体检：提示词里写清竖屏单手操作、全界面纯中文、零外部网络请求，建完直接跑 game_studio_playtest 并传 platform: wechat，让它按微信约束试玩一遍再改。施工单的交付标准是可玩、60 FPS、脚本零报错、通过预审体检、避开胶囊且带新手引导。Step 3 用同一套源码同时导出网页版和微信包，Step 4 再补过审范本与上线后封面规范。

照抄之前分清：哪些是经验哪些是规则

这张施工单的价值在顺序感：先算规则账，再装工具，再建游体检，最后补材料。很多 AI 小游戏死在真机黑屏、胶囊遮挡和主包超限这三处，施工单把它们前置成体检项，比提审被打回再改省时间。但文中「闲鱼有人卖四位数教程」是作者自述，未核实；过审截图和太阳码也是作者提供的材料，本站没有独立复核《一箱见底》的审核状态。

 版号、备案、认证费和流量主门槛这类规则会变，动手前去微信公众平台看当日官方页面，别把施工单里的数字当成现行规则。导出小于 4MB 的包只是能上传，平台审核是独立一步，试玩通过也不等于真机触控、渲染和内存都过关。

适合照着做的人：已经有小游戏点子、卡在「浏览器能跑微信翻车」这一步的人。先用最小完整流程拿到体验版二维码，再决定要不要投入皮肤和运营素材，顺序别反。
