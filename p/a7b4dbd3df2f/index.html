OpenMontage：AI 编程助手当导演的视频工厂

四万五千星标不靠炸

GitHub 上躺着个项目 calesthio/OpenMontage，上线首周霸榜 Trending 榜首，累计 4.5 万+ star。乍一看标题——“全球首个开源 agentic 视频生产系统”，容易让人联想到 Sora、Runway 那套“输入提示词、等 5 秒、收片段”的路数。但拉开源码一看，完全不是那回事。

 

大脑在你手里，不在服务器里

OpenMontage 的核心机制只有一句话：它坐在剪辑生成器之上，充当“生产层”。没有隐藏的中央编排器，真正的大脑就是你手里的 AI 编程助手——Claude Code、Cursor、Copilot、Windsurf、Codex 随便挑一个。助手读两种文件：YAML pipeline manifest（流水线剧本）和 Markdown skill 文件，然后一步步执行：调研、写脚本、决定调用剪辑生成器还是去免费素材库拉片、离线语音引擎配音、配乐对齐时间线、烧字幕、渲染成片。Python 只负责工具调用和文件落盘。整套系统本质上是 700+ 个指令文件，教你的编程助手当导演。12 条生产流水线覆盖解说、预告片、纪录片、播客切片等场景，52 个工具、500+ 个可执行 skill，全在本地跑。

不花钱也能跑通，但别信“零成本”鬼话

免费工作流是真能跑：离线 Piper TTS 配音，从 Archive.org、NASA、Wikimedia 拉真实历史素材片段，Remotion 渲染。官方给过两个样例账单——一支 70 秒历史短片 0.02 美元，一支 60 秒皮克斯风动画短片 1.33 美元。每轮渲染自带质检：抽帧检黑屏、音量校验、文件完整性校验，不合格直接拦截不出片。纪录片流水线专门剪真实档案素材；还能扔进一条参考视频，反推出带成本估算的制作计划。这套“可验证、可复现、可审计”的生产逻辑，才是它区别于黑盒生成器的硬骨头。

冷静面：别把 AGPLv3 当透明

500+ 个 skill 全跑在你的权限下，供应链安全风险摆在桌面——别人的指令文件可能偷偷 rm -rf 你的家目录，也可能把环境变量传出去。许可证是 AGPLv3，商用前先把条款啃透，别等收到律师函再后悔。它终究是“生产层”不是魔法，成片质量仍取决于底层素材库有多丰、底层模型有多聪明。想用它替掉专业剪辑师？先问问自己：能不能把导演意图拆解成 YAML 里的每一步决策？
