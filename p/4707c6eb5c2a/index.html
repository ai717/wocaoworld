一把 Key 管 11 Agent：DeepSeek半价到 11 月 12 日

一把 Key 打通 11 个 Agent

AIHubMix 刚在 Medium 上放出 官方公告，宣布 AIHubMix Desktop 1.0.0 正式可用。这款桌面客户端的核心卖点只有一句：一把 Key 管 700+ 模型，且一次性把市面上主流的 11 个 coding agent 全部接入，包括 Claude Code、Claude Desktop、Codex CLI、Codex Desktop、Gemini CLI、OpenCode、MiniMax Code、OpenClaw、Hermes、Pi（原文列出 10 个名字但口径仍称 11 个）。下载安装后，所有 agent 的请求都走 AIHubMix 网关，余额按平台原价扣费，不额外收取服务费。

DeepSeek V4.1 Flash 半价细节

同期推出的促销更让人眼前一亮：DeepSeek V4.1 Flash 1017 在 AIHubMix 网关层直接打五折，活动截止 2026-11-12。模型 ID 为 deepseek-v4.1-flash-1017，规格 1M 上下文、最长 393K 输出、支持视觉输入、工具调用与 Prompt Caching。促销价把输入、缓存读取两段费用全部减半，输入约 $0.0775/1M，而 DeepSeek 官方 off‑peak 挂牌价为 $0.15/1M input、$0.60/1M output（peak 翻倍）。官方给出的算例：20M 输入（其中 18M 缓存）+ 2M 输出，挂牌约 $1.61，促销后约 $0.80。无需优惠码，账户余额自动按半价结算，活动结束后自动恢复原价。

配置写入前的 Diff 预览与密钥托管

桌面端在把新的 base URL 与 API Key 写入各 agent 配置文件前，会弹出 预览 diff，让你确认改动再落地。终端导出的 base URL/key 优先级高于本地配置文件，密钥不以明文存放，而是分别走 macOS Keychain 与 Windows Credential Manager。断开连接时，客户端只会移除自己写入的片段，保留用户原有的其他设置，避免“全盘覆盖”导致的事故。

好在哪

  • 一键接入 11 个主流 agent，省去逐个配置 base URL 与 Key 的繁琐步骤。
  • DeepSeek V4.1 Flash 半价直接在网关层生效，无需手动切换模型或填优惠码。
  • Diff 预览 + 系统级密钥托管，安全感与可控性兼顾。
  • 客户端本体免费，所有请求仍按 AIHubMix 余额计费，无隐形订阅。

短板在哪

  • Windows 安装包尚未完成 Authenticode 签名，SmartScreen 会弹警告，需手动“仍要运行”。
  • macOS 最低要求 12+，旧系统用户无法直接使用。
  • 修改配置后必须彻底退出并重新启动桌面端，否则新 Key 不生效。
  • Codex 后台服务需手动执行 codex app-server daemon restart 才能让新配置生效。
  • 已有会话里的模型选择可能停留在旧会话，需新建会话或手动切换。

想把这套“单 Key 多 Agent”流程跑通的开发者，可以先去 Sovyron 的 AIHubMix 页面 查看实时模型列表与价格对比，再决定是否把 DeepSeek 半价窗口期利用起来。整体来看，AIHubMix Desktop 1.0 把碎片化的模型接入做成了“即插即用”的体验，配合这次网关层面的半价策略，对于高频调用 DeepSeek 的团队来说，性价比极高；但 Windows 签名缺失与重启依赖仍是上手前必须权衡的现实门槛。
