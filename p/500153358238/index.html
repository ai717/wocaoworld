Codex里跑MiniMax H3：插件免费，不到1元要看关机和授权

封装的是租卡流程，不是把模型变成免费午餐

Sac-Y/MiniMax-H3-Cloud 把云端 GPU、ComfyUI 运行时、提交工作和下载 MP4 收进 Codex 插件。作者说能在对话里构思提示词，走完从开实例到出片。仓库写明：插件本身不收费，也不内置 MiniMax H3 权重；卡时、系统盘和镜像由优云智算等平台计费，创建付费资源前必须你点头。默认约 30 分钟兜底关机，任务结束也立刻关，这才是「不到 1 元」可能成立的前提——实例忘关，数字就不成立。

H3 是 2026 年 8 月前后放出的开源权重视频模型，可出约 4 到 15 秒、最高约 2K、带立体声的片段。Arena 上开源组一度靠前，图生视频接近 Seedance 一档，这是盲测偏好，不是每条提示词都打平商业接口。社区许可证目前排除欧盟、英国、韩国和美国等地，不确定自己是否被覆盖时，不应启动付费实例。

Codex负责排队，钱和钥匙在云平台

支持文生视频、关键帧（首帧、尾帧或首尾）和一到九张参考图。本机需要 ssh、ffprobe，以及平台 CLI 保存密钥。插件技能写明不要打印或索要 API Key。库存和报价会变，5090 一类大显存只是作者实测偏好，不是永远最便宜。

不用高端电脑 算力在别人机房 账号、发票和地域授权

从装插件到第一条成片，作者称大约 15 分钟，包含注册和选卡。失败常见原因是库存没有对应规格、工作流超时、或实例没在倒计时前结束。迭代第二次时，先看上一次是否已经关机，再改提示词。

想试AIGC可以装，别把促销价写成成本结构

适合已经在用 Codex、能接受把任务交到第三方 GPU 的人。要稳定商用接口、发票和对公合同的，继续走模型官方 API 更省事。插件降低的是点控制台的步骤，不降低许可证、电费折算和「忘关机」这三项。先按平台账单核对一分钟单价，再决定这条低价路径值不值得养成习惯。
