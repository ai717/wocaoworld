输公司名出增长蓝图：REA-growth 拆解只要 0.58 美元

Jason Zhou 甩出个「增长逆向器」：输名字、出蓝图、收五毛

2026 年 10 月 30 日，独立开发者 Jason Zhou（@jasonzhou1993） 在 X 上扔了个炸弹：开源 /REA-growth skill。一句话功能——你把任意公司名丢进去，它帮你把这家公司从 0 到现在的完整增长动作全拆出来，SEO、AEO、付费广告、社媒运营，全时间线、带日期、可追溯。配套演示视频 1 分钟跑完 Lovable 8 个月冲到 $100M ARR 的全过程，拉了 2 年公开数据、对齐了 343 个带日期的公司动作。最吸睛的是价格：作者在帖子里声称「一次完整拆解只要 0.58 美元」。评论区有网友回说自己跑 Cursor 的完整拆解花了 0.48 美元（网友自述，非官方数据）。

这玩意儿跑在 treg 平台上，由 @sharenow_today 合作推出。treg 的机制很野：一个 token 调上千个工具端点，按次计费（from a cent），新验证账号直接送 $1.00 免费额度。也就是说，注册下来不充值，直接能白嫖一两次完整拆解。装法也简单，CLI 一行命令 curl -fsSL https://treg.to/install.sh | sh，然后 treg login / treg catalog search / treg call / treg balance 走起；不想折腾命令行的，Claude Code 装插件 /plugin marketplace add superdesigndev/treg 也能用。Discord 社区已经有 6.7k star 的 GitHub 仓库撑腰，生态跑得挺快。

 把「增长考古」变成了标准化 API 调用

以前想拆解竞品增长，要么花大钱买研报，要么自己人肉搜 Wayback Machine、Semrush、Ahrefs、社媒考古，还得懂得区分 SEO 和 AEO、广告投放节奏、内容运营节点。现在 REA-growth 把这套「考古 + 结构化 + 归因分析」封装成了一个可复用的 Skill，底层靠 treg 的 Agent 网络自动调度爬虫、SEO 工具、社媒 API、新闻源，输出结构化时间线。对于独立开发者、早期创业团队、做副业的数字游民，这意味着「增长复盘」的门槛从「专业技能 + 昂贵工具 + 大量时间」降成了「会输公司名 + 几毛钱 token 费」。Chia Y 还在 X Article《Reverse Engineer Any Company’s Growth in 10min》里把 Lovable 案例细化到了 343 个动作点，这种颗粒度放在以前至少得一份几万块的咨询报告。

真香在哪

  • 价格击穿地板：作者声称 0.58 美元 / 次，网友实测 Cursor 0.48 美元。按 treg「from a cent」的计费逻辑，拆解一个中型 SaaS 可能也就几毛到一块钱。新号送 $1，相当于前 1-2 次免费。
  • 覆盖面真全：SEO 关键词历史、AEO 问答覆盖、广告投放创意/渠道/时间窗、社媒内容矩阵/爆款节奏、PR 节点、甚至团队扩张信号，一次性给你拼成带日期的长图谱。
  • 数据可追溯：演示视频里每个动作点都有来源链接和时间戳，不是大模型一本正经胡说八道，按一下就能跳回原始网页验证。
  • 生态可拼装：treg 仓库 6.7k stars，工具端点上千，REA-growth 只是其中一个 Skill。你想加「自动生成竞品对比表」、加「监控竞品新动作发钉钉」？直接在 treg 里再串几个 Skill，不用重复造轮子。
  • 开源可自建：GitHub 仓库 MIT 协议，数据敏感的企业可以自建 treg 节点，数据不出内网。

 演示是演示，生产环境还得踩坑

  • 核心数据源全靠「公开数据」：私有后台数据、未公开的 A/B 测试细节、内部归因模型、暗投 KOL 返佣细节、线下地推动作——这些统统抓不到。拆出来的蓝图顶多是「公开面的增长动作复盘」，别指望能逆向出核心护城河。
  • Lovable 案例仅作者演示视频佐证：那个「343 个动作、0.58 美元」的完整推导过程只在附带的 1 分钟演示视频里出现过，文本没给细节，没有第三方复现报告，其他公司实例也只在帖子里一笔带过。
  • Agent 幻觉依然存在：treg 调度上千工具，中间任意一环抓错页、解析错结构、时间戳对不齐，最终时间线就会带偏。视频里跑通不代表你输「某不知名小厂」也能跑通。
  • 非技术用户有配置门槛：CLI 安装、登录、查余额、调用，全程命令行；Claude Code 插件门槛稍低但也得会装插件、懂 JSON 参数。完全不懂代码的运营同学可能卡在 treg login 那一步。
  • 计费不可控风险：按次计费听起来美，万一拆解超大型上市公司触发几百个工具并发跑，账单会不会飙升？目前文档没给封顶机制说明，$1 免费额度用完后建议先跑小公司测测水温。

 手头有竞品要拆的，现在注册正好薅羊毛

不夸张说，REA-growth + treg 是这半年见过最「整活」的增长工具组合：把几万块的咨询报告变成了几毛钱的 API 调用，把周级的人肉考古压缩成了 10 分钟的 Agent 跑批。作者声称的 0.58 美元、网友自述的 0.48 美元，加上新号送的 $1 免费额度，现在进场试错成本几乎为零。建议：别管它准不准，先注册 treg.to/rea-growth 拿到手，找 2-3 个你一直想拆但舍不得买研报的竞品跑跑看，对着源链接人工核对几个关键节点。如果误差在可接受范围，这玩意儿就能直接塞进你的「竞品监控周报」自动化流水线里了。要是翻车了，顶多损失几分钟配置时间，反正白嫖的额度不用白不用。GitHub 仓库、Discord、原推 全在手里，自己玩去吧。
