Concat 本地剪辑：免费离线对打剪映会员

 

为啥我把剪映卸了，改跑这玩意儿

剪映好用是好用，但不少高级功能要开会员，素材还得走云端。作为数字游民，出差在高铁、酒店弱网环境下，想剪个 4K 60fps 10-bit 素材，剪映直接卡成 PPT。GitHub 上 Concat 这会儿已攒 16,421 颗星（2026-11-10 核查），最新 v0.2.9（2026-11-05）直接甩出王炸：Rust + GPU 合成、Whisper 本地字幕（模型 78–488MB）、Kokoro / Chatterbox 声音克隆、4K 60fps 10-bit 导出（H.264/HEVC/AV1 全支持）、MCP 服务一条 concat --mcp 让 Agent 直接指挥剪片。全平台跑（macOS/Win/Linux/Android，iOS 侧载），AGPL-3.0 开源，无水印、无账号、无订阅、素材不上传。官网 concat.standalones.org 连下载页都没放“定价”俩字。

核心架构：Rust 内核＋本地模型＝真·离线生产力

别被 “Beta 测试版” 吓退，X 博主 mikenevermiss 演示过它的本地剪辑流程：Rust 原生引擎加 GPU 合成，时间轴渲染不走 Electron、不吃浏览器内存。Whisper 在本地跑，模型按需下载，从 78 MB (tiny) 到 488 MB (large-v3)，字幕全程不经过云端。语音端塞了两套方案：Kokoro 轻量多语种、Chatterbox 用几秒参考音频克隆音色。导出管线原生支持 10-bit HEVC/AV1，显卡加速导出 4K 60fps 素材。详细架构拆解见 Pham Nam 的深度长文。

价格以各家官网实时标价为准，免费与否才是这张表真正想说的事。Concat 唯一短板是 “Beta UI 还没剪映圆润”，时间轴缩放、关键帧曲线目前只能靠 WebUI 鼠标拖或 MCP 自然语言下指令，精细调色、多机位同步还得靠达芬奇/Premiere。但对 “不想交智商税、不想素材上云、想让 AI 自动剪同款口播” 的人，它是目前唯一 全程本地 的选择。

MCP 玩法：给 Agent 一句指令，它帮你把 2 小时直播切成 10 条短视频

开终端跑 concat --mcp 启动 MCP 服务，Cursor、Claude Code 这类支持 MCP 的客户端接进来之后，就可以扔提示词让 Agent 按语义分段、加双语字幕、克隆声音配旁白、导出竖屏成片，全程不用自己点鼠标。这才是 “Agent 指挥剪辑” 该有的样子——把时间轴交给代码，人只管审片。传统 NLE 还在卷 “AI 智能辅助”，Concat 的打法是让 AI 直接当剪辑师。

避不开的坑：Beta 期该知道的限制

1. Android/iOS 侧载版 需要自行侧载，普通用户折腾成本高，主力机建议跑桌面端。
2. Whisper large-v3 模型 488 MB 首次下载要花点时间，模型可在设置里单独下载。
3. 自动重构竖屏、对象追踪 这类功能还没做，精细调色还得导 DaVinci。
4. 项目文件 是自定义 JSON 文档，跨软件协作只能导成品再进别家软件。
5. 低配机型：有用户报告 8GB 显存的 NVIDIA 卡上导出会报错，跑 4K 之前先拿小片段试导出。

重要工程记得导成品备份。

分场景买单建议：别盲目跟风，对号入座

  • 数字游民/弱网环境创作者：全离线、跨平台、素材不上传，高铁上也能剪 4K，首选 Concat。
  • 隐私敏感/合规部门：AGPL-3.0 可自建、可审计、数据不出域，替代剪映/云剪毫无心理负担。
  • AI 自动化玩家/开发者：MCP 原生接入，写脚本批量产短视频、做本地化 RAG 视频库，生态想象力拉满。
  • 追求精细调色/多机位/商业交付：老老实实开 DaVinci Studio 或 Premiere，Concat 目前只能当 “粗剪+AI字幕+导出” 的前置节点。
  • 只想傻瓜式出片的小白：剪映会员更香，别来折腾 CLI 和模型下载。

一句话总结：Concat 不是想做 “免费版剪映”，它是想做 “本地优先、Agent 原生、开源可控” 的新一代视频基建。现阶段 Beta 够不上生产级主力，但把它塞进工作流当 “AI 粗剪员” 真香——省下的会员费和上传时间，够你买张更好的显卡了。
