免费AI视频链：两份开源清单拼出一条出片流水线

 

两份清单拼在一起：先看整条链长什么样

想做一条 AI 短视频，打开收藏夹一看，工具散在 20 个仓库里：生视频的、做动画的、对口型的、搞超分的、管剪辑的，哪个先装、哪个后装，全凭感觉摸索。replay_0x 这条帖子一次列出 20 个开源工具，从 Prompt 到成片排了一条全链；DN_degen 那条帖子又补了 10 个高星开源项目，覆盖脚本、语音、画面、剪辑与出片。两份清单合在一起，正好拼成一条脚本到成片的免费流水线，下面按环节拆开讲。

环节 工具 干什么 链接
脚本 MoneyPrinterTurbo 文字稿排成带配音与字幕的短视频 仓库
配音 fish-speech、kokoro 文字转语音，克隆音色或轻量合成 仓库
画面 Wan 2.2、HunyuanVideo 文生视频或图生视频 仓库

这张表就是全文的地图：后文按表里的顺序，一个环节一个环节讲，工具名第一次出现时给仓库链接，后面直接叫名字。

脚本与配音先行：文字变成能听的声音

写脚本不用从空白文档开始。MoneyPrinterTurbo是第二条帖子点名的短视频流水线工具，输入一段文字稿，它负责把稿子排成带配音与字幕的短视频结构，适合先把一期视频的骨架立起来，再决定画面怎么配。

配音一环有两个选择。fish-speech是开源语音合成项目，能按参考音频克隆音色；kokoro是轻量语音模型，跑起来负担小，适合先出一条能听的旁白验证节奏。两条帖子都把语音放在画面之前：声音定下来，画面的时长与节奏才有依据。

先把脚本工具装好，跑一条样片，确认稿子、配音、字幕能对上，再往下加画面工具。装法就是常规的拉仓库：git clone https://github.com/harry0703/MoneyPrinterTurbo.git

画面与动画接力：从静帧到会动的镜头

画面是整条链最吃资源的一环，也是两条帖子重合最多的地方。Wan 2.2与HunyuanVideo负责文生视频与图生视频，LTX-Video与CogVideoX是同类备选，第二条帖子还点名了Wan2.1。不用几个全装：先挑一个跑通，再按画质与速度留一个主力。

画面生成之后，动画把静帧变活。ComfyUI是节点式工作台，上面这些视频模型大多能接进来，拼成一条可视化的生成管线；FramePack负责让图片动起来，LivePortrait让一张照片开口说话、带上表情。三个工具分工不同：ComfyUI 是总装台，FramePack 与 LivePortrait 是专攻动画的零件。

工作台的装法同样是拉仓库：git clone https://github.com/comfyanonymous/ComfyUI.git装好之后先跑官方自带的基础流程，确认能出图，再把视频模型接进来，别一上来就拼复杂节点。

口型超分与剪辑：把粗糙成片打磨干净

画面动起来之后，口型与画质是两道关。LatentSync把配音和嘴型对齐，人物说话不再对不上嘴；Real-ESRGAN负责放大与修复，把模糊、带噪点的画面拉干净。这两个工具都不产生新画面，只修已经生成的画面，放在剪辑之前跑效果最好。

剪辑与导出是最后一环。Remotion用代码写视频：字幕、转场、片头都能写成可复用的组件；motion-canvas走同一路子，适合做带动画讲解的视频。习惯写代码的人用这对组合，比在时间轴上拖片段更快改版。

避坑提醒：本地跑视频模型很吃显存与硬盘，权重文件往往很大，下载前先看清仓库里的硬件说明。免费指的是工具本身不收钱，时间与电费照样是成本。先拿小模型跑通一小段，确认口型与画质能接受，再放大规模，别一上来就拉满参数。

照着跑一遍：先搭最小配置再慢慢加料

整条链不用一次搭完。最小配置可以只有四件：MoneyPrinterTurbo 立脚本骨架，fish-speech 或 kokoro 出旁白，Wan 2.2 或 HunyuanVideo 出画面，Remotion 剪辑导出。跑通一期之后，再按短板补零件：口型对不上加 LatentSync，画面糊加 Real-ESRGAN，想玩动画再接 FramePack 与 LivePortrait。

两条帖子合在一起的价值不在工具多，而在顺序清楚：脚本定方向，配音定节奏，画面定卖相，动画、口型、超分做打磨，剪辑收尾。按这个顺序走，免费工具也能拼出一条能出片的流水线；顺序乱了，再好的工具也只是一堆散件。
