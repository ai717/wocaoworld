MoneyPrinterTurbo怎么跑通：从主题到成片别只抄一键包

仓库名像印钞，流水线仍是脚本加素材加API账单

harry0703/MoneyPrinterTurbo 用一句话主题或自定义脚本，串起文案、库存或生成素材、配音、字幕、配乐和剪辑。2026 年 9 月可见版本约 v1.3.7，星标已过十二万。入口有 AI Agent、WebUI、API 和 CLI。本地要 Python 3.11，WebUI 默认 http://127.0.0.1:8501，API 文档在 8080/docs。GPU 不是硬性条件；云端大模型和在线素材为主时，CPU 和内存更关键。

开头那行「面向 macOS 和 Windows 的开源磁盘清理」对不上这个仓库。MangoDisk 如果存在，是另一套产品。下面按 MoneyPrinterTurbo 原文功能写，不把短视频工厂写成磁盘清理。

使用这个 Skill：https://raw.githubusercontent.com/harry0703/MoneyPrinterTurbo/main/docs/skill/SKILL.md 帮我生成一个主题为“人工智能如何改变普通人的日常生活”的视频。

Agent 能读 Skill、装环境和出片，缺 Key 才会停下来问。Windows 一键包要在 Releases 的 Assets 里下 .7z，不要下 Source code zip——解压后往往只有 webui.bat，没有 start.bat 和 update.bat。路径不能有中文、空格、特殊字符。建议先 update.bat 再 start.bat，空白页换 Chrome 或 Edge。

模型、网关和素材源堆在同一条配置里

脚本侧可接 Kimi / Moonshot、OpenAI、Anthropic Claude、Google Gemini、DeepSeek、通义千问、Azure OpenAI、火山引擎方舟、xAI Grok、MiniMax、小米 MiMo。网关和本地层包括胜算云、APIMart、Cloudflare AI Gateway、ModelScope、AIHubMix、AIML API、EvoLink、OpenRouter、API Route、Fluxion AI、Ollama、Claude Code 订阅、OneAPI、LiteLLM、Groq、Pollinations AI。Key 填在 WebUI 基础设置，也可导入导出恢复。

画面可走本地上传，或 Pexels、Pixabay、Coverr。生成侧原文列了秘塔 MiniMax H3（768P/2K、4～15 秒，9:16 / 16:9 / 1:1）、胜算云、方舟 Seedance、WaveSpeed、OFox（一个 Key 调 Seedance 与 Wan）、异步 MuAPI（3～12 秒，可配 Endpoint 和轮询），以及 OpenAI 兼容文生图再转动态片段。成片画幅是 1080×1920、1920×1080、1080×1080。跨平台发布可接到 TikTok、Instagram、YouTube Shorts，平台条款和账号风控不因开源而消失。

环节 原文里的免费或本地选项 仍要花钱或自备的
文案 自定义脚本、部分本地网关 云端 LLM Token
画面 Pexels / Pixabay / Coverr / 本地文件 H3、Seedance、胜算云等生成接口
配音 Edge TTS（Azure TTS V1），无需 Key ElevenLabs、MiniMax、Azure V2 等
字幕 edge 时间戳模式，默认可不用 GPU faster-whisper large-v3 约 3 GB，turbo 约 1.6 GB

配音字幕和那批默认 BGM

配音三种：自动、上传、无配音。Provider 还有 SiliconFlow、Gemini、小米 MiMo、Chatterbox、Kokoro、Fish Audio、ModelBest VoxCPM。VoxCPM 要能 speech_synthesis 的模型 ID，SSE 回 WAV 再转 MP3；参考音频最大 20 MiB，转换后单个 WAV 最大 5 MiB，只留在当前会话。v1.3.7 给 Edge TTS 加了 [pause: 2s] / [停顿: 2s]。字幕可改字体、位置、颜色、描边、背景；逐词弹出要在 WebUI 里单独开。BGM 在 resource/songs，说明来自 YouTube，侵权就删。字体在 resource/fonts。

Windows 一键包、uv、Docker 和 CLI 各管一种卡法

Docker 推荐 docker compose -f docker-compose.release.yml up，镜像 ghcr.io/harry0703/moneyprinterturbo:latest，先把 config.example.toml 复制为 config.toml。局域网访问 WebUI 设 MPT_WEBUI_HOST=0.0.0.0。API 默认同源；跨域才配 CORS_ALLOWED_ORIGINS。纯命令行：uv run python cli.py --video-subject "人工智能如何改变日常生活"。批量 --batch-file 最多 100 条、不超过 1 MiB，失败不阻断后续。上传音频不会写进配置，CLI 必须显式 --custom-audio-file。

项目 最低 推荐 理想
CPU 4 核 6 到 8 核 8 核及以上
RAM 4 GB 8 GB 16 GB 及以上
GPU 非必须 4 GB 显存及以上 8 GB 显存及以上

示例成片时长从 14 秒到 59 秒不等，中英都有，不能代表平台能过审。库存重复、口播和画面错位、生成片段只有数秒，都要人看。Key 进配置文件，不要提交到公开仓库。把印钞写进项目名，解决不了素材授权和账号被封；能跑通的是从主题到 MP4 的本地流水线。
