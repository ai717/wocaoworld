Claude Code 用量护栏对决：guard vs Peras

十分钟烧光五小时额度

最近在折腾 agent-usage-guard 和 Peras 两款护栏，都是为了解决同一个惨案：一个 research prompt 直接催生 394 个 subagent、341 并发、十分钟跑掉 84M context tokens，五小时窗口瞬间锁死。

agent-usage-guard：开源 MIT，规则全自定义

作者在 Show HN 拿到 26 points，安装只需三条命令：/plugin marketplace add rbartoli/agent-usage-guard 然后 /plugin install agent-usage-guard@agent-usage-guard 最后 /reload-plugins。核心思路是把「用量」当成预算，提供一套可写的规则表：

  • 窗口用到 80% 时新 agent 需审批，95% 直接拒绝
  • 全机并发 agent 上限 4，每 10 分钟新建或恢复上限 12
  • subagent 每 10 分钟 token 上限 10M
  • context 达 300k 加注提醒，500k 询问是否 compact、继续或取消
  • 同一工具连续失败 3 次拒绝重试
  • 本地运行、不联网、不存 prompt 文本，hook 失败则放行（fail-open）

所有规则都在本地 JSON 里改，想卡多严随手改，完全白嫖。

Peras：Product Hunt 新品，只卡支出不猜循环

发布页 Peras 把 Slogan 写成 『Pause Claude Code and Codex before they burn your week』。安装后跑两条命令即可：peras set weekly 85 pause、peras set prompt 3 pause。默认 90% 周额度自动暂停，机制是读取 Claude Code 与 Codex 自带的 usage 百分比（五小时窗口 + 周），每次 tool call 前经 hook 检查，超线直接拒绝并结束 turn。作者明确说「不猜 loop，只卡支出」，隐私上只看使用速度，不读 prompt 也不存命令。CLI 与 hook 免费 MIT，Mac 菜单栏原生应用一次性 €4.99。

核心维度对比

维度 agent-usage-guard Peras
安装方式 Claude Code 插件三条命令 CLI 两条命令，支持 Claude Code 与 Codex
限制粒度 并发、token、context、失败重试全可配 仅按周/窗口百分比自动暂停
价格与隐私 完全免费 MIT，本地不联网 CLI 免费 MIT，Mac 端 €4.99，仅读取使用速度
适用场景 需要精细控制并发、token 的重度开发 想要一键防炸、跨工具统一预算的轻量用户

按场景选哪个？

  • 你在自建服务器跑大规模 research，需要把并发、token、context 全部锁死 → 选 agent-usage-guard
  • 你在 Mac 上同时用 Claude Code 和 Codex，只想要一个「到线就停」的开关，不想改配置 → 选 Peras
  • 团队要统一预算、且不想折腾插件安装 → Peras CLI 免费、零配置上手最快
  • 极客喜欢把规则写成代码、随时调整阈值 → agent-usage-guard 的 JSON 规则表最爽

底线：两款都能在十分钟内把五小时窗口守住，区别在「想不想自己写规则」和「愿不愿为菜单栏付费」。按自己痛点挑一个，别让预算在不知不觉里蒸发。
