VoiceStudio：本地免费替代 ElevenLabs 的开源神器

云端配音又贵又不自由

做视频、做播客、做多语言教程，最让人头大的是每分钟都在烧钱，还得全程联网排队。ElevenLabs 音质确实好，但它是云端按量/订阅制，音频还得上传到对方服务器，隐私这块只能信人家的承诺。很多创作者只是想克隆几句台词、给视频配个音，结果被迫绑卡订阅、看网络脸色。

VoiceStudio 是什么

VoiceStudio（仓库 debpalash/VoiceStudio）是一个开源免费的本地语音工作站，协议 AGPL-3.0，前身叫 OmniVoice-Studio。它是 Electron 桌面应用，支持 macOS 和 Linux，把语音克隆、声音设计、视频配音、听写、转录、有声书全塞进一台机器。内置 17 个本地 TTS 引擎和 10 种转录选项，默认引擎是 k2-fsa/OmniVoice（模型协议 CC BY-NC，非商业用途），可以在模型管理器里切换。从源码装就一条命令：git clone https://github.com/debpalash/VoiceStudio.git && cd VoiceStudio && bun install && bun run setup && bun run dev。启动后在 localhost:3900 提供本地 OpenAI 兼容 API 和 Web UI，还自带 MCP server，Claude Code、Codex、Cursor 这类 agent 能直接调用；装 agent skill 只要 npx skills add debpalash/VoiceStudio。全程无账号、无 API key、无按量计费，数据不出本机。目前 GitHub 约 78k stars（近 7 天新增约 17k），热度相当炸裂。两家独立评测（TechUpSider、Andrew 的实测）都把它定位成 ElevenLabs 的本地平替。

硬核对比：8 个维度一次看清

维度 VoiceStudio ElevenLabs
价格 开源免费，无账号、无 API key、无按量计费 云端按量/订阅制
运行方式 本地运行，Electron 桌面应用，macOS/Linux 云端服务，全程联网
语音克隆 支持，需被克隆者授权 云端语音克隆
视频配音 内置视频配音能力 以音频合成为主
转录 10 种转录选项，本地离线跑 云端转录
MCP/API 自带 MCP server，localhost:3900 本地 OpenAI 兼容 API 云端 API，按官方文档接入
隐私 数据不出本机，完全可控 音频需上传至厂商服务器
协议与状态 AGPL-3.0，默认引擎 CC BY-NC 非商业；active beta，单人维护，官方 benchmark 页无实测数据 专有商业条款，成熟商业服务

先泼两盆冷水

第一，项目自己标注 active beta，基本是单人维护（作者 debpalash 占约 82.5% 贡献），还挂着 34 个 open issues，指望企业级售后不现实。第二，官方 benchmark 页面写着「No verified rows yet」——在你自己机器上到底跑多快，官方给不出实测数据，性能全看你的硬件。另外两条底线：默认引擎模型协议是 CC BY-NC，商用前务必先看模型协议；克隆任何声音都必须拿到被克隆者的授权，这是法律红线不是建议。

分场景推荐

个人创作者 / 数字游民：带着笔记本就能离线完成多语言配音、字幕转录，省下订阅费，飞机上也能干活。

隐私敏感团队：培训视频、产品演示全套跑在内网机器，文案不经过第三方服务器，合规审计好交代。

开发者玩二次开发：MCP server 和本地 API 能直接塞进自己的聊天机器人或语音助手，注意遵守 AGPL-3.0 的开源要求。

要稳定、要省心：ElevenLabs 这类成熟商业服务依然是更稳妥的选择——开箱即用、有人兜底。VoiceStudio 适合预算敏感、在意隐私、愿意自己折腾硬件的人；追求企业级稳定，就别跟 beta 版较劲。
