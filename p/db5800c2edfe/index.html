Cursor 对决 Antigravity：免费层硬刚付费墙，AI 编程选型指南

Cursor 突然换皮，老用户慌了

2026 年 10 月 12 日，Cursor 官方宣布改用 The X Subscription 体系，原有 Hobby、Pro、Teams 三档彻底停售（老用户可续订到期）。新定价毫不手软：Plus $8/月只能用自家 Grok，想调 Claude 或 GPT 得上 Premium $30/月起步，且第三方模型按 API 原价另算。Super $100、Ultra $200 两档更是直指企业钱包。消息一出，不少老用户开始算账：继续续订，还是趁机换门。

同期，Google Antigravity 2.0（2026-05-19 发布）悄悄把免费层 Individual 推到台前：$0/月、无限 tab 补全与命令、基础周限额、桌面端+IDE+CLI+SDK 全带走，模型池直接塞进 Gemini 3.8 Flash/3.1 Pro、Claude Sonnet 5 & Opus 5、gpt-oss-120b，连 Gemini 4 Argon 这种最新货也在阵容里。Mac 用户装个 Gemini 应用还能一键启动（需 AI Ultra 订阅）。RuntimeWire 实测显示：macOS 12+、Win 10 64 位、Linux glibc ≥ 2.28 全平台跑得飞起。

核心差异：你写代码 vs 你指挥代理

一句话概括定位差异：

  • Cursor = 「更好的编辑器」——你在写，Agent 在旁内联补行、重构、解释，手感贴合 VS Code 肌肉记忆。
  • Antigravity = 「指挥一队 Agent 干活的地方」——你下任务，多 Agent 并行跑测试、改文件、开 PR，你只管审结果。

前者适合「手不离键盘、逐行掌控」的重度内联党；后者适合「把整个功能切片扔给机器人、自己去喝咖啡」的并行控。没有绝对优劣，只有习惯匹配度。

避坑指南：别被营销页忽悠

  • Cursor 老用户别急着退订：Hobby/Pro/Teams 仍可续订到期，趁窗口期评估迁移成本。
  • Antigravity 免费层有周限额：跑满会降速，别指望拿它跑全量回归测试；企业合规、审计日志、SSO 全在 Org/Enterprise 里，别拿免费层上生产。
  • 第三方模型按 API 原价另算：Cursor Premium 以上调 Claude/GPT 跑久了，账单可能比订阅费还吓人，先看用量再决定。

分场景直球推荐

  • 预算敏感、爱折腾多 Agent 并行、不想绑定单一厂商模型 → 直接下载 Antigravity 免费层开干，桌面端+CLI+SDK 全齐，跑不爽再谈付费。
  • 重度内联编辑、肌肉记忆全在 VS Code、离不开 Copilot Chat 那套交互 → 咬牙上 Cursor Premium，或继续白嫖旧版到期再看，别为省钱砸手感。
  • 企业合规、SSO、审计、私有化部署 → 两家都要谈 Org/Enterprise，别拿个人版上生产，法务审不通过你哭都来不及。
  • Mac 党想要「一键启动」丝滑体验 → Antigravity + Gemini 应用（需 AI Ultra），或 Cursor 原生 macOS 客户端，二选一看钱包。

Cursor 换皮涨价是商业必然，Antigravity 免费层放大招是生态反击。没有「最强 IDE」，只有「此刻最对手」的工具。下载、跑通一个真任务、看账单、再决定——比刷十篇对比文管用得多。
