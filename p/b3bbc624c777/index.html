Kimi旗舰模型登陆 Vercel：1M 上下文图像输入

2026 年 10 月 23 日，Vercel Changelog 宣布 Kimi K3.1 Pro 与 Kimi K3.1 Pro Highspeed 正式上架 Vercel AI Gateway。模型基于 K3 做 post‑training，参数 2.8T 总量、104B 激活，支持 1M 上下文与图像输入。Pro 版定价输入 $2/M、输出 $10/M；Highspeed 版输入 $4/M、输出 $20/M，缓存命中 $0.20/M，较上一代 K3（$3/$15）大幅降价。

同步上架意味着开发者可直接在 AI SDK、Chat Completions、Responses、Anthropic Messages API 或接入 AI Gateway 的 coding agent 里调用，只需 npx vercel ai-gateway setup 选模型即可。权重计划在 11 月 4 日前开源，虽未公布许可证，但已让开源社区对长上下文、多模态大模型的落地产生强烈预期。

突破点

  • 1M 上下文 + 图像输入，单次对话可吞吐超长文档与多模态数据
  • 两档定价，Highspeed 号称 2‑3 倍推理速度，适合实时编码助手场景
  • 权重即将开源，降低自建推理门槛
  • 通过 Vercel AI Gateway 统一计费、缓存、限流，运维成本近乎为零

评述

路透社 10 月 24 日披露，Moonshot 从训练语料与强化学习环境中移除网络安全相关数据，主动削弱进攻性网络能力。官方自测显示过滤版在内部基准得 81.0%、未过滤版 90.5%、上一代 K3 仅 33.3%，但数据为 Moonshot 自家发布，未经独立验证，且 “削弱” 不等于 “完全不能进攻”。此外，Highspeed 版虽快但价格翻倍，实际吞吐提升需结合具体任务实测；权重开源许可证仍未公开，商业用途风险需自行评估。

价格与调用方式

价格是最实在的部分。按 Vercel 模型页的标价，K3.1 Pro 输入 2 美元、输出 10 美元每百万 token，缓存命中 0.20 美元；Highspeed 版输入 4 美元、输出 20 美元，约两倍价、号称快 2 到 3 倍，适合对延迟敏感的交互场景。上一代 K3 是输入 3 美元、输出 15 美元，这么一比，新模型反而更便宜，算是一次加量降价。

调用方式也不折腾：装好最新版 Vercel CLI，跑 npx vercel ai-gateway setup，再在 agent 里选 moonshotai/kimi-k3.1-pro 或 moonshotai/kimi-k3.1-pro-highspeed 就行。Claude Code、Codex、Cursor 这类接 AI Gateway 的 coding agent 都能直接用，也支持 AI SDK、Chat Completions、Responses、Anthropic Messages 这几种 API 格式。

安全取舍与权重时间表

这次最值得聊的不是参数，而是 Moonshot 主动做的取舍。据 路透社 10 月 24 日的报道，Moonshot 从训练语料和强化学习环境中移除了网络安全相关数据，保留通用编码能力。公司原话是“We aim not to release open weights that would extend the absolute frontier of cyber capability”。自家内部基准显示，过滤版 81.0%、未过滤版 90.5%、上一代 K3 只有 33.3%，不过这组数字未经独立验证，只能当作官方说法看。

说白了，这不是“完全不能进攻”，而是削弱之后仍然远高于上一代。权重计划 11 月 4 日前开源，但许可证至今未说明，动手之前先别默认它能随便商用。等权重放出、许可证写清楚，再决定要不要往生产里接，这才是稳妥的顺序。
