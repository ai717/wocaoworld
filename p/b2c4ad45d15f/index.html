AutoClip剪视频实测：1小时43分7分半出10条

 

贴个链接就能出片：AutoClip到底替你干了哪几步

长视频剪成短视频，最磨人的不是剪辑本身，是先看完整场、再挑高光、再裁竖屏、再烧字幕、再想封面标题。AutoClip 把这串活包圆了：贴视频网址或丢本地文件，选抖音、小红书、TikTok、Reels 或 YouTube Shorts，工具自动挑出最多 10 段合格片段，字幕、封面、标题标签一次给齐。开源 MIT 协议，GitHub 已经攒下约 1.54 万星，剪辑与渲染全在本地跑，不用把视频传上云排队。

它不只是个剪刀：说话人追踪、竖屏重构、封面生成、发布文案都在一条流水线里。播客、访谈、课程、游戏直播回放都能喂，v1.6 还加了直播回放入口，接 OBS、Twitch、YouTube、Kick、Discord 与本地录制，播完直接进剪辑队列。

1小时43分实测7分半出10条：成本账要这么算

仓库 README 贴出的实测数据很实在：1 小时 43 分钟英文带字幕视频转小红书，7.5 分钟出 10 条，文字模型费用约 0.09 元（按 qwen-plus 估算）。原帖作者说的“新台币 0.4 元”与这个数对得上，约等于 0.09 元人民币，没夸大。没有现成字幕的版本要贵一点：本地 Whisper 转写 2 小时 52 分钟中文视频花了 29.5 分钟，费用约 0.2 元。

免费的边界要讲清：软件本身免费开源，云端分析、转写与 AI 封面走的是你自己的 API Key，按供应商价格计费；想一分钱不花，就用 Ollama 或 LM Studio 加本地 Whisper 与 SenseVoice 全离线跑。剪辑渲染不上传视频，只有云端分析会发 transcript 文本、视觉模型只收采样帧。

桌面版、命令行、Docker三条路怎么选

最省事的是桌面版：去 Releases 页下 .dmg 或 -setup.exe，Python 与 FFmpeg 都打包好了，打开设置选个云厂商或起个本地 Ollama，粘贴链接点生成。想把它接进 Agent 工作流，用命令行与 MCP 更顺：

uvx autoclip-mcp

npx skills add zhouxiaoka/autoclip

autoclip produce talk.mp4 --srt talk.srt --platform tiktok --portrait-style podcast --json

自托管或 Linux 与 Intel Mac 用户走 Docker：git clone https://github.com/zhouxiaoka/autoclip.git 后 docker compose up -d --build，网页端开在 http://localhost:3000。三种路出片质量一样，区别只在你习惯点鼠标还是敲命令。

 7.5 分钟出 10 条的前提是视频自带字幕，没字幕要先走本地转写，时间直接翻几倍。云端转写会上传音频，介意隐私就全程本地跑；AI 封面与标题是生成式的，发布前务必自己过一遍，别让模型替你把关。

手里有长视频库存、又想稳定出短视频的人，这工具值得装一个：免费、本地、一次配置长期用，唯一的成本是你自己的模型 Key。
