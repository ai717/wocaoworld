ClaudeSEO插件实战：用 Claude Code 做全站 SEO 审计

前置条件

在动手之前，确认本地已经装好 Python 3.10+、Git 以及 Claude Code CLI。如果你还没把 claude-seo 克隆下来，先跑一下安装脚本。

安装与初始化

打开终端，执行下面这条命令，脚本会自动拉取依赖并把 26 个子技能、19 个专家智能体注册到 Claude Code：

git clone --depth 1 https://github.com/AgriciDaniel/claude-seo.git && bash claude-seo/install.sh

安装完成后，可以用 claude --version 确认 CLI 已就绪，顺便看一眼 SkillsLLM 安全扫描介绍 确认版本无异常。

页面级审计（先跑 /seo page）

单页测试比全站便宜，token 消耗少，适合先验证配置。对着目标页面运行：

/seo page https://your-site.com/your-page

返回的报告会逐条列出技术 SEO、内容质量（E‑E‑A‑T）、Schema.org、AI 搜索优化（GEO）等 6 大维度的问题，并且每条建议后面都附带“怎么知道它错了”的可证伪检查步骤。

全站审计（启动最多 17 个专家智能体并行）

确认页面级没大问题后，再跑全站：

/seo technical https://your-site.com

这次会一次性启动最多 17 个专家智能体，覆盖本地 SEO、电商 SEO、国际 SEO 等 9 个可选扩展（Ahrefs、DataForSEO、Search Console 等实时数据源可在配置里开关）。全站跑完通常需要几百万 token，建议在预算充足时再执行。

避坑指南

1️⃣ 不要一次性对超大站点跑全站审计，子智能体并行会把 token 烧光，导致后续命令排队失败。
2️⃣ 如果你只想看技术层面，关掉内容质量与 GEO 扩展能省下约 30% token。
3️⃣ 安装脚本若报 “permission denied”，先给 install.sh 加执行权限：chmod +x claude-seo/install.sh。
4️⃣ 所有建议都附带可证伪检查，拿到报告后务必人工复核一遍，别盲目全信。
5️⃣ 遇到网络抖动导致 Ahrefs 或 DataForSEO 请求超时，建议在配置里把对应扩展暂时关闭，等网络稳定再开启。

进阶：把审计结果接入 CI/CD

把 /seo technical 的输出重定向到 JSON，配合 GitHub Actions 在每次合并前自动跑一次轻量级页面审计，随时守住 SEO 底线。更多自动化玩法可参考 Claude Code 仓库推荐榜单 里的实战案例。
