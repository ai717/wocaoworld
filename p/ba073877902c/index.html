Claude 剪片新玩法：先看 706 条爆款，不开 CapCut

 

剪片之前，先让 Claude 当两天“片儿警”

多数人用 AI 剪片的姿势是：丢一段原片进去，说“剪得燃一点”，然后对着平庸的成片叹气。Ola Ξlixir（@thegreatola）把顺序反过来了：剪之前，先让 Claude 研究你喜欢什么样的视频。他给 Claude 一个 X 主页，让它找出表现超过该主页平均水平的帖子，拆解 hooks（钩子）、cuts（剪辑）、pacing（节奏）、sound（声音），最后沉淀成一个可复用的 Skill。他的 launch video（产品发布视频）skill 分析了 706 个视频，talking heads（口播）也做了同款。实测战绩：1 分 39 秒原片，直出 52 秒成品，字幕、动效、音效全有，全程没打开 CapCut、没自己动手剪。方法帖 2026-11-02 发出，prompt 免费公开。

四步：找超平均帖子、拆解、生成 Skill、喂原片

找：指定一个 X 主页（比如你自己的，或对标账号），让 Claude 找出那些“表现明显超过该主页平均水平”的帖子——只学赢家，不学平均。拆：对每条爆款拆四件事：钩子怎么起、剪辑点在哪、节奏快慢、音效什么时候进。沉淀：把共性写成 Skill，以后剪同类视频直接调用，不用每次重新讲一遍审美。开剪：把 Skill 连同原片一起丢给 Claude，一句话开工，等成片。

这套流程妙在“审美前置”：以前是你脑子里有感觉、说不清楚，Claude 只能瞎猜；现在先把 706 个样本的共识变成 Skill，等于给了它一本你的口味说明书。

同类玩家：这不是一个人的自嗨

同一赛道已经挤了好几家：Soulepreneur 用 Claude + Runway MCP 剪片，5 步流程，连换背景带调色全包；YouTube 博主 nextphase把剪辑方法沉淀成 Editor V2 / V3 两个免费 skills，一个学 9 秒爆款 reel 逐帧做快剪，一个学电影感侧脸运镜。说明“先研究爆款、再沉淀 Skill、最后套剪”是正在成型的方法论，不是单条帖子的灵光一现。

先说清楚的限制

  • 吃“参考源质量”：你喂的 X 主页决定 Skill 的上限，喂一堆土味营销号，剪出来就是土味成品。
  • 重剪辑轻创意：这套方法强在执行层（节奏、字幕、音效），故事和创意还得你自己想，Claude 给不了。
  • token 账单：分析 706 个视频不是免费的，沉淀 Skill 是一次性投入，剪得越多摊得越薄，只剪一条就别折腾了。
  • 平台水土：X 爆款的节奏套到 B 站、抖音未必服，换平台最好重新跑一遍“研究”流程。

一句话：别再对着原片喊“剪得燃一点”了。先花功夫让 Claude 学会你的审美，之后每条片子都是“按你的口味自动剪”。
