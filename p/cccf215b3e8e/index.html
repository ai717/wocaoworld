Hermes Agent 替掉 Grok Bot：手机 Telegram 指挥

 

为什么要把 Grok Bot 换掉

Grok Bot 2026-08-11 上线 Beta，卖点是把 Grok 直接塞进 Cursor，用起来确实顺手。但它有三道绕不过去的坎：座位费 40 美元起步，还得永久绑定 Cursor 账号；没有模型选择器，想换便宜模型没门；所有 Bot 共用一台云端机器，数据与登录态都留在别人手里。相比之下，Hermes Agent 是 NousResearch/hermes-agent 仓库（截至 2026-11-09 约 26.2 万星）发布的 MIT 开源项目，最新版 v0.22.5（2026-10-23），支持 7 种终端后端、Telegram 等多个通讯网关、自带仪表盘，模型随便换，数据全在本地，关键是 Nous Portal 免费模型 0 元 就能用，付费套餐 20/100/200 美元分别给 22/110/220 美元额度。

先看一张对照表再决定换不换

维度 Hermes Agent Grok Bot
软件费用 0 元，MIT 开源 包含在 Cursor 座位费里，40 美元起
模型选择 一条命令切换，Nous Portal、OpenRouter、OpenAI 或自有端点 没有选择器，官方未公布默认模型
运行位置 自己的电脑、服务器或沙箱 xAI 的云端机器
手机入口 Telegram、Signal、WhatsApp 等聊天网关 官方桌面与手机应用
账号绑定 不需要 必须绑定 Cursor 账号
数据归属 在自己机器上 在对方的云端机器上

这张表的数据来源是 Continuum 的 Grok Bot 与 Hermes Agent 对照，价格与版本以官方最新口径为准。结论很直白：要省心选 Grok Bot，要自己说了算选 Hermes。

动手前得备齐三样东西

一台能跑 bash 的机器（Linux、macOS、WSL2 均可），一个 Telegram Bot Token（找 @BotFather 申请），以及可选的 API Key：想白嫖就留空走 Nous Portal 免费模型，想更稳就备一个 OpenRouter 或 OpenAI Key。不需要 Docker、不需要 Kubernetes、更不需要 Cursor 订阅。把这三样攒齐，下面全程复制粘贴命令就能跑通。

一条命令把 Hermes 跑起来

打开终端，直接跑官方安装脚本：
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
按官方说明一键装好后切模型：
hermes model
交互式菜单里选 Nous Portal (Free)，回车确认。网络不通时先检查代理再重跑。装好后输 hermes dashboard，浏览器打开 http://127.0.0.1:9119 能看到仪表盘，说明核心跑通了。

把 Telegram 当成前端界面

在仪表盘左侧「Gateways」点 Telegram，按提示填入 Bot Token、可选的 Webhook URL（留空走长轮询）、允许的用户 ID 白名单（不填则全员可用），点「Save」再点「Start」。几秒后手机给 Bot 发 /start，收到欢迎语即代表网关通了。此时对话直接命中本地 Hermes 进程，再经由所选模型推理。若想同时上 Discord、Slack、WhatsApp、Signal、邮件，同理在 Gateways 里逐个开启，配置一次、到处可用。出门在外时，配合 Tailscale 把家里电脑暴露给手机，等于随身带了一个私人 Agent 服务器，这也是原帖里提到的远程方案。

免费模型这条路怎么走

Hermes 最大的实惠不在软件免费，而在模型自由：模型随时可换——hermes model 一条命令就能在 Nous Portal、OpenRouter、OpenAI 与自有端点之间切换，不用改代码；上下文归自己管——仪表盘「Sessions」里能看到完整会话记录，想审计、想导出全凭自己；终端后端随意切——本地 local、容器 Docker、远程 SSH、HPC Singularity、云端 Modal、Daytona、Vercel Sandbox 七选一，同一个 Agent 实例 能在笔记本、服务器、云端沙箱之间换地方跑。免费模型不是无限量：Nous Portal 免费池有并发与额度限制，高峰期可能限流，介意的话直接切到 OpenRouter 的免费模型或本地 Ollama 端点，同样一条命令的事。Grok Bot 那边恰恰反过来：省心是省心，但账单没有上限，跑多了只能认。

哪里最容易翻车

网关断线先看日志：Telegram 长轮询在弱网下会偶发断连，现象是 Bot 卡住不回消息。先到仪表盘 Gateways 页点「Restart」重启网关，还不行再重启 Hermes 服务，多数情况就地恢复。

免费模型限流别硬抗：Nous Portal 免费池并发有上限，高峰期可能返回限流。别反复重试，直接 hermes model 切到 OpenRouter 免费模型或本地 Ollama，切完即用，零代码改动。

自托管的代价是运维：Hermes 的短板不在功能，而在维护——更新可能改配置、网关可能掉线、备份得自己做。如果图省事、手机原生体验优先，Grok Bot 仍然是更顺的选择；如果在乎模型自由、数据归属与可控的账单上限，Hermes 这套替代方案值得花一个晚上搭起来。原帖还提到技能可以从 Grok Bot 侧迁移过来，迁移前先逐条核对 skill 里的路径与密钥，别把旧配置原样照搬。
