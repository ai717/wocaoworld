244 个像素特效全是代码：pixelfx 让 AI 当像素美术

 

仓库描述写 232、README 数到 244：先搞清这库到底装了多少货

2026 年 10 月 30 日上线的 patch-gg/pixelfx，首日破 1100 star，到 11 月 3 日已经 3531 star。仓库描述栏还写着 232 个特效，README 里已经数到 244 个 —— 长得太快，维护者连描述都顾不上同步。244 个像素风游戏特效，每一个都是一小段 JavaScript，没有一张 PNG，没有一行运行时依赖。火焰、爆炸、冰霜、闪电、传送门、金币拾取、屏幕转场，还有 12 组带招式动作的战斗特效。协议 MIT，代码和特效都能商用，只有一套 Patch Pixel 字体除外（见 NOTICE.md）。

方法论来自 Sprite Fusion 作者 Hugo Duprez 2026 年 10 月 28 日发的教程《How to make (good) pixel art effects with Claude》，核心思路是用噪声、贝塞尔曲线、粒子寿命、颜色渐变这些数学公式把像素美术「算」出来。他的开源特效集定了标杆，pixelfx 的 src/core/sim.js 和部分特效直接改编自他的代码（文件头有署名）。在线画廊能逐帧预览全库，先去逛一圈再决定装不装。

用法一：npm 一行装进浏览器游戏，零依赖逐帧画

最省事的路径，README 原话：

npm i github:patch-gg/pixelfx

然后在 Canvas、Phaser、PixiJS、Kaplay、three.js 项目里直接调代码。官方示例：

import { createFrame, clearFrame, createFx, composite } from 'pixelfx';

const fx = createFx(frostNova, { x: 160, y: 140 });

每个特效就是 src/fx/<category>/<name>.js 下的一个模块，20 个分组：moves、fire、explosions、water、ice、lightning、sci-fi、melee、impacts、projectiles、spawn & death、arcane、holy、shadow、status、nature、weather、ui、pickups、transitions、critters。浏览器路径零依赖，参数支持翻转、角度、随机种子、调色板。带角色的特效是「演」出来的：蓄力、出手、命中定格、收招，12 组招式能把 wind-up 到 recovery 串成完整攻击动作。

用法二：node 一行吐精灵表，Godot、Unity 直接拖进去

不想在运行时算帧、想离线烘焙进引擎？官方命令：

node tools/render.mjs ice/frost-nova --sheet

输出透明底 PNG 网格图 + Aseprite 风格 JSON（帧矩形、时长信息），拖进 Godot、Unity、GameMaker、Defold、LÖVE、Bevy 当手绘素材用。特效 id 去 在线画廊点任意特效看，分类目录见仓库 docs/CATALOG.md。

用法三：Claude Code skill 让模型按「挑剔像素美术」的流程造新特效

这是 pixelfx 最出圈的部分。装 skill 两条命令（README 原文，explainx.ai 上手指南有更细的步骤拆解）：

/plugin marketplace add patch-gg/pixelfx

/plugin install pixelfx@pixelfx

或者把 skills/pixelfx 文件夹拷到 ~/.claude/skills/。装完直接对话提需求，官方示例：”Add a frost nova to my mage’s ultimate.”、”Make five takes on a coin pickup sparkle and show me the best two.”、”Export the fire and explosions categories as sprite sheets for Godot.”、”This hit effect feels floaty. Make it punchier.”

skill 的工作方式是「像个挑剔的像素美术」：起草、渲染、看、改，循环打磨。注意前提：这是第三方 marketplace 的 skill，不是 Anthropic 官方维护，装之前建议把 skills/pixelfx 的内容读一遍，这是用任何第三方 skill 都该有的习惯。

四天大的仓库：进生产前先 pin commit，字体授权单独看

丑话说前面：仓库 2026 年 10 月 30 日才建，零稳定性记录，API 随时可能变。想进商业项目，别直接依赖 main 分支，pin 一个 commit 再用。字体坑单独拎出来：仓库 MIT 协议覆盖代码和特效，但 Patch Pixel 字体不在 MIT 范围内，见 NOTICE.md，带文字的特效（比如伤害数字飘字）打包进商业游戏前先确认字体授权。

总结一下：244 个现成特效拿来即用、导出精灵表进任何引擎、Claude Code skill 能把新需求变成代码草稿，代价是仓库太年轻、skill 代码得自己审一遍。原型期验证玩法，这库是真香；要上生产，先锁版本再谈。
