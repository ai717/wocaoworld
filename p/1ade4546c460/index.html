Stripe MCP 接入 Claude Code 一条命令搞定出海收款

前置条件

先确认你有一个 Stripe 账号（测试先用 sandbox 模式练手）；本机装好 Node 18+ 和 npm，能正常跑命令；Claude Code 已经装好并能正常对话；准备一台能联网的机器，因为远程 MCP 地址 https://mcp.stripe.com 走 HTTPS，确认防火墙没把出站 443 掐掉。动手前先扫一眼 Stripe MCP 官方文档，心里有数再开干。

一条命令接入

打开终端跑 npm install -g @stripe/cli@latest 装最新版 CLI，再执行 stripe agent setup。这条命令会自动探测你正在用的 Agent，把 MCP 服务器和官方 skills 一次配好。交互式使用选 OAuth：按提示在浏览器里点授权就行，后续 token 自动续；无人值守的后台 Agent 则用 agent API key，把 key 填进配置。手动党也可以直接改 MCP 客户端配置，核心就一段：{'mcpServers': {'stripe': {'url': 'https://mcp.stripe.com', 'headers': {'Authorization': 'Bearer 你的_AGENT_API_KEY'}}}}，OAuth 方式连这个都不用手写。

装完能干什么

场景一：半夜用户催退款，直接在 Claude Code 里说「帮我把这笔订单退全款」，模型会调用 stripe_api_write 发起退款，接着甩给你一条确认链接，你在浏览器点一下，24 小时内不点就作废。场景二：给新客户发收款页，说「生成一张 19.99 美元的一次性收款链接」，模型建好 PaymentLink 把 URL 丢回来，直接转发客户。场景三：查账对账，说「把最近 30 天 successful 的 charge 按金额列出来」，模型走 stripe_api_search 加 stripe_api_read 把金额、币种、手续费一次吐出来，省得在 Dashboard 里翻五个页面。场景四：想了解 Treasury（资金调度那套，目前 public preview），直接问「给我规划一个自动转账到对公账户的流程」，stripe_implementation_planner 会按步骤给你方案。

权限与安全

认证两条路：OAuth 适合人在回路的交互式客户端，首次 setup 按提示在浏览器授权；agent API key 适合无人值守的后台 Agent，建 key 时只给最小权限，泄露了立刻去 Dashboard 吊销。所有写操作（退款、创建付款、Treasury 转账）强制人工点确认链接，这是 Stripe 的硬性要求，谁也绕不过。关键截止日期：2026 年 11 月 30 日前，把还在用的 full-access secret key 和无 Agent 标记的 restricted key 全部迁走，12 月起 Stripe 直接拒收。Dashboard 里可以按 live、sandbox 分别开关 MCP 访问，测试只开 sandbox，上线再开 live。MCP 连接本身免费，不收额外费用，Stripe 的交易费率照常。

避坑

网上流传的各种「一行命令装 Stripe MCP」如果出自非官方渠道，先去 官方文档 对一遍再跑，只认 stripe agent setup；OAuth 授权时浏览器没弹窗，检查弹窗拦截或换个浏览器；agent API key 写进配置文件后千万别提交到公开仓库，.gitignore 里加上；确认链接只能在浏览器里点，终端里点不开，别干等到超时；Treasury 系列还是 public preview，生产先跑 sandbox；MCP 只负责读写 Stripe 资源，复杂业务编排还得自己写代码。更多实战细节可以看 这篇第三方实战记录。

搞定这几步，半夜催退款、查账、开链接这些脏活全丢给 AI，你只负责点确认链接。省下来的时间，够你多写两个需求了。
