tchMaterial-parser能把电子课本存成PDF，版权和登录都还在

工具解决的是离线阅读，不是把教材变成公共种子

happycola233/tchMaterial-parser 面向国家中小学智慧教育平台上的电子课本：解析预览页、按书名保存 PDF、可选写入书签。Windows、macOS、Linux 都有发行包，也可用 WinGet 或从源码运行。2025 年 5 月一度冲上 GitHub 热榜。程序开源（MIT），课本本身仍是出版社和平台的版权物。

平台自 2025 年 2 月起，多数电子课本要登录才能看。工具因此支持填入登录凭据，新版本还按官网方式生成私有下载签名，并限制并发、拉开间隔，减少连打接口被拒。官网改接口时，解析会跟着坏，仓库 issue 里反复出现过这类修复。

它自动的是文件名和目录，不是使用权

一次可粘贴多条预览页地址，下载后用课本名称当文件名，打开「添加 PDF 书签」后，目录页能跳到对应章节。这对需要离线备课、弱网地区反复翻页的人有用。浏览器在线阅读不必下载；把整套教材打包传到网盘、群文件或做资源站，则越过个人使用的边界。

能力 实际作用 不能当成的事
批量解析预览链接 少点几次另存为 绕过平台登录与授权
按书名存 PDF 本地好找 获得再分发权
自动书签 离线跳章节 替代官方阅读器的全部功能
跨平台安装包 Win / macOS / Linux 能跑 平台接口永不变更

仓库自带免责声明。教材版权在出版社和平台，登录态属于账号本人。教师备课、学生复习，应使用自己有权访问的条目，并遵守平台条款。接口变更、CDN 校验变严时，工具会突然报 400，这是解析类软件的常态，不是「开箱即用一辈子」。

离线副本要当私人笔记，不要当货源

智慧教育平台把统编和各版电子课本集中到网页里，本意是正规渠道阅读。解析器只是把已授权的页面变成带书签的文件。需要长期离线时，先确认账号能在官网打开该书；不需要离线时，继续用官方阅读器更省事，也少一份本地副本的管理成本。
