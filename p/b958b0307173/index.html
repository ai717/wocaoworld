4000+ 个免费 Agent Skills 一键装进 Claude Code

 

别再手写 Prompt 了，4000 个现成技能躺在这

还在为每个新任务现写 Prompt 发愁？mdskills.ai 直接摆出 4000 多个现成的 Agent Skills，覆盖开发、安全、SEO、数据分析等多个领域。背后靠的是 Anthropic 推的 SKILL.md 开放标准，本质是一套结构化 Markdown，把系统提示词、工具调用、参数校验全打包成一个 .md 文件。你只需要把文件扔进 .claude/skills/ 目录，Claude Code 启动时自动识别，零配置即用。

三个入口，一个命令全搞定

官方仓库 anthropics/skills 只收录官方示范技能，真正的大头在社区维护的 alirezarezvani/claude-skills：416 个技能、112 个插件、MIT 协议随便白嫖。最省事的装法是用官方 CLI：

最省事的装法是一条命令：npx skills add 加上仓库地址，比如 npx skills add anthropics/skills。也可以直接把仓库克隆下来，按需取用里面的技能文件夹。全程不需要 Docker、不需要 API Key、不需要信用卡，真正的「免费白嫖 + 效率整活」。

技能长啥样？拆开 SKILL.md 看门道

别被 .md 后缀骗了，这玩意儿不是普通 Markdown。打开任意一个技能文件，你会看到前置元数据（名字、版本、描述）加上一份分步指引，有的还附带脚本和参考资料。Claude Code 读到这段就知道该按什么流程办事，比如 SEO 审计技能会写明先抓页面、再拆结构、最后出修复清单。这种「提示词即代码」的设计，让技能之间能像 npm 包一样组合复用。

装之前先别急，坑在源码里

安全提醒：据 这篇 X 帖子 引述 Walma AI 对 3.1 万个公开 skills 的分析，约四分之一存在漏洞、约 5% 疑似恶意。装前先读源码不是建议，是生存技能。

最常见的坑是 Tools 里藏私货——比如声明只读 fetch，实际在 System Prompt 里诱导模型调用 exec 跑任意命令；还有技能把敏感文件路径硬编码在 Prompt 里，一旦被注入就直接泄露本地环境。建议养成验收动作：先把 SKILL.md 全文读一遍，再搜一搜有没有 exec、bash、shell 这类危险调用。别信 Star 数、别信作者简介，只信你自己读过的源码。

拿 SEO 审计技能举例：装好之后怎么用

装好之后，你只需要在对话里说一句“给这个站做 SEO 审计”，模型就会按技能里的流程走：抓页面、拆结构、跑检查，最后吐出一份带优先级的修复清单。全程你没写一行 Prompt，也没配过 MCP Server。想改检查重点，直接改技能文件里的文字就行，保存即时生效——这就是「提示词即代码」的爽点。

别让免费变成最贵的学费

4000 个技能听起来爽，但别把 Claude Code 当成插件商店随便逛。每个技能都是一段拥有工具调用权限的系统提示词，装多了上下文窗口会被挤爆、工具命名空间会冲突、推理延迟会飙升。建议按项目建 skills 子目录，只放当前项目需要的技能，别一股脑全装上。真正的高手不是装得多，而是懂得在 skill.md 里把 tools 列表剪到最小、把 system prompt 写得最窄。免费的技能最贵，贵在你不敢审计、不敢删减、不敢担责。
