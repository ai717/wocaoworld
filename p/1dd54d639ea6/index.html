Claude 免费课扩容到 22 门：零基础到 Agent 全免费

 

13 门变 22 门：先把数字这笔账算清楚

先说最容易踩的坑：别把“13 门”当成今天的总数。Claude Academy 是 Anthropic 的官方学院，2026 年 3 月 2 日上线时确实只有 13 门免费课，2026 年 8 月 20 日由 Anthropic Academy 改了现在的名字。目录一直在加课：2026 年 11 月 11 日核查的目录是 22 门，另一份 11 月 1 日核对的清单列出了 28 门、434 节课、83 小时。两个数字都对，只是统计时间不一样。报名之前以官网实时目录为准，别拿着旧清单按图索骥，13 门那份清单适合当入门地图，不适合当今天的总数。

三条线各管什么人：零基础别去挤开发者那条

课程分三条线，各管一拨人。零基础线不用会代码：Claude 101 约 2.5 小时，讲日常使用和提问方法；AI Fluency 讲怎么把 AI 用进工作，还有学生和教育者专用版本。开发者线要会 Python 或命令行：Claude Code 101 约 1.5 小时，Building with the Claude API、Claude Code in Action、Introduction to MCP、Introduction to Agent Skills 都在这条线，其中 Agent Skills 入门课只有 6 节课、约 1 小时，专门教怎么做可复用的 Skill。云平台线管 Bedrock 和 Vertex AI 上的部署。挑课先看身份，零基础跑去开发者线，第一课就会被命令行劝退。

免费是真的免费：邮箱注册，徽章能挂领英

全部免费是这套课最大的卖点：只需邮箱注册，不用信用卡，没有试用期套路。课程托管在 Skilljar 平台上，入口在 academy.claude.com。学完多数课程能拿结业徽章，可以挂到领英个人资料上。给新手一条最短路径：先上 Claude 101 摸清日常用法，再上 Claude Code 101 学会让模型写代码，最后补 Introduction to Agent Skills，把常用流程沉淀成自己的 Skill，这三门串起来就是一套完整的 Claude 上手路线。徽章是厂商发的学习证明，不是大学文凭，写简历时别夸大成认证。但对想系统学 Claude 的人来说，官方一手材料本身就值这个时间，比到处拼免费教程靠谱得多，至少不会学到过时的野路子。

先泼三盆冷水：不是每门课都有徽章

第一，28 门里有 4 门没有徽章，包括 Introduction to Agent Skills、Introduction to Subagents 这类课，冲徽章去的人先核对清单。第二，正式认证考试是另一回事：Claude Certified Architect 这类认证考试要收费、还有门槛，别和免费课的结业徽章混为一谈。第三，课程是英文平台，英文吃力的人要多留时间。第四，目录膨胀得很快，今天的清单下个月可能又变，收藏之前先确认自己要学的那门还在不在，报了名就尽快开课，别囤课。
