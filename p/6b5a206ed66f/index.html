一条 Mega Prompt 几分钟搭出 n8n AI Agent

先把 Docker 跑起来

先在服务器或本地装好 Docker，拉取官方镜像 n8nio/n8n，命令如下：
docker run -d -p 5678:5678 --name n8n n8nio/n8n。启动后浏览器访问 http://localhost:5678，看到 n8n 登录页就算成功。这一步不需要任何付费套餐，Community 版本完全免费且无执行次数限制。

把 Mega Prompt 扔进 ChatGPT

打开 Andrew Bolis 的 X 原帖，复制完整的 Mega Prompt（包含 role、task、requirements、output_style、expandability 五大模块）。把它粘贴到 ChatGPT 对话框，紧接着告诉它你想让 Agent 做什么，比如“帮我把 Reddit 热帖抓取、用 Claude 摘要、再推送到 Telegram”。几分钟内 ChatGPT 就会吐出一份完整的 n8n JSON，里面已经把触发器、AI Agent 节点、工具节点、错误处理、甚至自定义代码全写好。

在 n8n 里把 Agent 节点接好

把 ChatGPT 生成的 JSON 导入 n8n（右上角 Import → 从文件/粘贴）。重点检查三个子节点：
• Chat Model 子节点必须指向你可用的 LLM（示例里用 Claude）；
• 至少一个 Tool 子节点，像 HTTP Request、Telegram、Email 等；
• 可选的 Memory 子节点，如果需要上下文记忆就加上。保存后点击 Execute Workflow 跑一遍，观察每个节点的绿色对勾。

容易翻车的三个坑

1. 端口冲突：如果 5678 已被占用，Docker 会静默失败，改映射端口即可。
2. 凭证未授权：Tool 节点里的 API Key、Bot Token 必须在 n8n 的 Credentials 里先配好，否则运行时会报 401。
3. Prompt 太宽泛：只说“做个 Agent”会得到通用模板，必须把业务细节（数据源、输出格式、重试策略）喂给 ChatGPT，才能一次出成品。

实战案例一览

Andrew 本人已经用这套流程跑通三个项目：
• Reddit + Claude + Telegram 内容策展；
• 线索分级（prospect qualifier）自动打标；
• 自动邮件助手，按规则回复常见咨询。全部都是 Claude + n8n 驱动，零代码手写。

想拿完整 Prompt 直接去 X 原帖 复制，配合 techsy.io 教程 和 dev.to 实战笔记，半小时内就能把专属 AI Agent 跑起来。
