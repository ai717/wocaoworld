开启Chrome隐藏AI功能：Gemini与AI搜索一键解锁脚本教程

解禁 Chrome 隐藏战力：三步开启谷歌浏览器原生 Gemini 与 AI 搜索功能

在 AI 浏览器大战中，Google Chrome 其实内置了极为强大的 AI 全家桶——从侧边栏的 Gemini 到 AI 驱动的历史记录搜索，再到 DevTools AI。然而，由于地理位置限制或灰度测试，这些功能对许多用户来说依然处于“封印”状态。

以往我们需要通过复杂的 Flag 设置甚至重装系统来尝试解锁，但现在，一个名为 Enable Chrome AI 的轻量级 Python 工具彻底改变了规则。无需清除数据，无需代理到特定节点，直接在底层完成“降维打击”。

一、 它是如何运作的？（技术解密）

Enable Chrome AI 的核心逻辑并非通过前端 Flag 撞大运气，而是直接对 Chrome 的本地配置文件（Local State）进行“微创手术”。

  • 绕过地理限制：自动将 variations_country 设置为 “us”。

  • 激活 AI 准入：递归搜索并将所有 is_glic_eligible 标志设为 true。

  • 持久化生效：通过修改一致性国家代码，确保重启后功能依然常驻。

二、 准备工作

在开始这场极客冒险前，请确保您的环境满足以下条件：

  • Python 版本：需要 Python 3.13+（这符合 2026 年的主流开发标准）。

  • 浏览器状态：支持 Chrome 的所有版本（Stable / Canary / Dev / Beta）。

三、 闪电开启步骤（以 uv 为例）

推荐使用高性能的 uv 工具，它可以自动为您管理虚拟环境和依赖。

  1. 安装 uv（如果尚未安装）：

    • Windows: powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

    • macOS / Linux: curl -LsSf https://astral.sh/uv/install.sh | sh

  2. 执行 Patch： 进入项目目录后，直接运行：

    Bash

    uv sync
uv run main.py

  3. 重启 Chrome： 脚本会自动检测并关闭 Chrome 进程，完成修改后自动拉起。按下回车，你将看到一个“脱胎换骨”的 AI 浏览器。

四、 风险与提示

  • 数据安全：脚本会直接写入您的配置文件，建议在运行前备份 User Data 目录。

  • 独立性：此工具为开源社区项目，非 Google 官方提供，请在知晓风险的情况下使用。
