AI 模型降价开打了：OpenAI 和 Anthropic 同天互砍，开发者捡漏

9月22日，Anthropic 和 OpenAI 相隔一小时各自上新，打响今年最狠的一轮模型降价战：Claude Opus 5.5 便宜两成还更快，GPT-6 Sol/Luna 直接腰斩。同样的活花一半的钱，这篇帮你算明白。

三款新模型价格拆解：一张表看懂便宜了多少

Anthropic 先出手。9月22日发布的 Claude Opus 5.5：输入 $4/百万 tokens，输出 $20/百万 tokens，比 Opus 5 便宜 20%，生成速度快 30%。官方口气不小，宣称在所有指标上超越 Fable 5.1，在 agentic coding 和 knowledge work 上几乎全面超越 OpenAI 的 GPT-6 Astra。

约一小时后 OpenAI 接招，一次丢出两款：GPT-6 Sol 输入 $2/百万、输出 $10/百万；GPT-6 Luna 输入 $0.10/百万、输出 $0.50/百万，两款都比 GPT-5.6 对应版本便宜约 50%。Sol 主攻 recurring coding 和 agent 工作，Luna 专攻 summarization/extraction 这类高频批量任务。两款定位都低于 GPT-6 Astra——就是 9月3日发布的、被 OpenAI 称为 “the most intelligent and aligned model in the world” 的那款旗舰。详细的价格汇总可以看 Sunporch AI 的本周复盘 和 Colin Michaels 的 AI 周报。

模型 输入价格 输出价格 降价幅度 定位
Claude Opus 5.5 $4/百万 tokens $20/百万 tokens 比 Opus 5 便宜 20%，生成快 30% 旗舰级：agentic coding、knowledge work
GPT-6 Sol $2/百万 tokens $10/百万 tokens 比 GPT-5.6 对应版本便宜约 50% recurring coding 与 agent 工作
GPT-6 Luna $0.10/百万 tokens $0.50/百万 tokens 比 GPT-5.6 对应版本便宜约 50% 高频批量任务：summarization/extraction

横向一看，OpenAI 这次是真下了血本：Luna 的输入价只有 Opus 5.5 的四十分之一。哪怕不做技术分析，光看数字也知道，这轮模型降价战的受益人是掏钱的开发者。

Sol 和 Luna 怎么选：看场景，别看名字

OpenAI 这次把 GPT-6 家族的分工做得非常直白，基本不用猜：

你的场景 该选谁 理由
每天跑成百上千次摘要、信息抽取 GPT-6 Luna 批量任务成本直接砍掉一个数量级
写代码、跑 agent、周期性 coding 任务 GPT-6 Sol 专为 recurring coding 和 agent 工作调校
要最强推理和知识工作能力 Claude Opus 5.5 / GPT-6 Astra 旗舰定位，价格也最高
  • 做 RAG、文档摘要、数据清洗流水线：闭眼 Luna，省下的钱够你多跑十倍数据。
  • 做代码助手、自动化 agent：Sol 是甜点位，比旗舰便宜一大截，能力又够用。
  • 做复杂推理、长链条 agent：Opus 5.5 降价 20% 之后，旗舰体验的门槛低了不少。

对开发者意味着什么：每个任务到底能省多少

别光看单价，算一笔 per task 的账。假设一次代码补全消耗 2000 输入 tokens + 1000 输出 tokens：Claude Opus 5.5 成本约 $0.028，GPT-6 Sol 约 $0.014，GPT-6 Luna 只要约 $0.0007。放大到一万次调用：Opus 5.5 是 $280，Sol 是 $140，Luna 只要 $7。选对模型，一万次调用的成本能差出 40 倍。

“That Luna pricing is strikingly low for a GPT-6 family model — and it signals where the real competition is heating up: not just on capability, but on the cost per useful task completed.” —— Sunporch AI

翻译成人话：真正的战场已经从跑分卷到了每个有用任务的成本。对独立开发者和小团队来说，这意味着以前烧不起的批量任务（全量文档重写、大规模数据标注、7×24 的监控 agent）现在可以重新排进日程了。

薅羊毛姿势也有讲究：新模型上线初期，官方 playground 和 API 新用户额度往往最慷慨；另外 Claude Sonnet 5.5 与 Haiku 5.5 将在未来几周发布，中杯和大杯的价格大概率更香，不急的话可以等等再做技术选型。

避坑指南：便宜的价格也可能打出贵账单

  1. 价格不等于真实成本。agent 任务要跑多轮、带长上下文，一次任务的实际 token 消耗可能是你预估的 5~10 倍，单价便宜但重试拉满，账单照样爆炸。
  2. 旧攻略过期了。GPT-5.6 时代的价格表和选型建议可以直接扔了，按新价格重新算一遍 ROI。
  3. 别为省钱牺牲质量。Luna 便宜是因为它干的是苦力活，复杂推理还得旗舰上，省错地方等于返工花双倍。
  4. 等等党可能赢。Claude Sonnet 5.5 和 Haiku 5.5 未来几周就发布，Anthropic 的中杯一向是性价比之王，大额采购前先观望。

一句话收尾：模型降价战开打，开发者是最大赢家，但赢的是会算账的人。先把你的任务按场景分好类，再对号入座选模型，这波羊毛才能薅到实处。
