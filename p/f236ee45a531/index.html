WolfCut对标CapCut常用刀法：Alpha本地剪，不是特效商城

不收费、不注册、无水印，但还在预发布

jub0t/WolfCut 把自己写成开源的 CapCut 替代：Rust 引擎加 React 界面，装上就能剪，不必开账号。仓库写明多轨、可开多条时间线，切割合并、转场、变速、标题和模板都有；自动字幕在本机转写，音频不出电脑；另有本地 TTS 和音色滤镜。协议是 MPL-2.0，安装包会带独立调用的 FFmpeg。当前发行是 0.2.0 的 Alpha，星标刚过六百，功能面比剪映商城窄一截。

烦的是导出弹会员、字幕要上传。WolfCut 把这两刀砍在本地。它补不了的是海量模板、云协作和平台一键发布。当备选合理，当「剪映可以卸了」还早。

对得上日常短视频，对不上整座特效库

短视频常用路径：多轨叠画面和BGM、切开、变速、加标题、出字幕、导出无水印。这些 README 都点过名。时间线在画布上画，时间计算放在 Rust 里，避免前端浮点漂移。Windows 和 macOS 标过测试，Linux 可装，Mac 包未签名，要自己去掉隔离属性。

你要的 WolfCut现在 仍要留着CapCut的时候
无水印导出 宣称没有订阅墙 要官方特效和热门模板
自动字幕 本地转写 要云端更高识别或多语种精修
配音 本地TTS和滤镜 要商用音色库和授权票
多时间线 一个项目可开多条 要团队云草稿
稳定发片 Alpha，更新快 不能接受崩草稿

路线图还写着人脸检测模糊、字幕逐词高亮、脏话检测和自动去静音，说明这些还没当成品卖。本地模型会占磁盘和CPU，第一次出字幕可能要等加载，这是隐私换来的重量，不是「装上就和会员版一样快」。

先当第二套刀，别把交片押在Alpha上

适合讨厌账号墙、素材不能出门的人。交客户成片前，先用一段无关素材走完导入到导出。会员弹窗可以少看，特效口味和稳定性还得自己验收。多个备选不会错，把备选写成已经取代剪映，会在第一次寻找某个滤镜时碰壁。
